## Selected boundary

One private synchronous process per live app/profile selection executes one fixed `ObserveWindowsReuse` command. It has no permission source, domain enrollment, startup storage lease, persistent observation cache or arbitrary dispatcher. Initialize and Shutdown are lifecycle messages. Requests from physical parent workers serialize; no per-thread process pool or cross-profile service is introduced.

Replace only the warm Windows observation block in `storage_admission._reuse_evidence`. Parent retains original `_Acquisition`, source/execution selection, hold/evidence selection, counted real `StorageLease` and final `checked(provenance=True)`. Send root/selector spelling, expected input tuple and ordered posture/content dependencies as detached data. Child executes the original `_windows_inputs` context, compares inputs, and conditionally calls original `_observe_evidence` while the original shared registry lock remains held. Input mismatch skips union observation. Context exit and positive native retirement precede the detached result. Parent compares stamps and runs unchanged final provenance checks. No lease, HANDLE, fd, callback, source object or permission verdict crosses the protocol.

Completed ordinary mismatch or original OSError/ValueError with proven retirement retains the original negative-evidence/full-derivation policy. A selected transport/source/protocol/issuance/retirement failure raises a distinct RuntimeError-derived owner failure outside that negative fallback. Parent outer cleanup closes its original counted token. Never replay the selected command locally or in a replacement process.

## Native custody contract

Add explicit inert-outside-scope hooks to `Utils/windows_files.py`, with a small stdlib-only private custody implementation. The exact worker scope is tied to PID, physical thread, worker generation and command ordinal. This scope grants no permission. No global monkeypatch, cloned source, dynamic callback or fake raw operation.

Each native allocation attempt is recorded before entering the native call. Retain its monotonic issuance ID, operation/site, resource kind, native output cell, parent birth, flags/access, result/error and state after context exit. Prepublished ctypes output cells cover birth before validation. Interrupted/unknown results remain uncertain. Raw values can be reused and never identify custody without the issuance record.

| Resource family | Required hooks and existing source |
| --- | --- |
| Bootstrap/selector private traversal and files | Original `bootstrap.pinned_directory`, `_read_record_bytes`, `_fingerprint` and `private_paths` walker remain. Track all raw-to-CRT births underneath; add explicit `WindowsOS.close` that preserves ordinary `_os.close` behavior outside scope. |
| Direct admission traversal | `native_files.pinned_directory` can have both current and newly opened successor when parent close fails. Retain both births; close a never-attempted known successor once on unwind, preserving the error. |
| Raw roots/relative opens and validation failure | Prepublish all `NtCreateFile` outputs in `_Native.open_handle`, including non-metadata paths. Check/retain every reachable `CloseHandle` in `_parent` and open failure cleanup. |
| Root duplication and CRT transfer | Record `DuplicateHandle` birth; retain `transfer_pending` before original audited `open_osfhandle`. Link successful CRT birth to raw HANDLE. Ambiguous transfer prohibits blind raw close and success. |
| Registry lock | Preserve `O_RDWR`, original `LockFileEx` shared lock and postwait identity/list/read checks. Record lock ownership against its exact descriptor. Original positive CRT close releases it; add no early unlock. |
| Ordinary stat and union metadata | Cover `WindowsOS.stat` for registry/qualification/error-classification paths. Reuse `_AdmissionMetadataHandle` and `_AdmissionMetadataCloseError` for union opens/bottom-up reopens; retain successful/rejected records and explicit close results after `opened` removal. Preserve finite metadata-tree volume proof and fresh ACL/identity checks. |
| Security allocations | Record GetSecurityInfo descriptors and ConvertSidToStringSidW strings, with checked LocalFree. Owner/DACL/ACE pointers are borrowed; ctypes-owned buffers need no native free. Preserve original immutable descriptor decoding memo. |

| Qualification reader | Keep original fresh stat/cache validation and installed evidence file behavior. Add explicit fdopen transfer and owning-stream close-result hooks in `qualification._load_evidence`; stream close bypasses facade close. Exercise both hit and miss paths. |

Directory enumeration here borrows a descriptor and uses GetFileInformationByHandleEx with a ctypes buffer; it creates no FindFirstFile handle. Fixed command paths do not reach creation/private_sd, mutation, SQLite or general reopen APIs; source changes that expand allocation reach require coverage before selection.

Before close mark the exact record close-attempted. Successful `_os.close` retires its transferred HANDLE; CloseHandle needs nonzero BOOL; LocalFree needs null return. False/raised/ambiguous close remains uncertain and is never retried by number. Continue retirement attempts for other known-owned births. Process exit contains uncertainty but cannot relabel it successful retirement. This deliberately tightens formerly ignored raw CloseHandle/LocalFree failures only in the selected scope; ordinary outside-scope behavior stays compatible.

Seal only after original context exit and a complete issuance/transfer lineage check: each attempt has a terminal result; each successful birth is positively closed or transferred to a positively retired successor. Equal counts, empty maps, successful return, `.closed` alone and exit zero are insufficient. Receipt carries exact issuance/state lineage and errors; parent validates correlation/shape/transfer consistency. Retain child records until correlated receipt acknowledgment, then release successful records. Preserve unresolved ones through containment. No permanent success-history store.

## Source selection and audit semantics

Only exact stock ordinary Windows warm reuse selects. Cold/recovery/maintenance, unsupported/custom/changed source paths retain their original route before selection. Task25's classifier is the starting point: inspect actual PID/thread/task identity and all matching raw registrations under the storage RLock, including hidden/inactive/retiring entries. Raw or MCP-preparation TLS, voice ContextVars, visual state even without a helper, unavailable/changed discovery and unknown census exclude. Foreign owners alone do not exclude. Never call effectful selectors or clear state to manufacture eligibility.

Qualify a fixed declared command implementation closure at command boundaries: original helper/wrapper/code/default/keyword/closure/module bindings, private walker, native facade, qualification, codec and custody. No per-scalar whole-module scans. Include exact native signatures, loaded source origins, interpreter/platform/architecture and token-user SID at boot. Source drift after selection refuses rather than replaying. The child role and existing permission-worker role never select this observer, preventing recursion.

Parent captures actual installed app/config module and app-class identities, profile environment/cwd/epoch and selector/execution facts and checks them after serialization/startup waits before issue, and after IPC before adoption. Preserve original source-specific application guards and final checked provenance; no coordinator lock across IPC. The command does not consume `_CONFIG_GENERATION`, `_CONFIG_CACHE` or `app.app_config`: do not freeze or recursively compare those mutable presentation/configuration values. Upstream chosen paths remain the exact public acquisition arguments; the original child checks freshly read selector bytes and registry, and original parent guards still validate their actual sources. This distinction preserves ordinary concurrent settings publication without replay or a new negative-evidence policy. Existing permission capture/currentness patterns are references, not permission-publication machinery to reuse. In particular, active permission/raw owners remain excluded and parent policy callbacks are not moved into child.

Task37's real `t37configb` control established the reason for this refinement: a normal actor-pack file read completed its native checks while another thread replaced the settings cache. A broad recursive cache snapshot incorrectly poisoned the resident owner although all actual implementation/ambient identities remained current. Restrict facts to the fixed command's actual dependencies; source replacement, epoch/pause, path selection and caller drift still refuse. The refinement removes newly introduced unrelated checks, not any original admission check.

The child executes original Python native/CRT operations and their normal audit events/rejections in **its own interpreter**, like the existing permission worker. Arbitrary parent audit hooks are not copied or transparently forwarded. No product integration requiring parent sys.addaudithook callbacks on these reads was identified. This is an explicit execution-boundary tradeoff, not an always-unknown selector or a new launch-wide audit inventory/capability subsystem. Installed application authority/custody/source callbacks and custom routes retain their original contracts.

## Process lifetime and implementation seams

Add `Backup_Recovery/admission_observation_process.py` for fixed selection, framing, parent custody/census and maintenance; `admission_observation_worker.py` for the fixed loop; and the small native custody implementation. Reuse `MCP.permission_process.read_message/write_message` and immutable identity framing only. Existing framing bounds chunk size/nesting, not total payload: the fixed decoder also validates request cardinality, paths, exact fields/types and bounds before projecting results. Reuse actual ProducerLifetime, ExecutorProcessTree and process adapter cleanup primitives; do not subclass permission publication or reproduce its mutation protocol.

Parent records process ownership before Popen, establishes containment before child product/native initialization, verifies the absolute interpreter and exact source/dependency origins, and uses isolated no-window launch. Boot imports the fixed command without config composition or startup enrollment. Explicit receipt/source-file reads and native initialization have boot custody; stdlib loader internals remain interpreter infrastructure. Ready requires boot retirement/source agreement, not just a frame. Every command still performs original installed qualification checks. Unexpected command-time imports or domain enrollment refuse.

One finite parent reservation spans queue wait, first-use startup, command exchange, receipt acknowledgment, postchecks and physical callback return. Repeated cancellation cannot retire the callback/token early. Withhold result adoption to cancelled/stale callers; settle the exact command/process before returning cancellation. Timeout/EOF/malformed result/source drift/uncertain retirement closes that generation's intake and retains unresolved identities. Terminate/await exact process tree; close actual issued pipes/process HANDLE/job handles and join monitor with explicit outcomes. Process poll plus `.closed` is insufficient.

Register this independent owner in runtime maintenance discovery, snapshots, close/drain/resume and pre-local-pause coverage. Include queued/initializing/active/unacknowledged/unresolved ownership. Close intake before drain; shut down idle healthy workers, then prove exact command/boot/process resource retirement before local pause. Explicit app exit/profile replacement performs the same shutdown; atexit is supplemental. A resumed healthy lifetime may start a fresh generation only after positive old retirement. Never repair a failed selected command by replacement/replay.

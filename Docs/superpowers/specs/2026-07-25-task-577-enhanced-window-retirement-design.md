## Scout verdicts (2026-07-25, two independent scouts — binding ground truths)

1. **The Console pipeline is fully independent of the legacy chat stack.** Send flow: `#console-send-message` → `ChatScreen.handle_console_send_message` (`chat_screen.py:11256`) → `_dispatch_console_draft_send` (`:11344`) → `ConsoleChatController.submit_draft` (`console_chat_controller.py:454`) → `console_provider_gateway.stream_chat` → `Chat_Functions.chat_api_call`; streaming renders via `ConsoleChatStore.append_stream_chunk` + a 0.2s poll into `ConsoleTranscript.set_messages`; persistence via `ChatPersistenceService`. Zero `chat_events` symbols anywhere in it.
2. **`ChatWindowEnhanced` is never instantiated** (`_ensure_chat_window` `chat_screen.py:2175` has zero callers) ⇒ the entire descendant tree is dead: `EnhancedSettingsSidebar`, all of `UI/Chat_Modules/`, `ChatTabContainer` → `ChatSession` → `ChatTabBar` → the `chat_events_tabs.py` wrappers → `Chat/tabs/`. `#console-chat-tabs` has **no composer** ⇒ `chat_screen._get_tab_container()` always returns None ⇒ its tab plumbing is unreachable.
3. **The legacy dispatch fabric is write-only**: `app.button_handler_map` (`app.py:3365`/`_build_handler_map:5210`) has zero readers; `TldwCli.on_button_pressed` no-ops in screen-nav mode; `_use_screen_navigation` is hard-`True` (`app.py:3133`) ⇒ `watch_current_tab`'s legacy body and `_execute_tab_switch` never run.
4. **The send stack is dead**: `handle_chat_send_button_pressed`/`handle_respond_for_me_button_pressed`/`handle_stop_chat_generation_pressed` are reachable only via the never-read map, CWE descendants, and the dead tab wrappers. Their button ids (`send-chat`, `stop-chat-generation`, bare `respond-for-me-button`, `send-stop-chat`) are composed nowhere live.
5. **Streaming events are dead**: `StreamingChunk`/`StreamDone` are posted only by `worker_events.chat_wrapper_function`, whose only path in is `app.chat_wrapper`, whose callers are `chat_events.py` (dead), `conv_char_events.py` CCP generators (CCP window unmounted; out of 577 scope), and `MediaWindow_v2.py:1569` (**liveness must be gate-proven, see Ambiguous Gates**). `chat_streaming_events.py` targets `#chat-log`/`#ccp-conversation-log`, composed nowhere.
6. **The `current_chat_*` reactives are never written by any live flow** (only writers: `chat_events.py` + the dead tab wrappers); the app-level watchers were already removed; `chat_screen.py:2063-2072` documents this in-code.
7. **More zero-importer orphans**: `Widgets/minimal_settings_sidebar.py`, the whole `Event_Handlers/tab_initializers/` package (nothing registers it — it is NOT the Console's init), `Event_Handlers/Chat_Events/chat_events_sidebar.py`, `Event_Handlers/sidebar_events.py` (from the 562 audit). The hot-path `_populate_chat_character_search_list` "error on every tab switch" is actually unreachable (its caller lives in `_execute_tab_switch`) — no live log spam; it deletes with the rest.
8. **Keep-set (LIVE — never touch):** `Chat_Events/chat_events_console_dictionaries.py`, `Chat_Events/chat_rag_events.py` (both imported by chat_screen), `Chat_Events/chat_token_events.py` (live-invoked by the 120s `db_status_manager` timer; functionally degenerate but out of scope this cycle), `Chat/chat_models.py::ChatSessionData` + `ConsoleChatSession` (live chat_screen importers), `Widgets/Chat_Widgets/chat_message_enhanced.py` + `chat_message.py` (widget classes referenced by app-level Action handlers — see Ambiguous Gates), `Chat/Chat_Functions.py`, the whole Console module family, `conv_char_events.py` (CCP stratum — out of scope; only its *import coupling* is handled, below).

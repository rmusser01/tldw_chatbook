1. A raw Character Bench sampler value can differ while normalizing to the same model value. Its later accepted input/context must survive; test alongside name and card/description state rather than relying on is_dirty alone (Task 1).
2. Character Save can publish after newer completed or lock-pending selection, or accept input during awaited rail replacement. Check applicability immediately before replacing the detail (Task 1).

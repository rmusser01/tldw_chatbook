## Packaging correction discovered during preparation

The initial wheel/sdist passed the old manifest gate, but a fresh wheel install
crashed importing `Web_Server.serve`: `static/mobile/index.html` was absent.
`include-package-data = false` meant MANIFEST.in's recursive sdist inclusion did
not put newer web files into wheels. Eleven files were missing: device/passkey/QR
scripts and provenance plus the seven mobile assets. The installed CLI smoke
had to use the existing private-child helper to isolate the complete profile;
a first attempt with only XDG/config overrides was inconclusive and is not
release evidence.

AC #4 and the task plan were expanded before implementing the fix. Add the
explicit asset paths to `pyproject.toml` and both checker contracts, allowing
only the exact vendored notice through the existing Markdown guard. Keep
MANIFEST.in's existing recursive inclusion. No web screen, runtime API,
dependency or ownership behavior changes; ADR-032 applies directly.

Two RED checks demonstrated the omitted wheel assets and acceptance of a source
archive with the mobile page removed. A follow-up correctly caught the vendored
notice needing the narrow Markdown allowance. The final affected check set
passed all 61 tests, including actual installed CLI/server `--help`, immutable
package verification and mobile-page removal from wheel and sdist. E9/F821,
ruff formatting, whitespace and Backlog readability/uniqueness checks passed.
Default Ruff checking also reported 13 findings, identical by file/rule/message
on unchanged dev; no new default-lint findings were introduced. Unrelated
import/style and exception-handling cleanups remain outside this release diff.
A second, fresh dependency-resolved Python 3.12 environment installed the
corrected committed wheel; `pip check` passed and both installed commands
returned help with exit 0 from separate initially absent private profiles.
The actual import resolved from that environment's site-packages and reported
runtime/distribution version 0.2.4. The complete corrected installed-distribution
run passed all 231 tests in 551.06 seconds using two isolated pytest workers:
`python -m pytest Tests/Packaging/test_installed_distribution.py -m integration
-n 2 -q -p no:cacheprovider`. This includes direct and sdist-rebuilt wheels,
real migration chains, archive corruption/removal controls, offline tokenizer
resources, immutable package ownership and both command entry points.

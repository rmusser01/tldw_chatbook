mosaic cell rounding/aspect and rejects letterboxing; resize retires the transform
without changing stored rectangles. The confirmation is explicit and fits narrow
terminals. Ready-made frame imports remain available.

controller's main action body. It reuses the source, editor/profile identity, native
connection ownership, settings revision and canonical prepared pixels. Saved recipes
are revalidated; unsupported settings allow confirmed reselection at their existing
CAS revision. Applied components are recovered only after complete pixel invariants.
Changed Save stops the exact draft sample and installs an immutable rest-only snapshot;
unchanged Save retains its revision/candidate/sample. Active DB artwork is untouched.
Apply forwards optional composition provenance, while successful manual import still
switches to ordinary six-frame readiness.

# Staged Console configuration handoff

Canonical Canvas background polls now cooperate with an already-owed Console configuration callback. Owed work alone grants no suppression. Suppression begins only at the original qualified warm or issued-read boundary; its current checked receipt then permits one guarded callback attempt. A generation-bound logical token protects that original CORE or identity attempt, including a busy refusal, and retires independently of the physical read. FULL activates CORE only; identity uses its own existing issued-read installation, including unchanged results. Lifecycle/source loss releases exact tokens without abandoning accepted native work.

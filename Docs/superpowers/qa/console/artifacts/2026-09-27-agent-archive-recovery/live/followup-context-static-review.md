The proposed native caller at package:117–121 supplies the authenticated capability's exact destination, and no untrusted caller was identified. Prefer deriving model-visible origin from an authenticated authority within the runtime/native path, or documenting/enforcing the method's trusted-caller precondition. This is hardening against future misuse, not a demonstrated model/JSON provenance bypass.
- **Unavailable workspace is mislabeled Default.** Package:88 uses “Default” whenever the workspace snapshot is absent, even when the retained row has a non-null `workspace_id`. Existing result UI distinguishes those cases. Preserve that distinction using the already-observed absence/ownership information, e.g. “Workspace unavailable” for non-null IDs without a snapshot; no raw workspace ID need be exported. The exact ref and final confirmation still prevent this display issue from redirecting restoration.
- **Clarify the byte-bound accounting boundary.** Package:110 checks the complete header/JSON block, but `console_chat_controller.py:22079` adds `Evidence: ` and separator text afterward. If “32 KiB whole envelope” is meant to include this transport wrapper, reserve that small fixed overhead or bound the final inserted rider.

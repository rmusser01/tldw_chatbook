### Important (Should Fix)

1. **A drained capacity wait cannot stop the active clock while the phase remains accepted.** `tldw_chatbook/DB/automatic_work.py:2164` treats every not-yet-claimed task as unsettled (`c.child_reservation_id IS NULL`), and the only interval-closing operation at `:2182` also completes the entire phase. For example, after task A has published and drained, task B can wait for a global slot/manual reserve with no live or uncertain owned operation. `settle_workflow_phase(..., drained=True)` refuses because B is unclaimed, so the open interval keeps charging this ordinary capacity wait and can exhaust the workflow. The accepted phase cannot instead be completed and replayed: remaining claims require acceptance. Add a durable quiescence/resumption seam in this ledger that retains phase acceptance and reservations, closes only after positive drain/no unsettled owned work, and reopens before subsequent attributable dispatch. Add an injected-clock test with a completed/drained task, an unlaunched task, a long capacity wait and subsequent dispatch; assert only execution time is charged. Host scheduling may remain Task 8.

2. **Revoked or unsuccessful planning has no valid drained-settlement path.** `tldw_chatbook/DB/automatic_work.py:2175` requires a plan for every planning settlement, then `:2193` publishes it using the attempt's old control revision. Pausing/revoking planning advances that revision (`tldw_chatbook/DB/workflow_runs.py:322`); even with all provider reservations settled and `drained=True`, publication fails CAS at `workflow_runs.py:280`, rolling back interval closure and phase retirement. Omitting the obsolete plan instead raises `planning_result_missing`; a provider failure that produces no plan has the same dead end. Thus physically drained cancelled/failed planning stays accepted/open and keeps consuming active time, and passive Stop/replan remains blocked by active evidence. Provide a terminal non-publication settlement for the exact accepted owner/attempt: preserve consumed charges and uncertainty, record durable cancellation/failure outcome, release only proven unused capacity, and close only on positive drain. Keep the current CAS requirement for successful publication so stale plans cannot become current. Add tests for accepted planning → pause/control advance → confirmed drain, and accepted planning → provider failure/no plan → confirmed drain, including rollback on settlement persistence failure.

**Locations:** [automatic_work.py:2321](/Users/macbook-dev/Documents/GitHub/tldw_chatbook/tldw_chatbook/DB/automatic_work.py:2321), [automatic_work.py:2393](/Users/macbook-dev/Documents/GitHub/tldw_chatbook/tldw_chatbook/DB/automatic_work.py:2393), [workflow_runs.py:977](/Users/macbook-dev/Documents/GitHub/tldw_chatbook/tldw_chatbook/DB/workflow_runs.py:977). For retained size R, new reservations S and decision bytes D, the implementation checks R + S and R + D. It needs to admit R + S + D. This is not a race between transactions; the omission exists inside one otherwise properly serialized transaction. The same branch accepts the original initial or remaining decision from the public coordinator's genuine native approval producer.

- New decision: 192 bytes.
- Admission error: none.
- Committed rows: one decision, one phase, one payload reservation.
- An immediate original _capacity(connection, workflow_id, 0) raises workflow_payload_capacity.

The expected-refusal assertion failed: **1 failed in 0.84s**. See [probe source](/Users/macbook-dev/Documents/GitHub/tldw_chatbook/.superpowers/sdd/2026-11-01-native-phased-agent-workflows-implementation/final-whole-capacity-probe.py), [raw log](/Users/macbook-dev/Documents/GitHub/tldw_chatbook/.superpowers/sdd/2026-11-01-native-phased-agent-workflows-implementation/final-whole-capacity-probe.log), and [JUnit](/Users/macbook-dev/Documents/GitHub/tldw_chatbook/.superpowers/sdd/2026-11-01-native-phased-agent-workflows-implementation/final-whole-capacity-probe.xml).

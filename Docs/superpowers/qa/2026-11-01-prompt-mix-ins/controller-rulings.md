# Controller rulings

Chronological decisions for the approved prompt mix-ins plan, including superseded intermediate decisions and their costs if wrong.

1. Required version-fenced writes refuse if the mutation API cannot honor the fence. This is within ADR-286 source compatibility, not a new user option or endpoint.

3. This supersedes the briefly proposed optional-field expansion before implementation.

4. 6. 7. 8. Fresh automatic origins default empty; continuations keep accepted custody.

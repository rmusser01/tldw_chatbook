- `execution_sessions.py`: lazy-import presenter follows the reviewed transcript adapter's original type, method, property and source checks. It checks actual App/screen/current mounted visit, exact client publication/view/source and nonfailed/nonclosing/nonfenced client. Under the existing screen lock, it queries the original surface, applies only an existing exact original acknowledgement owner's marker overlay, and awaits original `sync_sessions`. The exact publication, visit, lock, acknowledgement owner and queried surface are checked again after the await. Cancellation and exceptions retain the original finally counter decrement. There is no retry against a newer publication.

No screen/widget/style methods were changed or copied. The presenter never calls ensure/settings/workflow/fleet/coaching/local runtime/store/controller methods and creates no acknowledgement owner. Each must retain its original module function and definition, exact partial type, sole argument identical to the current screen, and no keywords. Neither callback is invoked; no ACK is created. A foreign-screen ACK or changed callback refuses.

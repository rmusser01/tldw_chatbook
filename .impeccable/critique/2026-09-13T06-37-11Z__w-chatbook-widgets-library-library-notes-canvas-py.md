## Priority Issues

- **[P0] The app exited during the first-timer's edit journey with an unhandled `InvalidSelectValueError`.** *Why*: a hard exit with no message is the worst thing a notes tool can do to a first-timer, and nothing on the profile says where it happened. *Evidence*: fresh-profile `tldw_cli_app.log:300` — `event=unhandled_exception component=app exception_type=InvalidSelectValueError` at 22:50:33, then screen unmounts and `app_stopping`; `faulthandler.log` empty; the tmux server died with it (capture 14 empty); the same keys replayed after relaunch did not reproduce (capture 16). *Cause*: crash **PROVEN**; site **INFERRED**. (1) `TldwCli._handle_exception` (`app.py:18225-18257`) persists only `type(error).__name__` and lets Textual print the traceback to stderr — the dead pane — so no site survives. (2) Textual 8.2.8 raises this only from `Select._validate_value`: any `select.value = X` with `X` outside the options, including the mount of a `Select(..., value=X)` composed with a value not in its options. (3) Every `Select` reachable inside Library ▸ Notes is guarded — the only one, `LibraryNoteFolderTargetDialog` (`library_note_folder_dialog.py:105-121`), inserts `("Top level", "")` whenever it passes `value=""`; the Search/RAG panel composes none. (4) The keystrokes did not reopen the note: F6 in Notes is `action_focus_next_workbench_pane` (`library_screen.py:8597`) whose targets (`:1433`) go preview region → rail `#library-search-input`; Escape then Enter there is a blank rail-search submit, which "still lands on the Search canvas" (`library_rag_search_controller.py:773-800`) — and the log shows `Media search completed` at 22:50:30, three seconds before the crash. (5) The one unguarded compose-time `Select` on the Console hand-off path from there is `Widgets/Console/console_model_popover.py:436-440`, `Select(provider_options, value=settings.provider)` with no membership check against `_provider_select_options()` and no blank guard for a no-provider draft — while the model select four lines down is guarded exactly this way (TASK-16502).

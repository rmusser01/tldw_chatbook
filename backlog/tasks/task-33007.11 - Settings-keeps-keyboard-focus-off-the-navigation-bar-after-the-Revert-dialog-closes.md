## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
In Settings, Esc releases a text field so the single-key shortcuts work (task-1560). Nothing is focused after that. Pressing r then opens the Discard changes dialog. When the dialog closes, keyboard focus lands on the app navigation bar's first button (Home), so a following Enter leaves Settings.

Measured on 2026-10-04 on the TASK-33007.9 branch, in a mounted Settings with the real stylesheet at 211x44. Focus landed on Home in all four cases: from the Provider control and from the Endpoint field on Providers & Models, closing the dialog with Discard changes and with Keep editing.

Cause: the screen resumes with nothing focused, and the framework then focuses the screen's first focusable widget. Settings names no widget of its own for that. The path is not specific to Providers & Models; any Settings field left with Esc takes it. Other Settings categories and other dialogs opened from Settings were not measured.

Found by the TASK-33007.9 review (finding M6). That task's change does not cause it, so it is filed on its own.

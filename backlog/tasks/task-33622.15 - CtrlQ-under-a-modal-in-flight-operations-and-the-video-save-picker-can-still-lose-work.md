## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Residual gaps found by the PR #2949 (TASK-33622.10) round-6 review. #2949 made Ctrl+Q a priority binding and gave every modal that guards its own close a confirm_quit. These cases remain:
- Modals that REFUSE to close while an operation is in flight have no confirm_quit, so Ctrl+Q quits past the operation: ConsoleForkChatModal while committing (console_fork_chat_modal.py ~406), ConsoleCapturePolicyDialog and ConsoleTracePrivacyDialog while applying (~809, ~1038), and ProjectSkillsImportModal mid-import (~276).
- While the generated video's Save-to-disk picker (EnhancedFileSave) or its Replace / Destination-changed confirmation is open, the capacity modal is already dismissed (UI/Console_Modules/video.py ~958-978). The quit walk finds no hook and the video is lost without asking. This matches today's design, where cancelling the picker also discards silently, so it needs an owner decision.
- Interview race: if Leave > Discard is already running, Ctrl+Q still asks 'Discard interview and quit?'. If the discard finishes under the quit prompt, the refused dismiss_safe_once is never retried, and after Continue the screen stays open and busy over a discarded draft.
Every review round on #2949 found more modal paths, so the durable fix is a census rather than one more modal.
<!-- SECTION:DESCRIPTION:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Ctrl+Q no longer quits past a modal's own close guard: in-flight modals answer "still working" and stay, the generated video's Save-to-disk screens ask before discarding it, the interview discard race closes once, and an AST census pins a Ctrl+Q decision for every guarded modal close.

- In-flight refusals (AC#1): `Widgets/quit_while_working.py` (`refuse_quit_while_working`: a warning toast "<activity> Quit again once it finishes.", returns Stay, pushes no prompt). Lazily imported from `confirm_quit` on ConsoleForkChatModal (committing), ConsoleCapturePolicyDialog / ConsoleTracePrivacyDialog (`_applying`), ProjectSkillsImportModal (`_import_in_flight()`): each refuses on exactly the condition its own Escape refuses on.
- Video picker (AC#2, quit hook chosen over a docs-only decision): `Widgets/Console/console_video_save_screens.py` subclasses EnhancedFileSave / ConfirmationDialog with a `confirm_quit` that asks the capacity modal's own "Discard generated video and quit?" (shared as `confirm_quit_discarding_generated_video`); `UI/Console_Modules/video.py` pushes them for the picker and the Replace / Destination-changed confirmations (imported only on Save to disk).
- Interview race (AC#3): `ProfileInterviewScreen` tracks the running terminal operation (`_closing_activity`: discard, cancelled-start discard, cleanup retry); `confirm_quit` answers "still working" instead of asking "Discard interview and quit?" while it runs. Every terminal close goes through `_close_with`; a close refused while covered is kept and finished in `on_screen_resume` (the mixin's documented one-shot pattern), so the screen never stays open and busy over a discarded draft.
- Census (AC#4): `Tests/Architecture/test_guarded_modal_quit_census.py` scans every ModalScreen's Escape / `_perform_safe_cancel` entry for a path that returns open or pushes a prompt, keyed where the guard is written; each row is CONFIRM_QUIT (hook required on every inheriting modal) or an exemption with a reason. Fails on a new unrecorded guard, a stale row, or a hookless CONFIRM_QUIT modal; fixture negative controls plus a live-reach control. The census is best-effort, as its docstring says: a guard written only in a Button handler or an `on_key` override, or a dismissal through a helper outside the class, is not seen and stays a review item.
- AC#5 was added during implementation (scope note for review): the census found nine more modals that refuse to close mid-operation or guard unsaved edits (exchange/trace export, prompt collection manager, buddy character review, both personal-context review modals, Watchlists bulk sources, session switcher mid-commit, model popover edits); each got the same one-flag `confirm_quit`. Five exemptions are recorded with reasons (picker overlays, trajectory viewer, review notes, first-run settling dialog).
- Choke point: `test_quit_flow_prompt_choke_point.py` now scans module-level quit helpers in every hook module (the new delegates included). Prompts go through `await_quit_prompt` only.
- `test_console_modal_dismissal.py`: the reachable-modal pin was stale on dev (measured 51 at f0ffcf9e81 by a probe, not 49; unreachable behind an inventory assertion that already fails on dev for unrelated modals); now 53 with the two new screens.
- Docs: User Guide index (Ctrl+Q row), console.md (model popover), console/video.md, console/branching-and-rewind.md, settings/personal-context-profile.md.

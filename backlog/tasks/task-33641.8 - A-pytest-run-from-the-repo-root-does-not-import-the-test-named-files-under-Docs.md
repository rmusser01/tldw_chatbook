## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
A pytest run that collects from the repository root (an empty argument, or 'pytest .') imports three tracked test-named files under Docs/ with no test isolation in force: no conftest.py covers them. Docs/Development/test_logits_openai.py imports tldw_chatbook.config at module level and its test calls a paid provider with the configured key; Docs/superpowers/qa/2026-10-03-console-chat-starts-dev-integration/latest_predispatch_test.py is a patch script that rewrites a tracked test file when imported with the root as the working directory; Docs/superpowers/qa/2026-09-16-ingest-lifecycle/test_profile_guard.py executes a native check at import. On 2026-10-10 a Phase 9 agent's run did this by accident (zsh read "$T[id]" as a subscript and passed pytest empty arguments): the first file's import ran the startup admission against the real profile, which refused. pyproject.toml has testpaths = ["Tests"] and --ignore=STests and nothing that excludes Docs. Measured by that agent on a toy tree with pytest 8.4.2: with --ignore=Docs in addopts, an empty argument and '.' import neither file, and an explicit path to a file under Docs still runs.

## Implementation Notes

<!-- SECTION:IMPLEMENTATION_NOTES:BEGIN -->
Phase 9, plan Task 14 (Wave 5); base 0af11c2871.

**Fix.** `pyproject.toml`'s pytest `addopts` carries `--ignore=Docs` beside `--ignore=STests`, with a comment naming why and the pinning test.

**Test (AC#1, AC#2).** `Tests/CI/test_pytest_root_collection_skips_docs.py` runs pytest at the real repository root, `--collect-only --noconftest -p no:python` with a small recorder plugin (written to `tmp_path`) that notes every file the collection visits under `Docs/`. With the python plugin and every conftest off, nothing there is imported even if the guard is gone. `test_a_root_run_visits_nothing_under_docs[empty-argument]` and `[dot]` assert that the visit list is empty; `test_an_explicit_path_under_docs_is_still_collected` asserts that `Docs/Development/test_logits_openai.py` given by path is still visited. Red first at the base: both root nodes listed all 17,093 files under `Docs/` (`3 failed` with the first version, whose explicit-path assertion wrongly expected the file alone; collection lists each directory on the way down, so siblings appear, and the assertion is now membership). Green after the fix: `3 passed in 2.72s`. The file is in `Tests/CI`, which the PR Fast Lane's sandboxed step runs whole, so it needs no new lane entry.

**Lesson (AC#3).** The existing entry in `backlog/docs/lessons-testing-evidence.md` (the node-id trap in another form, TASK-33641.3) gains a paragraph naming the guard and its test, and the limit already measured there: the option resolves from where pytest starts, so a run started inside `Tests/` is not covered.

Files: pyproject.toml, Tests/CI/test_pytest_root_collection_skips_docs.py, backlog/docs/lessons-testing-evidence.md.

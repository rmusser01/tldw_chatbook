## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
TASK-33621.4's delta-review fix remembers the agent's tool cost (schemas plus fenced prompt text) per tool configuration. The configuration signature covers the model, the `[tools]` gates, the `[mcp]` config section and the Console's agent and local-tool settings, all read from in-memory config. MCP servers added, removed or enabled in the hub live in the local MCP store, and reading that would need a store read (a file stat) on the UI loop. So a server change keeps the old figure until the next send, which can read Ready while a bigger tool set holds. Needs an in-memory revision that the MCP hub bumps on server changes, which the display can read cheaply.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The Model view puts setup ahead of tuning. Connection comes first, and it is about 25 rows at 211x44 (verified-claims C5(4)). Every tuning field then sits inside the 'Advanced generation' Collapsible (console_settings_modal.py:1954-1960).

That order was set by TASK-30012 AC#1 and is pinned by Tests/UI/test_console_session_settings.py:13764 test_console_settings_modal_connection_first_hierarchy_and_title. In the review, a power user needed 45 actions for a switch-and-tune task, including Tab ×13 to reach Apply (report.md).

Streaming is a toggle Button (:2020-2034), although ADR-095:79 makes chat-scope streaming a plain On/Off choice. Labels drift from the other surfaces ('Response max tokens', 'Budget', 'Summary').

The judge's rule 2 gives every editor one row grammar: Label | one-row control sized to its value type | Source word | help line. The Source words and their resolver already exist since Switch model (phase 4); this modal must reuse them rather than keep its own mapping. Spec §6 also requires values, not placeholders: an empty field shows what it inherits. The review measured placeholders at 2.8-3.5:1 and found them indistinguishable from values, and spec §6 puts help and Source text at 4.5:1 or better.

The wide tier (85% capped at 196 columns, _console_panels.tcss:192-203) is pinned by Tests/UI/test_console_settings_geometry.py:62, :168 and :214. The mock is 150 columns.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Chat settings' Model view now opens core-first with one field-row grammar.

**Approach**
- New module `Widgets/Console/console_settings_field_row.py` (no ratchet row; R1) holds the row builder, the MODEL row, the Source-word/help sync, the per-view open-focus helper (R13) and the disclosure handlers, as `ConsoleSettingsFieldRowsMixin`. The modal keeps only the wiring and shrinks 7,751 -> 7,516 lines; its ratchet row is lowered to 7,516 (the slack test would otherwise fail).
- Layout: scope line, MODEL row (model · provider · readiness word), CORE rows (Temperature, Max tokens, Streaming, then the reasoning/thinking controls; unsupported ones stay hidden by the existing support sync), then one-row disclosures Sampling (Top P, Min P, Top K, Seed, Presence penalty, Frequency penalty), Connection (the existing block, unchanged inside), Request estimate and "Your name in this chat". Advanced generation is gone; every field keeps its id.
- Row grammar: Label (18, Model view only; the shared 23-cell label stays for Connection and the Context view, R5) | control sized by type (numbers 12, Streaming 8, choice Selects as before) | Source word (20) | one help line from `MODEL_CONFIG_FIELDS` (ellipsis, never a second row). Source words come from `resolve_console_value_layers` + `CONSOLE_VALUE_SOURCE_WORDS`; the edited set is the P3 unsaved guard's, and the resolver reruns only when the pair or the edited set changes.
- Values, not placeholders: a blank optional field's help reads "blank = provider default · …"; a blank Temperature/Top P names its range; the name field's placeholder became help copy.
- Streaming is an On/Off Select showing the effective value; `_streaming_draft` stays tri-state until a pick (R15).
- Focus opens on Temperature; while a connection blocker stands (anything but none/active run) Connection opens at compose and the recovery action takes focus (R6/R13). A restored focus target still wins; a missing or unavailable one falls back to Connection exactly as before (TASK-30012), in either view, so the Context and memory view's restore tests stay unchanged (AC#11). A focus that lands inside a closed disclosure opens it. Tab order: view tabs, the body in DOM order (closed contents and hidden rows are skipped), footer.
- Geometry: `#console-settings-modal` is `$ds-size-150` x `$ds-size-22`, both capped at `$ds-percent-95`, no vertical padding; the Context view keeps its 94% height through a `-context-view` class (AC#11). The 196 wide tier, its token, its `App.-wide-viewport` rule and the Python toggle are removed; the wide-tier registry lists the modal as a fixed-token skip. Inside the modal, disclosures have no margin and their Contents no padding.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
**Impact.** With Anthropic claude-haiku-4-5 selected, staging an image makes the composer strip read 'leaf.png - 116 B  Send blocked - choose a model to continue >', while the status bar says 'Model: claude-haiku-4-5'. Clicking the '>' link opens the full-screen first-run wizard ('Set up tldw chatbook', Step 1 of 6). The user can back out with Esc → Tab → Skip setup, and the draft survives, but the link sends an already set-up user to the wrong place.

Haiku 4.5 does accept images: a live probe returned the correct colour for a 32x32 PNG. The vision table (`model_capabilities.py` DEFAULT_MODEL_PATTERNS and the shipped config template) covers claude-3*, *opus-4*, *sonnet-4* and claude-sonnet-5. It misses claude-haiku-4-5, claude-opus-5 and claude-fable-5, all of which are in the shipped Anthropic model list.

The accurate vision copy ('claude-haiku-4-5 can't accept images. Remove the attachment, switch to a vision model, or ...') travels in the `setup_blocked_reason` slot. `build_console_disabled_reason` matches the substring 'model' and rewrites it to the generic line. The setup-blocked class then turns the strip into an `app.run_setup_wizard` link. The accurate text survives only in the Send tooltip and in a System row shown after Enter.

**Severity / prior art.** P1, NEW (verified live and by the skeptic as PARTIAL, confirmed in code). Related Done tasks: TASK-21145, TASK-2154.12 (its lesson: test the classifier with the verbatim reason string), TASK-2154.6, TASK-26023, TASK-335, TASK-869. This is one case of the Theme 0 'untyped blocker slot'. The umbrella task owns the typed-blocker model; this task fixes the capability data and the vision block's own presentation.

**Suggested direction.** Fix the capability data, preferably with a family rule: tier-first-named Claude families with major version 4 or higher accept images. Make it reach users whose config.toml carries the old patterns block, which replaces the defaults wholesale. Give attachment blocks their own slot, with 'Remove image' and 'Switch model' actions next to the chip. Keep the setup-wizard link for genuine readiness blockers only.

Evidence: qa/console-ux-review-2026-09-29/findings.md → G4-09 (source J4-03). Code refs: tldw_chatbook/model_capabilities.py:44-48, tldw_chatbook/Chat/attachment_core.py:413-442, tldw_chatbook/Chat/console_display_state.py:293-296.

Review finding ids: G4-09 — see qa/console-ux-review-2026-09-29/findings.md.

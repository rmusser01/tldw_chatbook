## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The Google and Cohere streaming translators drop the provider's usage block -- the only usage read in the provider module is on the non-streaming response, and the Cohere stream's `message-end` handler maps the finish reason without extracting usage. The gateway records usage only from stream chunks and has no final-usage fallback, so streamed turns from those two providers record no token counts or cost at all.

## Findings this closes

- **P1 [D1]** (LLM) Google and Cohere streaming handlers drop the provider's usage block; the gateway records usage only from SSE chunks, so streamed Gemini/Cohere turns carry no token counts or cost
  - Where: google `tldw_chatbook/LLM_Calls/LLM_API_Calls.py:3798-3921` (the SSE→OpenAI translator reads `candidates` only; `usageMetadata`, present on every Gemini stream chunk, is never emitted); cohere `:2832-2846` (`message-end` carries `delta.finish_reason` AND `usage`; only `finish_reason` is forwarded).

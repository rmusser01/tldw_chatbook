## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Found in TASK-33621.50's review. If a MiniMax task succeeds between two polls and the user presses Stop before the next poll, the adapter's cancel DELETE reaches a finished task. MiniMax answers 200 action=deleted (recorded live 2026-10-30): it deletes the task's record, so a clip that is already billed is thrown away. The Console then says MiniMax did not confirm the cancel and that the task may keep running, which is wrong: the task has finished and, if it succeeded, has been billed. The DELETE predates TASK-33621.50.
<!-- SECTION:DESCRIPTION:END -->

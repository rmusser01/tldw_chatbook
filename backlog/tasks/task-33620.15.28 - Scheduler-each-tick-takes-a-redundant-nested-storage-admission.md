## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Found reviewing TASK-33620.15.24. Every scheduler admission is now two worker hops (enter and release). A regular tick takes run()'s per-tick admission and then tick()'s own nested admission (_admitted_dispatch), so four hops, plus the emergency-stop and heartbeat hops; each due reminder adds two more (dispatch_reminder). The nested admission under an admission run() already holds adds wall time to every tick and competes for the default to_thread pool with every other offload in the app.
<!-- SECTION:DESCRIPTION:END -->

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Why: Raised by the Task 8b first review (R0, I-3; TASK-34000.29 N-29 Delete forever) and carried as follow-up (i). Delete forever refuses a note that a sync folder holds (`Notes/notes_scope_service.py:1893-1895`) with "This note is kept in sync with a folder, so it can't be deleted forever here." (`PURGE_REFUSED_SYNC_BOUND` :96). The sentence names no way out because there is none in this release: the runtime's `disconnect_root` is blocked (`Notes/notes_sync_runtime.py:4846-4849`), Manage sync folders prints "Retarget/Disconnect unavailable — not in this release" (`Widgets/Library/library_notes_sync_roots_canvas.py:137`), and a deletion review's Disconnect item is painted disabled. So a user who put a note under folder sync and later wants it gone for good (a private note, a mistake) can only leave it in Recently deleted. The refusal is honest and safe; it is a dead end, and the owner ruled it acceptable for this release (ruling T8b-c).

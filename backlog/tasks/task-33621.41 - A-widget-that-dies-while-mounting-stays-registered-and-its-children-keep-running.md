## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
From the PR #2944/#2945 round-4 review, follow-up to #2944's app_keep_alive (TASK-33621.13). retire_dead_pump returns 'widget' for a widget whose message loop ended in _pre_process (it raised in on_mount). _move_focus_off_dead_widget only moves focus. Textual 8.2.8 skips _message_loop_exit for that widget, so it stays attached and in app._registry, and its already-mounted children keep running. Probe P6: a container composes a ticking child, then raises in on_mount inside a live screen; afterwards the child's timer still ticks. #2944 fixed the same gap for SCREENS (_finish_unmounted_screen); widgets need the equivalent teardown (stop timers, clear watchers, _message_loop_exit, cancel workers) without disturbing the live screen around them.

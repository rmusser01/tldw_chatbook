## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Resolve Safe or Full once at accepted Console turn admission and carry that immutable detail through the existing run signals and provider gateway so one-shot conversation and global policy behave deterministically across all provider-call shapes.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Kill switch next-send conversation global and Safe-default precedence resolve deterministically and invalid values fail Safe.
- [ ] #2 One-shot detail is consumed only by an admitted manual or authorized queued human turn with pre-admission cancellation preserving it and post-admission cancellation consuming it.
- [ ] #3 Autonomous wakeups neither use nor consume the one-shot override.
- [ ] #4 Frozen detail reaches direct calls agent tool loops retries and surviving fleet calls without changing an admitted run.
- [ ] #5 Anthropic generic and llama.cpp paths retain the approved Safe or Full semantic content while capture failures never fail the model run.
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Add failing admission/consumption tests for manual, authorized queue, wake, rejection, cancellation, local command, and re-arm races.
2. Implement exact-revision session policy state, repository hydration/promotion behavior, and one-shot disarm semantics.
3. Resolve and consume policy exactly once after accepted owner admission and freeze the result on stream/call signals across durable continuations.
4. Thread frozen detail and the shared capture budget through generic, Anthropic, llama.cpp, retry, tool-loop, and surviving fleet paths with content-free failure logging.
5. Implement the canonical structured global capture mutation lifecycle, kill-switch one-shot disarm, stale-generation behavior, and Safe/Full publication ordering.
6. Run the focused controller/store/provider/config gates, perform static/privacy self-review, then close the child only after independent review.

## Description

Give policy editing, manual search, and staged/cited source review separate,
truthful Console surfaces that remain usable at narrow terminal widths.

## Acceptance Criteria

- [ ] One fixed-order two-axis chip renders the four policy combinations and
      an explicit unavailable state without absorbing readiness or source count.
- [ ] A Library Access modal uses text-valued controls, local/not-synced and
      provider disclosures, explicit Save/Cancel, distinct saved/missing/temp
      state, CAS conflict recovery, persistent errors, and dirty safe dismissal.
- [ ] Canonical F9 Settings exposes Never/Automatic and Blocked/Allowed as
      **New Console conversations** defaults with config-template/schema
      round-trip, keeps Direct/RAG separate, and adds nothing to deprecated
      Settings surfaces.
- [ ] A separate Search Library modal always prefills the exact composer draft,
      removes the query heuristic, labels source filters “This search only,”
      and never mutates standing policy.
- [ ] Staged/cited source lists render one primary row per source with details
      behind activation and use the fixed Sources/Cited sources terminology.
- [ ] Dynamic content renders literally, including adjacent recovery paths;
      keyboard, focus, text-labeled state, disabled reasons, idempotent repeated
      actions, and opener restoration are explicit.
- [ ] Production-bundle render tests at standard and narrow viewports prove
      action containment, scrolling, stacking, painted labels, safe
      Escape/backdrop behavior, and containment for expanded, CJK, emoji,
      combining-mark, and RTL-shaped text.

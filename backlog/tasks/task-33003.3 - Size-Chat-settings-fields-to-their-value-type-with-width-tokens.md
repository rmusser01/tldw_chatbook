## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
At 211 columns, the short numeric inputs in Chat settings are about 125 columns wide. Controls fill up to 75% of a modal that is itself 85% of the viewport (css/features/_console_panels.tcss:77-81 and :200-203; C5, corrected statement). A 4-character value in a 125-column field wastes the width that help and source text need, and it makes the eye travel. ADR-161 spec 3.10 says a value with real semantic weight graduates to a named token, and raw dimension literals are banned outside css/core/_variables.tcss (Tests/UI/test_component_pattern_governance.py:266-289).
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 At 211x44 and 235x52, numeric fields in Chat settings are at most 12 columns wide, edge included. This covers Temperature, Top P, Min P, Top K, Max tokens, Seed, the penalties, the budgets and the context limits.
- [x] #2 Each enum Select is no wider than its longest option plus the arrow.
- [x] #3 No free-text field (model id, URL, env var name) is wider than 64 columns.
- [x] #4 Field widths are the same at 211 and 235 columns: they are sized by value type, not as a percentage of the viewport.
- [x] #5 Every width comes from a named token defined only in css/core/_variables.tcss. test_dimension_literal_ratchet and test_python_style_ratchet stay at zero.
- [x] #6 A 211x44 live capture of the Model view is attached to the task notes.
<!-- AC:END -->
## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Probe every shown field's width under APP_STYLESHEETS at 211x44 and 235x52 (before numbers).
2. Write the failing rendered test: numbers <= 12 (edge included), each enum Select = its longest option + arrow with no crop, free text <= 64, widths equal across the two sizes, numeric hints fit their field.
3. Size the fields in features/_console_panels.tcss from the $ds-size-N scale: numbers by their section containers, enum Selects by id, free text capped by type with `1fr` kept for narrow terminals.
4. Keep the boot CSS byte budget (ADR-097) from rising: pay for the new rules by deleting dead rules for retired Console widgets.
5. Rebuild the bundle; update the Console User Guide; live-verify both sizes on a scratch profile; regression-compare against the task base; preflight.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
**Approach.** Chat settings fields now follow spec §6's row grammar: a field is as wide as the value it holds, edge included, never a share of the viewport. All widths live in `features/_console_panels.tcss` and come from the `$ds-size-N` scale in `core/_variables.tcss`. No Python layout code changed.
- **Numbers, 12 columns.** Every Input inside `#console-settings-generation-advanced` and `#console-settings-context-view` holds a number, so two container selectors cover all 13: Temperature, Top P, Min P, Top K, Max tokens, Seed, both penalties, Thinking budget, Conversation max tokens, Compact at (%), Reduce context to (%) and Summary response max.
- **Enum Selects, longest option + 5.** Each Select is sized by id to its longest option or blank prompt, plus 5 cells: the edge, one padding cell on each side, and the arrow with its gap. Verbosity and Thinking effort are 11, Reasoning effort and History policy 12, Reasoning summary 13, Budget strategy and When limit nears 14, Representation 22, If compaction fails 23, Keep after compaction 32.
- **Free text, capped by type.** These keep `1fr`, so they still give way in a narrow terminal (80x24 stays green in `test_console_settings_geometry`), with a `max-width` cap: Your name in this chat 32, the provider and model pickers 48, the endpoint URL 64. Chat settings has no env-var-name field.
- **Hint copy.** The Conversation max tokens hint "Required in Custom mode" became "if Custom". In a 12-column field (9 content cells) the old hint cropped to "Required", which is false in Automatic mode.
- **Boot CSS budget (ADR-097).** At the task base the census was 607,968 B of 608,090 B: 122 bytes of room. The new rules use bare ids with no `ConsoleSettingsModal` prefix. They are paid for by deleting dead rules for four retired Console widgets, each already proven absent by an existing test: `#console-workspace-tree-selection-context` and `#console-workspace-tree-star` (`test_contextual_star_button_and_selection_line_are_retired`), both `#console-chat-tabs` rules (`test_console_gate15_does_not_mount_full_legacy_chat_window_chrome`), and `#console-model-section-provider/-model .console-model-section-value` (`test_model_section_does_not_repeat_provider_and_model`). Net bundle change is +12 B, giving 607,980 B.

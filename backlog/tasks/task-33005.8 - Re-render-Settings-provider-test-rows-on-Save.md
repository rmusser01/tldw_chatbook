After Save, the Test rows show the saved values on the same visit.

- `action_settings_save_category`, Providers & Models' fully applied branch: when the save changed a connection field (`setup_mutation` is set), `rebase_after_save` carried the evidence to the saved identity, and the rows are not one of the two sentinel copies, `_provider_test_result` is rebuilt with `_run_provider_readiness_test()` after the draft is popped, so no row reads "(draft)", and `_update_provider_test_result()` repaints the result grid, the Key check row and the Inspector identity row.

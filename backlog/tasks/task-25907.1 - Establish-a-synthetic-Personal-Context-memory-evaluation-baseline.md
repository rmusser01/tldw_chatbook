## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Make changes to memory retrieval and explanation measurable using synthetic, source-labelled conversations and profile records, without collecting real user data or requiring a paid provider.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 A deterministic synthetic fixture set covers lexical and paraphrased queries, workspace exceptions, changed preferences, absent or ambiguous evidence, empty relevant sets, and deleted or user-only records.
- [x] #2 The offline baseline separately reports fixed-K precision, recall and reciprocal rank for relevant eligible search records; expected context selection and budget behavior; metadata-status checks where implemented; and unauthorized disclosure failures.
- [x] #3 Offline checks invoke production selection and profile-tool paths; direct lookup bypasses cannot satisfy recall checks, and negative authority cases have successful authorized controls.
- [x] #4 Development and held-out regression cases are frozen before retrieval changes; current misses and per-category results are retained rather than hidden by aggregate scores or weakened assertions.
- [x] #5 Fixtures, independent relevance labels, K values, scoring rules, baseline command and work bounds are documented; empty relevant sets use false-positive measures rather than fabricated recall.
- [x] #6 No provider calls, real user data or full-suite run are required; generated-answer quality and semantic support are explicitly unmeasured, and missing provenance UI behavior is not replaced with a duplicate production implementation.
<!-- AC:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Established an offline, test-owned baseline using 24 frozen synthetic cases, real encrypted repositories, and production service/tool/snapshot paths. The runner reports independent fixed-K relevance metrics, authority checks, exact context packing, retained metadata and policy gaps. Exclusive JSON output cannot replace prior evidence and hashes the exact bounded fixture bytes used.

Measured results: recall 0.8 in both partitions; four misses (reordering, paraphrase, German and Japanese text), one metadata-only false positive. No harness, live-authority or context errors. Both existing policy gaps remain explicitly failed; this task does not change application behavior or permission policy.

Validation: 96 targeted tests passed in 681.43 seconds; two reports from fresh temporary repositories matched the committed candidate. Ruff check/format and whitespace checks passed.

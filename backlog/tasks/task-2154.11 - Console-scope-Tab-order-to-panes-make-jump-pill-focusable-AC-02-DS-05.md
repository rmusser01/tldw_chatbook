## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Tab is now scoped to Console regions; F6 keeps the pane cycle; the jump pill is keyboard-focusable and Enter/Space-activatable.

Approach:
- `chat_screen.py`: new `CONSOLE_TAB_REGIONS` pairs shell widgets into four Tab regions (control bar+composer, left handle+rail, transcript region+chips, right handle+rail). `action_focus_next`/`action_focus_previous` keep the slash-popup accept and setup-modal trap first, then call Textual's selector-filtered `focus_next(selector)`/`focus_previous(selector)` so the cycle wraps inside the focused widget's region and never crosses the 15 app-nav buttons. Focus sitting in app chrome (clicked nav button) keeps the default app-wide chain; nothing focused lands on the composer home. New `CONSOLE_FOCUS_PANE_FOR_WIDGET` maps the between-pane widgets (control bar, chips, rail handles) to their logical pane so F6 from them continues the cycle instead of restarting at pane 0. Help panel "Panes" group gained `Tab / Shift+Tab: cycle within the current pane`.
- `console_transcript.py`: `ConsoleTranscriptJumpPill` is `can_focus = True` and activates via `on_key` (Enter/Space), NOT BINDINGS -- a Key event bubbles to `ConsoleTranscript.on_key`, which stops `enter` before App-level binding dispatch would consult the pill's bindings (same idiom as `ConsoleTranscriptActionButton.on_key`). Keyboard activation jumps, then focuses the transcript (the jump hides the pill itself).
- CSS: `.console-transcript-jump-pill:focus` (outline:none + bold underline; resting style already uses focus colors) added to `_agentic_terminal.tcss`; `tldw_cli_modular.tcss` regenerated with `build_css.py` (the rebuild also folded already-pending sibling 2154.x component edits into the bundle -- build is idempotent).
- Spec doc `2026-07-02-console-dual-audience-ux-design.md` keyboard section now documents pane-local Tab.

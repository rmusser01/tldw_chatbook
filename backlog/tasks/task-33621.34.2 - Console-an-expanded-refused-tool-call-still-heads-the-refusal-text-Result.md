## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Found by TASK-33621.34's live check (2026-11-22, real claude-haiku-4-5, a `create_note` call denied on its approval card). The marker reads `create_note · Denied by you`, and its expand button reads "Sent to the model". Expanding it shows the call's detail box, which reads "Denied", "Arguments", then **Result** above "tool call denied by the user: create_note. Do not retry this call, do not rephrase it, …". The heading comes from `format_tool_activity_detail` in `Chat/console_tool_activity.py`, which writes "Result" (or "Live output" while running) for every call-id tool marker whatever its status.

This is the misreading TASK-32279 fixed for the button, one level down: the text under "Result" is the instruction the model received, not anything the tool produced. The Docs/User_Guide page (`console/agent-runs-and-tools.md`, "After you decide") says expanding a refused row shows the refusal text the model was given, so the heading contradicts the guide.

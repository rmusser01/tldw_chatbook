## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Slice D6 (spec §5.6, owner ruling Q6). The note editor shows `[title](media://…)` and `[[Title]](note://…)` links as `title ↗`. The raw Markdown appears only while the caret is inside the link. Copying and saving always use the raw text. Without this, a narrow working note fills with 36-character UUID links that wrap over several lines.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Media and note links render as `title ↗` in the editor and expand to raw Markdown while the caret is inside the link
- [ ] #2 Saved note bodies and clipboard copies contain the raw Markdown byte-for-byte
- [ ] #3 Cursor movement, selection and undo behave correctly across a tidy link (no caret jumps, no lost characters)
- [ ] #4 Pilot tests fail on dev before the change; verified live at 120x36 and 160x45
<!-- AC:END -->

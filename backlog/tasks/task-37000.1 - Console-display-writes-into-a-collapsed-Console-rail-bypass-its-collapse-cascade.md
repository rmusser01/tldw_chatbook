## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Found by TASK-37000 (2026-10-27). The collapse cascade (ChatScreen._sync_console_rail_descendant_visibility) hides every descendant of a collapsed Console rail, the Context rail and the Inspector rail alike, and records the display each had; the rail's opening restores that record. A direct display write inside the hidden rail shows the widget in a rail nobody sees, asks for a whole-screen layout, and is then undone by the opening, which restores the display recorded at the collapse. TASK-37000 routed the Agents section's write through set_display_under_console_rail (it lost the section after a first send). Other writes of the same shape remain. In the Inspector rail: the Environment and Tasks sections' display after an environment landing (ChatScreen._land_console_environment), ConsoleSelectedTurnActivity.sync_state's own display, and ConsoleInspectorSection.set_open's body and summary display. In the Context rail, found by TASK-37000's review: ChatScreen._sync_console_agent_section writes the fleet summary line, the drill-down Back button, View full log, Cancel all and the agent section body straight to styles.display, so for example Cancel all is missing after the Context rail opens during a live sub-agent run that started while it was collapsed. None is on a send's path, so TASK-37000 left them.

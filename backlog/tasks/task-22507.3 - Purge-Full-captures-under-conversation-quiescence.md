## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Provide an immutable-conversation count and logical deletion path for Full exchange records that coordinates every live and durable writer so deleted captures cannot reappear or leak through stale Inspector state.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Full capture counts and deletion cover active off-path abandoned and soft-deleted messages by immutable conversation ID while Safe captures messages usage policy exports and backups remain unchanged.
- [x] #2 Purge is available only under a controller-owned quiescence lease that blocks admission and flush and accounts for primary fleet retained-signal and in-flight writers.
- [x] #3 Database failure before commit leaves durable and live state unchanged while commit is followed only by authoritative staged swaps and capture-revision advance.
- [x] #4 Ephemeral sessions receive the same staged purge and cache invalidation contract without database writes.
- [x] #5 Stale expansion clipboard and file-export actions fail closed after the capture revision changes and later flushes cannot recreate deleted rows.
<!-- AC:END -->

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Found in review of TASK-33620.15.5. The ADR-097 screen pre-import payload budget (Tests/Performance/test_screen_preimport_payload_budget.py) walks only the speculative screen routes. Since TASK-33620.15.5 the post-UI-ready pre-import pass first imports the Console's first-send modules (Chat/console_first_send_modules.py, about 70 modules and what they import, about 213 ms CPU in a fresh interpreter), and none of that is counted.

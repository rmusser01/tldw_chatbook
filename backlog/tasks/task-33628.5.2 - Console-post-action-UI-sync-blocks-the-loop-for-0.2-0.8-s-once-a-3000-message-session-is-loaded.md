## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Found while measuring TASK-33628.5 (ConsoleHarness + file-backed DB, branch fix/task-33628.5-delete-off-ui-thread). With a conversation holding 3,000 messages on a branch that is not on the active path, so the transcript shows four rows, merely arming a Delete (a status-only Console sync, no database write) blocked the event loop for 0.20-0.84 s at its worst and 0.64-1.55 s in total across three runs. After TASK-33628.5 the Delete and Undo themselves cost about 25 ms on the loop at that size; the 0.1-0.46 s loop blocks that remain around them are this same sync (_sync_native_console_chat_ui at 0.19-0.62 s per call; stack samples put most of it in _sync_console_rail_and_controls / _run_console_config_sync and compositor renders). The figures above came from a throwaway probe that was not committed; TASK-33628.5's notes record the loop-block ranges around Delete and Undo measured on both arms after that task (n=6).

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Found by the TASK-33628.2 review (PR #2941). console_delete_scope counts store.subtree_message_ids, while CharactersRAGDB.soft_delete_message_subtree tombstones by a recursive parent CTE. The store skips role='tool' rows, hydration drops empty rows, and legacy flat roots are chained in memory, so 'Delete N messages' and 'Deleted N messages' can understate what is removed. A review probe tombstoned 6 rows while the scope counted fewer.

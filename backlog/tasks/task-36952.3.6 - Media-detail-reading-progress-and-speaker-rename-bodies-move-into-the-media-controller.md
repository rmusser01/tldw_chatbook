## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The media detail load, the reading-progress capture and restore queue, and the speaker-rename facts still run on LibraryScreen behind eight controller callbacks, and three tests patch the detail load on the screen class. Moving them gives the reader's data path one owner.

Source: architecture review 2026-10-25, `Docs/QA/architecture-review-2026-10-25/report.md` §F2; slice 6 of 8 in the TASK-36952.3 split plan, measured at `08b3c9d337`.

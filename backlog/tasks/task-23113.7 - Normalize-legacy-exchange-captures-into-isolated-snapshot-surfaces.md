## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Expose historical full and safe exchange blobs through isolated legacy snapshot surfaces with explicit uncertainty and without inventing semantic chronology.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Existing full and safe capture blobs normalize incrementally into isolated `legacy_snapshot` surfaces structurally equivalent to their sanitized legacy projection or an explicit omission record.
- [x] #2 Repeated transcript prefixes in legacy snapshots use persistent prefix nodes so migration does not recreate quadratic normalized storage.
- [x] #3 Unchanged pre-ledger messages acquire lazy digest-free revisions and normalize as canonical references when uniquely matched instead of becoming provider-only artifacts.
- [x] #4 The viewer labels legacy provenance and uncertainty and never presents inferred message edits, call order, or source identity as known fact.
- [x] #5 Migration is resumable and idempotent with batches bounded to 100 rows, 100 ms, and 4 MiB and completes the five-second historical fixture gate.
- [x] #6 Unmigrated and migrated records remain readable during rollout, including malformed or partially recognized legacy blobs.
- [x] #7 ADR required: yes; this task implements the legacy compatibility policy in ADR-097.
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Add failing unit and database tests for bounded Full/Safe decoding, aggregate omissions, corruption/truncation, unique canonical-revision matching, ambiguous/unmatched artifacts, isolated legacy-snapshot surfaces, and persistent-prefix reuse.
2. Implement one-exchange normalization through the production decoder and mandatory credential filter, with digest-free canonical references where uniquely provable and explicit content-free uncertainty or omission metadata everywhere else.
3. Add failing migration tests for dual reads, resume, idempotency, rollback, equivalence failure, lease exclusion, checkpoints, and strict row/time/decoded-byte batch limits.
4. Implement idle maintenance normalization with same-transaction structural equivalence before legacy deletion, retryable content-free failures, and a pinned historical fixture that completes within five seconds.
5. Run the focused normalizer, projection, capture-migration, maintenance, benchmark, privacy, migration-chain, static-analysis, and derived-artifact checks; self-review storage growth, chronology claims, and sensitive-data owners before completing the task.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Implemented bounded legacy Full/Safe capture normalization through the production decoder and mandatory credential sanitizer. Legacy records now project into isolated snapshot surfaces with explicit provenance, recorded-call-only chronology, uncertainty metadata, canonical lazy digest-free revisions where uniquely provable, and persistent-prefix nodes that avoid quadratic storage. Added resumable idempotent idle maintenance with lease exclusion, transactional readback verification before deletion, checkpoints, dual-read rollout behavior, corruption/omission handling, and inspector labels. Added a genuine schema-v53 200-call historical fixture plus checksum and generator; migration completes in 3.86 seconds against the five-second gate. ADR-097 governs this work; no new ADR was required. Focused normalizer/migration tests passed (14), broader relevant trace/capture/UI/runtime groups passed approximately 235 tests with one pre-existing Console runtime startup timeout, Ruff and py_compile passed, and git diff --check passed. A full 71,015-test sweep was attempted but stopped at 1 percent after unrelated early failures and impractical runtime; focused evidence was used for this task.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Fixed in burn-down PR 3 of the B2b follow-ups, with TASK-38228 and TASK-33910.46.

- **On dev (29592ecc9b):** the server branch of `_character_title()` passed no `matched`, and no unfiltered server total was kept, so a server search read a bare "Characters 12". This PR fixes it.
- **Owner decision 2026-11-05:** "'12 of 340' / '12 of 100+' (Rec.)". AC#2 is re-worded to record it.
- **Fix:**
  - When an unfiltered server window commits (replace or append, inside the render lock, after the fence check), `PersonasScreen._server_unfiltered_total` records (server id, total, known). Search, failed and blank windows record nothing.
  - While a search is active and the record is for the active server, the title reads `N of M`: "Characters 12 of 340", or "Characters 12 of 100+" while the unfiltered read was a full page with no total. A search page that is itself full with no total reads "Characters 100+ of 340", through `items_border_title`'s new `matched_known` flag (`roleplay_list_window_state.py`).
  - No server call is added, and the mounted tests count the calls.
  - The record is keyed by server id, so another server's M never shows. A runtime-source change drops it.
- **When neither total is known,** the title keeps dev's form: the bare count "Characters 12" ("Characters 100+" for a full search page). That happens when the unfiltered read failed, or when the record belongs to another server or to before a source change.
- **Tag:** the tag picker refuses the server source (unchanged), so only search reaches this; AC#1's "or tag" has no server path.
- **Tests:**
  - `test_a_server_search_title_reads_n_of_the_last_unfiltered_total` (3 cases) is RED on dev.
  - `test_a_server_search_with_no_unfiltered_total_keeps_its_bare_count` (3 cases) passes on dev, as a guard.
  - `test_border_title_names_the_kind_and_its_count` (`Tests/UI/test_roleplay_item_list.py`) gains 2 rows.
  - Named mutations cover the record condition, the server key, the source reset, `matched_known`, and an extra list call.
- **User Guide:** `Docs/User_Guide/roleplay-chat-dictionaries.md` "Counts in the border".

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
**Impact (P1, triage NEW).** Compaction was left at the default 'Ask' and the chat was at 86%, over the 80% trigger. A send was held before any provider call. The user saw:
- an empty Assistant row;
- a full-width 'Response accepted; waiting for dispatch.' panel with [Retry response] [Discard] (panel border contrast 1.01:1);
- 'Send blocked — resolve response recovery first' in the composer;
- 'Ready' in the header and 'Run: Ready' in Inspect.

The reason appears only after Retry: 'Assistant Failed / Response failed.' plus a System row, 'Conversation context reached its compaction threshold. Review and approve compaction before sending again.', which has no action. After Discard the reason is never shown. Every later send gets the same panel.

There is no /compact command or palette entry. The only 'Compact now' button is at the bottom of header Settings ▸ Context and memory, about 20 wheel ticks down, and it runs without a preview. The Model chip popover names the lever '/rewind ▸ Summarize', which does have a preview (TASK-26017), but that path is disabled in exactly this held-tip state. Its disabled reason is cut off below the visible part of the modal. The default setting turns the first over-threshold send into an unexplained stall that reads as a sync or dispatch problem.

**Prior art:** ADR-052:62-63; TASK-14811.2.1, TASK-14811.3, TASK-14915, TASK-26017, TASK-21145 and TASK-2154.6 (all Done); PR #2882.

**Suggested direction:**
- Give a policy hold its own turn state, separate from dispatch-checkpoint recovery, and settle the checkpoint so the dispatch panel never appears.
- Show the hold in the turn slot on the first block, with the numbers and actions: Summarize & send (with the TASK-26017 preview and the extra-call cost), Send without older turns, change the policy, Cancel.
- Let the manual-summarize planner accept the held tip.
- Surface 'Next send will pause for compaction approval' in the header, Inspect and the Context chip.
- Add /compact and a palette entry.
- Document the behaviour in the Console guide and F1.

Evidence: qa/console-ux-review-2026-09-29/findings.md → GAP2-02; qa/console-ux-review-2026-09-29/evidence/evidence__GAP2__71-compaction-ask-panel.png, evidence__GAP2__74-after-retry.txt, evidence__GAP2__78-conv-settings-context-bottom.txt.

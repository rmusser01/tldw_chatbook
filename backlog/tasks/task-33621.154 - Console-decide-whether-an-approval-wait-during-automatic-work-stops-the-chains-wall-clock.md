## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
From TASK-33621.153. The owner decided (2026-11-12) that time a chain waits at a compaction_ask hold does not count against its automatic-work wall clock: the chain's time limit measures only the time the work runs. Other waits the user must lift still count. A tool approval card raised in an agent wake's turn keeps the chain's clock running while it waits for the user, and the wake's deadline watcher (ConsoleFleetWakeCoordinator._watch_deadline) stops the turn once the deadline passes, even while the card is open. ADR-134 says so ('Elapsed time includes queueing and human approval waits'), and the User Guide says waiting for approval does not pause the automatic elapsed deadline (agent-runs-and-tools.md). The autowake_disabled pause (Paused: auto off) also counts. Goal runs document the same rule ('Pauses, approvals and waits count toward that deadline'); workflows already count only active intervals. Found by reading; not reproduced.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The second half of phase 3a of the fleet spec (§3 invariant 5, corrected
2026-08-11: auto-wake is required; §7: completion reaches the user across
conversations). PR 3a-1 (task-13154's cross-turn runtime slice, merged
`d5445a4c1`) let a child outlive its turn; this PR makes a finished child
(a) wake its supervisor so it can act on the result and (b) reach the user
wherever they are. Plan:
Docs/superpowers/plans/2026-08-13-supervisor-fleet-pr3a2-autowake.md.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria

<!-- AC:BEGIN -->
- [x] #1 A finished background sub-agent re-invokes its supervisor: the wake turn reaches the provider carrying the child's DB-sourced result, and the transcript records a SYSTEM-class machine-origin notice — never a USER row
- [x] #2 Completion reaches the user from any screen: app-wide toast, unseen-completion badge on session tabs and sidebar rows, deep link claimed on return to Console; the durable mark and wake-delivery ledger survive restart
- [x] #3 `[agents] autowake_enabled` (default ON) disables the wake without losing completions — OFF still records, marks, and toasts; ON delivers what OFF recorded
- [x] #4 A woken turn grants no new authority: risk-floored tools still raise approval cards, the wake cannot resolve a pending card, and the turn runs under every existing cap
- [x] #5 Exactly-once delivery: a redelivered drain or a restart never re-announces a stamped run (`agent_runs.wake_delivered_at` first-writer-wins), and no completion is lost
- [x] #6 User wins ties: a non-empty Console composer draft defers a due wake until the draft clears or the next trigger
<!-- AC:END -->

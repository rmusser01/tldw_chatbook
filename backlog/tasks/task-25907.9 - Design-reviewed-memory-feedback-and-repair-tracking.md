## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Define how explicit user corrections and unresolved interaction issues become scoped, reviewable improvements without speculative psychological profiling.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 The design assigns user facts and preferences to Personal Context and verified procedural improvements to Agent Lessons, with linked evidence and explicit scope.
- [x] #2 Issue state distinguishes observed feedback, proposed response change, user approval, and resolution evidence; inferred feelings or personality claims are not silently stored.
- [x] #3 Any standing guidance is a bounded derived view of approved records and remains user-owned data that cannot override current instructions or tool authority.
- [x] #4 Expiry, reopening, forgetting, and changed-evidence behavior are specified without treating narrative reflection as independent evidence.
- [x] #5 The relationship to the separate Dreams discovery feature and existing Companion goals is explicit; neither gains a second authoritative store.
- [x] #6 The output is a reviewable design with synthetic acceptance examples and a bounded release scope; no nightly job is enabled.
<!-- AC:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
All four lock-state fixes implemented and verified.

- FR-03: the screen now passes `("", "")` as the empty-state action when the provider blocker copy is empty (`_sync_console_transcript_guidance`); `ConsoleTranscript.sync_empty_state` stores an empty label as "no action" instead of falling back to the legacy `Choose model` constant. `ConsoleTranscriptEmptyPanel` renders `Button#console-empty-provider-action` only with a concrete label and never in `card` mode (the modal already covers the transcript); the button posts `WorkbenchActionRequested("provider-recovery")`, the same route as the modal action. The dead-end case this fixes: fresh session + previously-completed first send + provider broken since (quiet empty state, no modal).
- FR-06: `CONSOLE_WORKBENCH_SHORTCUTS_SETUP_BLOCKED` replaces `Enter send` with `Enter continue setup`; `_register_console_footer_shortcuts` picks the tuple from `_console_setup_modal_blocking()` and `_apply_console_setup_block` refreshes it on every transition (before the composer QueryError early-return). Deviation from the literal AC ("hidden"): swapped for the accurate action instead of dropping the entry, since Enter genuinely activates the focused card action — the misleading send hint is gone either way.
- FR-09: `ConsoleSetupModal.on_key` consumes printable characters while blocking (also keeps the screen's j/k/c/e/r transcript bindings inert under the overlay) and raises one informational toast per blocking episode; the flag re-arms when the block lifts. Verified in the real app via an instrumented UAT probe: headless `run_test` defaults `notifications=False` (no ToastRack mounted), which is why no UAT capture can show toasts; with `notifications=True` the toast mounts into `textual-toastrack` as expected.
- FR-10: added `CONSOLE_SETUP_CARD_SUBTITLE` ("A provider is the AI service that answers your messages — for example OpenAI, Anthropic, or a server running on this computer.") rendered under the card title, display synced with blocking; `_STEP_ONE_LABELS` endpoint variants now read "Save the provider's server address (endpoint)" and "Pending" reads "Choose a provider that works in the Console". - Tests: new Tests/UI/test_console_setup_lock_polish.py (5 tests, pass).

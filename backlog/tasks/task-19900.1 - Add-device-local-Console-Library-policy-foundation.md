## Description

Establish one truthful device-local owner for per-conversation automatic
retrieval and assistant Library access, including upgrade preservation and
temporary-session lifecycle, without changing agent composition or Console UI.

## Acceptance Criteria

- [ ] A local-only policy table stores both axes with schema version, revision,
      update time, cascade ownership, and no sync/export/metadata projection.
- [ ] Only conversations present at migration are marked for one-time legacy
      initialization; initialization is idempotent and preserves their prior
      effective automatic and assistant behavior.
- [ ] New local sessions capture current global defaults once; newly synced or
      imported missing-row conversations resolve Never/Blocked without a write.
- [ ] Reads distinguish valid, absent, pending, corrupt, and failed states;
      every non-valid state is explicit and fail-closed.
- [ ] Conditional insert and revisioned CAS prevent concurrent overwrite and
      never publish an uncommitted candidate.
- [ ] First local conversation persistence includes captured policy atomically,
      and ephemeral promotion persists/restores the complete policy-bearing
      bundle atomically on success/failure.
- [ ] Targeted historical migration, repository, concurrency, lifecycle,
      deletion, and rollback tests pass and mutation-check the missing/error
      fail-closed guards.

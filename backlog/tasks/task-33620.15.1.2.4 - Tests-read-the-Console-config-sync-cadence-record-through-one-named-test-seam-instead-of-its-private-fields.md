## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Found in the pre-merge review of TASK-33620.15.1.2 (2026-10-27). Four test files (six sites) read the Console config-sync cadence record's private fields directly through config_sync._cadence(...): test_console_config_sync_cadence.py, test_console_workspace_display_reads_off_loop.py, test_console_projection_reads_off_loop.py (three sites) and, since TASK-33620.15.1.2, test_console_config_sync_lifetime.py, which asserts the native worker's refresh recorded its projection inputs. Each is tied to the record's field names, so renaming or reshaping a field breaks unrelated tests for reasons that have nothing to do with what they pin. One named, documented read seam for what tests need to observe (inputs recorded, published count) would let the record change shape without touching them.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
`chat_with_kobold` posts KoboldAI's native payload to whatever URL is saved for KoboldCpp. Dev's endpoint contract (TASK-35010/35832, pinned in Tests/UI/test_settings_saved_lists_follow_file.py) resolves a typed server root such as `http://localhost:5001` to the OpenAI-style `/v1/chat/completions`. A user who types the bare address therefore saves a URL the handler cannot use. The key check still passes, and the first chat fails.

TASK-34100.6 (merged in PR #3294) made first-run setup show KoboldCpp's native route as the example, so the default setup path is safe. A typed root, in setup or Settings, is still unsafe. The owner chose (2026-10-29) to fix it in its own task.
<!-- SECTION:DESCRIPTION:END -->

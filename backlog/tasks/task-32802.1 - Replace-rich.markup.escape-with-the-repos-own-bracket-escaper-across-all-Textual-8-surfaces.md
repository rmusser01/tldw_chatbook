## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
`rich.markup.escape` only escapes tags beginning `[a-z#/@`, so Textual 8's `Content.from_markup` deletes every other bracketed token: a note or conversation titled `[TODO] Q3 plan` renders as ` Q3 plan`, and `[IMPORTANT]` renders as an empty row. Measured directly against the production constructors. This affects roughly 40 sites -- every Library list row title through the shared row helper, plus Console conversation titles, queued prompts, rewind previews, scope and tag labels, attachment filenames, tooltips and Canvas labels. The repo already shipped the correct escaper, whose own comment names the `[TODO]` case, and applies it to exactly one surface.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Three of the four P0s in the core review violate one contract: a worker target must be a coroutine or declare `thread=True`, and a `query_one` after an `await` must tolerate a removed subtree. No check exists for either, which is why all three shipped. An AST check over `run_worker(`/`@work` call sites and post-await DOM lookups would have caught all three, and belongs beside the existing derived-artifact checks in `scripts/`.

Source: core-runtime code review 2026-09-17 — `qa/core-code-review-2026-09-17/report.md`; per-slice evidence in `qa/core-code-review-2026-09-17/slices/`, reproductions in `qa/core-code-review-2026-09-17/phase4-verification.md`.

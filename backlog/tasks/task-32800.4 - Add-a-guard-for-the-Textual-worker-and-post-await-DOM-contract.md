## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Three of the four P0s in the core review violate one contract: a worker target must be a coroutine or declare `thread=True`, and a `query_one` after an `await` must tolerate a removed subtree. No check exists for either, which is why all three shipped. An AST check over `run_worker(`/`@work` call sites and post-await DOM lookups would have caught all three, and belongs beside the existing derived-artifact checks in `scripts/`.

Source: core-runtime code review 2026-09-17 — `qa/core-code-review-2026-09-17/report.md`; per-slice evidence in `qa/core-code-review-2026-09-17/slices/`, reproductions in `qa/core-code-review-2026-09-17/phase4-verification.md`.
<!-- SECTION:DESCRIPTION:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
--------------------------------------------------
Added scripts/check_textual_worker_contract.py, registered in scripts/preflight.sh and .github/workflows/derived-artifacts.yml.

W001 (hard gate): resolves each run_worker target statically; fails when a non-coroutine method runs without thread=True. Zero violations once this branch's fixes land, so no allowlist. Two false-positive classes were found and handled while building it: @work-decorated methods read as non-coroutine through the decorated attribute (the same trap that fooled the review's first enumeration), and @property targets are unresolvable -- UI/Console_Modules/agent.py:2089 looked like a violation but its property returns chat_screen.py:18491, an async def.

W002 (census ratchet, NOT a gate): query_one/query_exactly_one reached after an await inside an async def with no enclosing try, limited to UI/ and Widgets/. 279 sites exist today. Whether one can crash depends on whether the awaited work can remove the subtree, which is not statically decidable, so a hard gate here would be the 'guard that cries wolf and gets muted' preflight.sh's own header warns about. The 279 are pinned in scripts/textual_await_dom_census.tsv; the check fails only on a NEW site. Shrinking is always allowed. The census header states the rows are a mechanical baseline, not an endorsement.

Mutation evidence (both directions): reverting audio_troubleshooting_dialog.py's thread=True -> W001 fires, exit 1. Reverting mcp_inspector.py's post-await guard -> W002 reports mcp_inspector.py:3427 as a new site. Restoring both -> exit 0. Clean-tree exit 0, mutated exit 1, restored exit 0, verified without a pipe so the code is the script's own.

Full preflight passes with all eight checks green. ruff E9,F63,F7,F82 clean.

## Implementation Notes

<!-- SECTION:IMPLEMENTATION_NOTES:BEGIN -->
ChatScreen now answers for its own unsaved composer work through `ChatScreen.has_unsaved_editor_state() -> bool`. The probe's ChatScreen branch is one line: `label, dirty = "Console composer", owner.has_unsaved_editor_state()`. This is the same shape as its BenchEditor and SpeechSettingsPane branches.

**Approach.** The probe's ChatScreen body moved almost verbatim into the method, which sits next to `save_state`:
- It reads the mounted `ConsoleComposerBar` with `self.query`, not the memoizing `_console_composer_or_none`.
- It reads the session controller's draft-switch snapshot and the keyboard-send capture's stash.
- It writes nothing.
- Every fail-closed `TypeError` is kept: unknown composer count or type, snapshot shape, pending-send type, stash type, and non-str text. The two `_exact` checks became `type(x) is _ConsolePendingSend` / `ConsoleDraftStash`, which are the same objects in that module.
- The probe still gates on `_exact(owner, ..., "ChatScreen")`, still maps a raise to "unknown-editor-state", and still applies its `type(dirty) is not bool` check.
- `unsaved_editors.py` no longer imports `ConsoleComposerBar`.

**Ratchets moved in this commit:**
- `test_screen_size_ratchet.py`: the ChatScreen row went from 24616/741 to 24654/742, a raise by the measured +38/+1 with a dated waiver comment. Base measures 24604/741, head 24642/742.
- The two Architecture pins of that row: `LIVE_RATCHET_ROW` in `test_console_review_selection_controller_boundary.py` and `LIVE_RATCHET_BUDGET` in `test_console_wave6_closeout_inventory.py`.
- `layer_direction_allowlist.tsv`: removed the `unsaved_editors -> Widgets.Console.console_composer_bar lazy` row, because that import is gone.
- `test_exact_type_names_point_at_their_defining_modules`: the floor went from 35 to 33 pairs, because the probe no longer names `_ConsolePendingSend` or `ConsoleDraftStash`.

No new module was added. The boot-import ratchets read 687/688 and 1038/1038, the same as base.

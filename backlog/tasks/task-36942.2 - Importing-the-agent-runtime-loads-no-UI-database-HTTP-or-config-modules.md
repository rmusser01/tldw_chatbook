## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
`Agents/agent_runtime.py` documents itself as a pure module with no Textual, app, DB or I/O imports, but a fresh-interpreter probe shows importing it loads `textual`, `httpx`, `sqlite3`, `DB.ChaChaNotes_DB`, `Chat` and `config` (207 tldw_chatbook modules). The cause is one constant imported from `Chat.console_project_instructions`, which runs `Chat/__init__`. `agent_models` already has a forbidden-import test; `agent_runtime` has none.

Source: architecture review 2026-10-25, `Docs/QA/architecture-review-2026-10-25/report.md` §F5; claim-by-claim verification in `Docs/QA/architecture-review-2026-10-25/verification.md` (origin/dev 7a5e2513c5).

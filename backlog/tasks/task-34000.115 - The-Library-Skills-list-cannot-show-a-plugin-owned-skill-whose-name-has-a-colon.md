## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Why: Plugin-owned skills are named `<plugin>:<skill>`. The Skills list builds each row's widget id straight from the name (`Widgets/Library/library_skills_canvas.py:1351`, `id=f"library-skill-row-{row.name}"`). A `:` is not a valid Textual identifier, so composing a plugin-owned row raises `BadIdentifier`, and the user cannot open a plugin-owned skill from the list.

Found while fixing PR #3423 review m-6 (2026-11-06). That task's mounted pin had to open the plugin-owned skill by name, because the list could not show its row. The bug is on dev `29592ecc9b`; PR #3423 does not touch that line.
<!-- SECTION:DESCRIPTION:END -->

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The Full track's optional steps say one thing and do another. The RAG step saves an embedding setting the RAG pipeline never reads, then the Summary shows '✓ RAG', and there is still no way to have your documents used when you chat. The Tools step promises 'Everything is off by default' while three tool groups ship on and the app's own MCP server still gives the agent create_note. The Notes step configures nothing. Speech offers only a 633 MiB download behind jargon, with actions above the choices they depend on. Appearance spends half its space on a 78-card splash gallery, yet the splash can't be turned off and motion can't be reduced. Before any of this, first launch shows 10-16 s of random joke splash with no skip hint, after raw dependency warnings. A first-timer leaves with a false picture of what the app will do; a power user's deliberate choices are silently dropped.

This implements structural fix SF10 ("Steps earn their place") from the review report, Docs/superpowers/qa/first-run-wizard-ux-review-2026-10-02/README.md (§5.1, §4.3), together with the honest-copy halves of fulltrack-01/-02 and enhancement E7. The shape-changing parts of SF10 (tldw server step, Quick-track rescope, documents-first Welcome) are in TASK-34100.17. Resolves: [fulltrack-01] [fulltrack-02] [new-full-track-steps-02] [fulltrack-06] [fulltrack-11] [coverage-13] [fulltrack-05] [voice-speech-15] [voice-speech-12] [entry-exit-handoff-17] [new-coverage-power-01] [coverage-15] [fulltrack-09] [fulltrack-13] [entry-exit-handoff-18].

Coordination: tool titles and blurbs live on the _GATEABLE_BUILTINS row (task-32284), so blurb fixes land there and the MCP Tool gates pane changes with them. The chat_with_llm half of the built-in MCP exposure, and the product call on whether that server belongs in plain chat, sit with [entry-exit-handoff-24] in TASK-34100.5. Tools row grouping [fulltrack-12] is TASK-34100.12, and the Quick-track note [protect-summary-12] is TASK-34100.9; share one derivation. The splash work overlaps task-24306 (first-run WebP decode cost). The 'Style' to 'Appearance' tracker rename rides TASK-34100.15's glossary. GGUF placement follows [voice-speech-13] in TASK-34100.9. Welcome's track labels must describe whichever Quick shape TASK-34100.17 ships. Removing Notes shifts every 'Step N of 11' assertion, so expect test churn.

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
New logic goes into small helper modules beside the steps (`first_run_<step>_<topic>.py`). `first_run_speech_step.py` (1,708), `FirstRunSetupWizard.py` (3,177), `app.py` (5,712), `chat_screen.py` and `console_chat_controller.py` are size-ratcheted: their diffs are net-zero or shrinking, never a raised row. Every AC gets a test that fails on the base first (RED), then the fix (GREEN).

1. **Search step (AC#1, #5).** Rebuild `RagStep` as "Search your documents (optional)": one SetupRadioSet "When you chat: search my Library only when I ask (default) / automatically", prefilled from `chat_defaults.rag_auto_retrieve_on_send` and committed as a delta through the same key Settings and Console read. The embedding model shown read-only from `resolve_active_rag_config()` (worker, off-loop), naming Settings ▸ Domain Defaults ▸ RAG, with Settings' own Library privacy sentence (shared constant) for an `openai/` model. No `[embedding_config]` read or write; drop `embedding_config` from `WIZARD_OWNED_SECTIONS`. Extras missing: the control stays, the extras package name is a secondary line with a Copy button (no "pip", real Settings path). Summary "Search" row from the flag plus the resolved model (resolver injected into SummaryStep like `rag_deps_installed`). Draft field becomes `auto_retrieve: bool`.
2. **Config template (AC#6).** Quote the bge keys, comment out the two sample rows, fix 3-small 1536 / 3-large 3072, drop the literal OpenAI api_key placeholder. tomllib test over the rendered template: every `[embedding_config.models.*]` entry has `provider` and `model_name_or_path`. Check every remaining UI that lists the table; filter incomplete/sample rows there.
3. **Tools step (AC#2, #3, #4).** Pure posture helper (`first_run_tools_posture.py`) derived from `all_tool_gates()` (given an optional config snapshot so the Summary can pass the re-read config): posture sentence for first run and re-run, read-only "Also available (asks first): …" line from the enabled local-group gates, Summary row and the Quick-track note from the same derivation. Master switch not offered. Blurbs on the `_GATEABLE_BUILTINS` rows: file tools name Workspace folders + chat scratch area; ask wording matches the approval card (asks before each use; This session). One static hint under the file rows pointing at Settings ▸ Workspaces. MCP built-in twins: `MCPToolProvider.compose_catalog` drops `builtin:tldw_chatbook` `create_note` while `[tools] create_note_enabled` is off and `create_character`/`update_character` while character tools are off (twin table beside the gate enumerator).
4. **Notes (AC#7).** Remove `notes` from `_FULL_TRACK`, `STEP_TITLES`, the draft field table, `WIZARD_OWNED_SECTIONS` and the step factory; delete `first_run_notes_step.py`. Draft reader tolerates the retired step and retired fields (old drafts resume instead of being dropped). Summary row "– Notes folder sync — not set up · Library ▸ Notes ▸ Add from files…" (text only: Library has no deep link to Add from files). Rewrite the "Step N of 11" pins.
5. **Appearance (AC#12, #13, #14).** Theme rows and the Summary Theme row use display names with a tone tag; the shortlist list grows to its content (no hidden row). Gallery out; one read-only line names the current card from the full config TOML and points to Settings ▸ Splash Screen. New controls: "Startup animation: Off / Short (2 s) / Full", "Reduce motion", "Plain ASCII status marks" (preset from NO_COLOR or TERM=linux), each delta-committed to `[splash_screen]`/`[appearance]` (`appearance` joins the owned sections) and shown on a Summary row.
6. **Splash and first launch (AC#10, #11, #16).** Extract the splash decision out of `app.py.compose` into a helper: a profile's first launch (no `[first_run]` flags) skips the splash; joke/persona cards (JULES intro, URMOM table, and similar) are excluded from the random pool (opt-in by name only); the splash draws a dim "Press any key to skip" line whenever `skip_on_keypress` is true. `TLDW_REDUCE_MOTION`/`NO_MOTION` fold into the loaded appearance settings at launch. Route `RequestsDependencyWarning` and optional-dependency notices to the log file, not the pre-TUI terminal. Perf-guard: a fresh-profile "time to Welcome" test in the perf-guard latency file.
7. **Welcome (AC#15, #16).** D1 time-line copy, a Full label that names what Full adds, privacy scoped to local models, no empty error band; "Moving from another computer? 8. **Speech (AC#8, #9).** Engine helper module: detected choices "No dictation for now" (preselected, writes nothing), "Already available — <installed engine>", "On this computer — Parakeet (633 MiB download)", "Cloud — OpenAI Whisper (audio is sent to OpenAI)" when an OpenAI key exists; only a choice made this run writes `[transcription]`, on Next.

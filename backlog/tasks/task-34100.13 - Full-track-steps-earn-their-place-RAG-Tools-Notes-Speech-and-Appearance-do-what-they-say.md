## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The Full track's optional steps say one thing and do another. The RAG step saves an embedding setting the RAG pipeline never reads, then the Summary shows '✓ RAG', and there is still no way to have your documents used when you chat. The Tools step promises 'Everything is off by default' while three tool groups ship on and the app's own MCP server still gives the agent create_note. The Notes step configures nothing. Speech offers only a 633 MiB download behind jargon, with actions above the choices they depend on. Appearance spends half its space on a 78-card splash gallery, yet the splash can't be turned off and motion can't be reduced. Before any of this, first launch shows 10-16 s of random joke splash with no skip hint, after raw dependency warnings. A first-timer leaves with a false picture of what the app will do; a power user's deliberate choices are silently dropped.

This implements structural fix SF10 ("Steps earn their place") from the review report, Docs/superpowers/qa/first-run-wizard-ux-review-2026-10-02/README.md (§5.1, §4.3), together with the honest-copy halves of fulltrack-01/-02 and enhancement E7. The shape-changing parts of SF10 (tldw server step, Quick-track rescope, documents-first Welcome) are in TASK-34100.17. Resolves: [fulltrack-01] [fulltrack-02] [new-full-track-steps-02] [fulltrack-06] [fulltrack-11] [coverage-13] [fulltrack-05] [voice-speech-15] [voice-speech-12] [entry-exit-handoff-17] [new-coverage-power-01] [coverage-15] [fulltrack-09] [fulltrack-13] [entry-exit-handoff-18].

Coordination: tool titles and blurbs live on the _GATEABLE_BUILTINS row (task-32284), so blurb fixes land there and the MCP Tool gates pane changes with them. The chat_with_llm half of the built-in MCP exposure, and the product call on whether that server belongs in plain chat, sit with [entry-exit-handoff-24] in TASK-34100.5. Tools row grouping [fulltrack-12] is TASK-34100.12, and the Quick-track note [protect-summary-12] is TASK-34100.9; share one derivation. The splash work overlaps task-24306 (first-run WebP decode cost). The 'Style' to 'Appearance' tracker rename rides TASK-34100.15's glossary. GGUF placement follows [voice-speech-13] in TASK-34100.9. Welcome's track labels must describe whichever Quick shape TASK-34100.17 ships. Removing Notes shifts every 'Step N of 11' assertion, so expect test churn.

## Implementation Notes

**Summary.** The five optional Full-track steps now do what they say. Search sets one real setting, the one Console reads. Tools derives every sentence from `all_tool_gates()`, and the app's own MCP server no longer hands the agent a twin of a gated-off tool. Notes is gone. Speech opens with an engine choice built from what this machine has. Appearance replaces the 78-card gallery with startup animation, motion and glyph choices. A profile's first launch plays no splash. Each step writes only the choices made in this run.

**Approach.** New logic lives in helper modules beside the steps. The size-pinned modules shrank, so no ratchet row was raised:
- `first_run_speech_step.py` went from 1708 to 1638 lines, and its ratchet row was lowered to 1638.
- `FirstRunSetupWizard.py` went from 3177 to 3151.
- `app.py` is at 5703 against a budget of 5712.
- The ui-ready module census stayed at 1033: the splash policy was folded into `Widgets/splash_screen.py` and `Utils/startup_logging.py` instead of adding a module.

Every AC got a test written first and run red on the base (see Test evidence).

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
`config.py` creates three database singletons lazily (`get_chachanotes_db_lazy`, `get_prompts_db_lazy`, `get_media_db_lazy` at `:11873`, `:11908` and `:11937`). That makes the config module a global service locator for the app, `app_feature_glue`, the CCP character handler, `Character_Chat_Lib`, the document expansion tool, `Utils/doctor.py` and `MCP/local_runtime_delegate.py`. Its `initialize_all_databases()` has no production caller. Under the 2026-10-25 services decision, every entry point gets its databases from the services bundle (TASK-36947.2) or from the shared factory. Per ADR-250 §6, the factory is added by the first PR that calls it.

Source: architecture review 2026-10-25, `Docs/QA/architecture-review-2026-10-25/report.md` §F9; claim-by-claim verification in `Docs/QA/architecture-review-2026-10-25/verification.md` (origin/dev 7a5e2513c5).
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 config.py defines no module-level database instance and no database getter
- [x] #2 initialize_all_databases is gone
- [x] #3 Every former consumer gets its database from the services bundle or its shared factory, and their tests pass
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Delete config.py's DB globals, `initialize_all_databases` and the three lazy getters (and the DB class imports only they used); drop Notes_Library's dead `config.chachanotes_db` import-time fallback.
2. TUI opens: `_init_notes_service` and `_init_media_db` open through `app_services.open_chachanotes_db`/`open_media_db` (imported in the method bodies; same options, `seed_builtin_content=True` only for ChaChaNotes); `_select_profile_database` takes the notes service's own template instead of the global, and retries through the opener.
3. Consumers take their slice explicitly: FTS backfill reads `self.services.storage`; CCP helpers and `fetch_character_names`/`fetch_all_dictionaries` take `db`, with PersonasScreen `_character_db()` reading `app_instance.services.storage`; `BuiltinToolProvider(storage_provider=...)` hands note tools and `expand_document` their DBs (ConsoleRuntime passes the bundle's storage, mobile its engine storage); `LocalMCPRuntimeDelegate`/`LocalMCPControlService` take a storage provider; `run_doctor(integrity_fn=...)`, `/doctor` supplies one over `services.storage.chachanotes`.
4. Retarget every test patch of the getters/globals so it still reaches the code; lower config.py's size row, the ad hoc construction census rows, and any lookup census that drops.
5. Covering tests (-n 4), Tests/Architecture serially vs arch-base-u-5ca7.txt, boot-import ratchets, preflight.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->

The dispatch checkpoint stays 'accepted', and nothing appears in the transcript, toast or log beyond that status line. A Default-workspace send on the same build goes through. This may share its mechanism with TASK-33621.2: project instructions and other unsaved system rows fail to build trace provenance. Check that first; if the TASK-33621.2 fix resolves it, close this as covered.

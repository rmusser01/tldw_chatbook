## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Plain-text setup v1 (TASK-34100.33) leaves a stated gap: a screen-reader user still cannot change the tldw server, Search, Tools, Spoken replies, Dictation or Appearance without the TUI, which contradicts the spec's goal that setup is usable without it. The owner approved filing this slice together with v1 so the gap has an owner (spec Q7).

Plain mode has no running app, so it cannot bind a server itself. The approved spec has it save the server and token for activation at the next launch, where the shared runtime-source coordinator (TASK-34100.19) binds it and prepares sync, and reports the result (decision D10; ADR-033's 2026-10-03 amendment). The other areas render the Full-track step states from TASK-34100.27 as plain prompts.

Spec: Docs/superpowers/specs/2026-10-03-first-run-setup-shape-design.md (revision 3, approved by the owner on 2026-10-03; ADR-217): D10 (v1 gap), D3, §3.11, §10 F13b.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Extend the existing ExchangeCapture and ChaChaNotes sidecar so Safe and Full semantic records have bounded credential-safe content queryable provenance and a sparse local conversation override while every existing runtime path continues to resolve Safe.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Safe remains the application and migration default and no user-visible path can activate Full.
- [ ] #2 Safe and Full request/response capture share credential exclusion endpoint sanitization nested binary stubbing and bounded serialization compression and decompression.
- [ ] #3 Every persisted exchange derives matching blob and queryable capture_detail provenance and mismatches fail closed.
- [ ] #4 Conversation capture override storage is local-only sparse checked and cascades with conversation deletion.
- [ ] #5 Historical and current-schema migration fixtures plus the complete DB migration suite pass.
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Add failing pure tests for Safe/Full parsing, precedence, legacy-Safe provenance, endpoint sanitization, tagged instruction handling, nested binary stubbing, and the shared 64 MiB budget.
2. Implement capture types, bounded request/response construction, explicit capture-detail serialization, bounded decompression, and content-free failure behavior.
3. Add and test the current-schema migration, queryable exchange provenance, and sparse local conversation-policy repository.
4. Thread matching blob/column provenance through ChaChaNotes, persistence, store, and Inspector loading with corrupt mismatch fail-closed behavior.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
**Impact.** This is a classic mode error at the worst moment. After arming the Terminal and clicking New then Create, the session starts ('➜ home') under 'HOST TERMINAL - FULL USER ACCESS / Terminal content is user-only and is not sent to a model.' Keyboard focus, however, returns to the chat composer. Typed 'echo hi' and then 'ls ~/.ssh' landed in the composer, and Enter really sent them to the LLM: the proxy logged a POST to api.anthropic.com. Because the Terminal center hides the transcript, the turn finished 'while hidden', and a new chat titled 'echo hi' appeared. The footer showed 'Enter send / queue | Y trace' the whole time. The verifiers found more:
1. After confirming the Arm dialog, focus also goes to the composer, not to New.
2. When a session already exists, creating Terminal 2 leaves Terminal 1 selected, so Focus or a viewport click sends keys to the old session.
3. A viewport click does give it input, but nothing on screen says this is needed.

Verified live on dev 64579cce2c (live, code and skeptic all CONFIRMED).

**Cause.** The terminal focus helper runs only on a center swap. `request_new_session` never refocuses, and the resume path's focus restore falls back to the composer after the Arm and New-session modals close.

**Severity / prior art.** P1, triage NEW. TASK-22512 (Done) shipped 'create, name, list, focus, and close' as separate actions. ADR-099 forwards keys only 'while terminal input is focused' and says nothing about focus on create. Related: TASK-26034, TASK-23114.

**Suggested direction.** Make the Terminal center a real focus owner. While it is open, restoring focus after a modal must target the terminal, not the composer; a one-off 'focus after create' would race the resume handler. After an admitted create, select the new session and focus its viewport. While the Terminal owns the center, show Terminal footer hints (release chord, Return to transcript), and relabel or collapse the composer so typing there is clearly a chat action.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Define a forget operation that removes or invalidates governed derivatives and prevents retained source material from silently recreating forgotten information.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 The design inventories canonical history, Undo, proposals, promoted records, interview drafts, context caches, compaction or Note derivatives, outboxes, Sync staging, and remote copies by actual owner.
- [x] #2 Archive, deletion with Undo, immediate forgetting, source-transcript deletion, and delete-everywhere have distinct reviewable semantics.
- [x] #3 Dependency and source-suppression rules prevent re-extraction under a new record ID, including restart, replay, and concurrent background jobs.
- [x] #4 A proposed ADR defines cross-owner crash recovery, deletion fences, privacy-safe receipts, and unavailable or offline peer outcomes without claiming remote erasure prematurely.
- [x] #5 Synthetic acceptance scenarios cover mixed-source derivatives, user-authored Notes, stale snapshots, recreated proposals, old-generation sync, and retained exports outside managed custody.
- [x] #6 The deliverable is a reviewed design and bounded release scope; no destructive migration or deletion is performed.
<!-- AC:END -->

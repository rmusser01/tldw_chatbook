## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Let users inspect Samira's complete pack and safely create profile-owned immutable versions when replacing or generating reactions, without mutating installed assets.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 The Personas workbench filters all 31 labels, displays a visible count and text label, and decodes only the selected lazy preview.
- [ ] #2 Replacing, clearing, or generating reactions stages one complete candidate; Save publishes exactly one immutable version and cancellation or failure leaves the active version unchanged.
- [ ] #3 The first edit of a built-in pack creates a private profile-owned copy using validated same-filesystem staging and never writes beneath the installed package root.
- [ ] #4 Generate All requires explicit confirmation for 31 provider calls, uses bounded concurrency, is cancellable, and never publishes a partial version.
- [ ] #5 Publishing a new active version invalidates the bound actor's Console resolver and decode-cache entries before the updated binding is presented.
- [ ] #6 Pack authoring, copy-on-write, atomic replacement, orphan cleanup, permission, provider-failure, cache-invalidation, and Textual geometry tests pass.
<!-- AC:END -->

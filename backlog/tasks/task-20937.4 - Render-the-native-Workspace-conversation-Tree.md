## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Replace the grouped all-workspaces browser with a native Textual Tree under Workspaces, retain compact Switch/New/RAG controls, and preserve keyboard, focus, disclosure, star, and Default-workspace routes.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Workspaces mounts one native Textual Tree with `show_root=False`, `auto_expand=False`, a hidden non-selectable root, compact two-cell guides, literal Rich `Text` labels, and explicit Unicode/ASCII disclosure and guide vocabularies.
- [ ] #2 Every visible/selectable non-retired named workspace is a top-level node; paged associated conversations, loading/empty/error/Retry/`Load more…` nodes, active workspace/conversation markers, run markers, and starred state render in deterministic order without embedded row-widget containers.
- [ ] #3 The active identity is one ellipsized row, Switch/New/RAG Scope form the approved compact pinned strip, Default remains reachable through Switch, and contextual Star/Unstar remains usable without allowing fixed chrome to exceed 12 rows.
- [ ] #4 A one-node Tree hugs its natural height; demand of at least eight rows receives at least eight visible rows inside the 20-row Workspaces body; the Tree is the direct and sole local scroll owner, enters Tab order whenever it has a selectable node even when it does not overflow, and keeps its separate hint and wheel handoff overflow-dependent without a nested viewport.
- [ ] #5 Pointer disclosure, Space, Enter selection, Up/Down, guarded Left/Right, shifted ancestry/sibling boundary guards, `s` Star/Unstar, editable-input exclusion, Tab/Shift+Tab, wheel handoff, and no-wrap hidden-root behavior match ADR-083.
- [ ] #6 Search-time disclosure is temporary and restores the exact pre-search persisted snapshot; incremental keyed updates retain node identity, cursor, focus, and outer/local offset where possible, while removed targets recover within the owning section before leaving the rail.
- [ ] #7 Production-path tests cover long/literal/CJK/emoji labels, narrow-width worst-case chrome, Default switching, action recovery, rapid search/page/membership mutations, star persistence, structural movement, collapse/reopen, responsive focus handoff, and no preference writes from transient Tree state.
<!-- AC:END -->

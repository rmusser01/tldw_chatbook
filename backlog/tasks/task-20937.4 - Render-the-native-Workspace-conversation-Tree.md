## Implementation Notes

- Added `ConsoleWorkspaceTree`, a native Textual 8.2.8 adapter with literal single-row labels, explicit Unicode/ASCII glyphs, guarded native navigation, contextual actions, auxiliary status nodes, temporary search disclosure, and stable business-ID maps. Keyed updates preserve node/data/cursor identity; true deletion uses the public API.
- Added native-scroll-owner mode to `ConsoleBoundedSection` without changing its default viewport path. Workspaces now composes fixed identity/action/search chrome plus the direct Tree and separate overflow hint, with mounted geometry/focus/wheel recovery coverage.
- Extended immutable display/tree state and Console controller/wiring for active workspace state, independent workspace query/loading/error/retry/marks state, the actual Tree owner token, retained-page collapse invalidation, and lifecycle fencing. Flat Conversations and workspace search remain independent, and flat/Tree selection shares one saved-conversation hydration/open path.
- Amended ADR-083 before production work to authorize one fail-closed exact-version private move helper. Textual 8.2.8 has no public move/reparent API; public remove/add was rejected because it destroys `TreeNode` identity and cursor continuity. The helper is isolated and mutation-tested, but a Textual upgrade must revalidate its private shape.
- Replaced obsolete grouped Starred/Workspaces production tests with native Tree coverage and retained the flat Conversations tests. Rebuilt `_agentic_terminal.tcss` into the canonical modular bundle; no glyph-fallback file change or performance-speed claim was made.
- The independent specification review found nine integration gaps. Eight behavioral RED probes reproduced initial named-workspace loading, current/stale search settlement, zero-result input editability/no-echo initialization, persisted disclosure wiring, logical cursor fallback, expanded-Right descent, and pointer Star/Unstar behavior; exact-version and single-invalidation seam probes characterized already-correct fail-closed behavior. The forward repair wires those production paths without weakening search/page/lifecycle fences or allowing transient search disclosure to write preferences.
- The second specification review found six remaining integration defects. The final repair routes persisted/default-expanded nodes through page-zero loading, settles and cancels cleared workspace searches, persists exact disclosure sets through the durable config writer, places contextual Star/Unstar on a separate narrow-safe row, returns focus to the Workspaces header when the final selectable node disappears, and treats same-parent private move indices as final positions. A lightweight-host regression discovered during verification also pinned section-header geometry so a late allocator pass cannot let body content intercept a visible disclosure control.
- Final verification after both reviewer repairs: the six-suite primary gate passed 171 tests; the audit-discovered controller/lifecycle/routing/geometry/performance/native-flow/recompose/tick/CSS gate passed 126 tests. Scoped Ruff check, Ruff format check, CSS build integrity, and `git diff --check` passed. Seven required mutants were killed with zero survivors before review: overflow-gated focus, `auto_expand=True`, hidden-root guard removal, persistent search disclosure, public remove/add movement, nested native viewport, and missing collapse page guard. The reviewer-correction behaviors are pinned by focused RED/GREEN regression tests, including separate automatic-startup and manual-page request lifecycles.
- Modified production/state files under `Widgets/Console`, `UI/Console_Modules`, `UI/Screens/chat_screen.py`, `Workspaces`, and Console CSS; added/updated scoped UI tests plus the Task 4 plan, ADR-083 amendment, and this task record. No general custom rendering framework or new dependency was introduced, and no new cross-task lesson was needed.

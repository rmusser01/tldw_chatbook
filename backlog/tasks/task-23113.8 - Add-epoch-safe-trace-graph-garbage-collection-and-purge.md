## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Reclaim unreachable trace graph data safely across conversation deletion, branch pruning, retention, migration, and concurrent reachability changes while preserving shared fork history.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 A schema-derived root/edge inventory covers calls and lifecycle links, segments and inherited boundaries, conversation visibility/ownership, retention, events, surfaces, bindings, locators, headers, artifacts, response links, and migration state.
- [x] #2 Every inventoried mutation that can change trace reachability advances the single global trace-graph epoch in the same transaction.
- [x] #3 Garbage collection marks from persisted conversation, fork, open-call, migration, soft-delete, and explicit retention roots and sweeps only when the exact marked epoch remains unchanged.
- [x] #4 Deleting one fork or owner never removes revisions, artifacts, surfaces, events, or calls still reachable from another owner.
- [x] #5 Conversation purge and retention expose explicit logical-reclamation results and are idempotent after interruption.
- [x] #6 A compaction-heavy adversarial fixture proves no reachable trace data is deleted under concurrent ownership changes.
- [x] #7 Privacy tests verify deletion or retention across every durable trace owner and projection.
- [x] #8 ADR required: yes; this task implements the reachability and deletion boundary in ADR-097.
<!-- AC:END -->

## Implementation Notes

Implemented ADR-097's logical-reclamation boundary as the new v62→v63 schema
transition. The collector persists an exact-epoch mark, follows bounded fork
lineage and every durable trace projection, and receives a connection-local
delete grant only inside the validated sweep transaction. Owner-scoped purge
now survives interruption, reports forks retaining shared history, and records
content-free live/reclaimed, freelist, WAL, and allocated-byte measurements;
retention, migration, call lifecycle, and redaction-root changes invalidate
stale marks. Direct and raw-connection deletion remains fail-closed.

Added the schema-derived reachability inventory, historical v62 migration and
idempotent-reopen coverage, shared-fork/open-call/soft-delete/retention fixtures,
crash rollback and expired-lease takeover tests, a 256-artifact concurrent
compaction adversary, and reopen privacy checks across every trace payload
table. Also corrected the pre-existing current-version repair gates so pinned
v56 fixtures do not run v58-only Notes repairs. ADR required: yes; implemented
the existing `backlog/decisions/097-console-reference-backed-semantic-trace-ledger.md`.
The post-rebase release gate also proved the mark lookup is already covered by
the table primary key, so the redundant index was removed; the retention-expiry
index now matches the collector's `julianday` predicate and has a no-statistics
query-plan pin. PR review additionally hardened UTC detachment validation and
bounded-fork marking: eventless pre-dispatch calls now remain reachable only
when their immutable turn identity is proven inside the inherited prefix.

Verification: 207 focused trace, migration, schema-allowlist, and built-package
tests passed before rebase, an 86-test focused post-rebase regression set
passed, and the final review fixes passed a 110-test focused matrix; Ruff,
Python compilation, the complete derived-artifact preflight, schema table
allowlist, index-plan census, and diff checks passed. The repository full suite
was not run because project policy requires separate owner opt-in.

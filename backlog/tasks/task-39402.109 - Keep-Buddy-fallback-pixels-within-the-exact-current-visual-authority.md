## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The original Buddy fallback oracle requires keeping the currently painted frame only when the entire visual authority still matches. The current controller compares only selected owner IDs and keeps fallback animation enabled; the widget resets to frame zero if the animation flag changes.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 A same-authority decode failure freezes the exact currently painted frame without moving or refitting Buddy.
- [x] #2 Changing the binding or pack version before or during resolution never reuses the previous visual.
- [x] #3 Real repository and mounted regressions reproduce both gaps before production changes, then pass with existing authority, size, motion, viewport and retirement controls. Legacy collectors stay open until their remaining coverage qualifies.

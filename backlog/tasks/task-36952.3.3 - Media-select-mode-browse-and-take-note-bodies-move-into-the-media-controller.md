## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Select mode, the browse request and filter state, the type filter and the take-note action still run on LibraryScreen, reached by the controller through seven callbacks, and the browse sync is the hub most other media bodies call. Moving it gives the list surface one owner.

Source: architecture review 2026-10-25, `Docs/QA/architecture-review-2026-10-25/report.md` §F2; slice 3 of 8 in the TASK-36952.3 split plan, measured at `08b3c9d337`.
<!-- SECTION:DESCRIPTION:END -->

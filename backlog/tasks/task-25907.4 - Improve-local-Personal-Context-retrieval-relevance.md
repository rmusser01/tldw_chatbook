## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Improve recall for ordinary profile queries while keeping retrieval local, deterministic, bounded, and subject to the existing record authority rules.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Search returns only eligible records with positive matches in meaningful payload or semantic-key fields; provenance IDs, hashes and incidental JSON field names cannot create hits.
- [x] #2 Multi-term matching qualifies any positive term match and ranks more distinct matches first, then subject and same-field phrase matches with stable identity ties; no usable terms or no matches yields an empty result.
- [x] #3 The executable plan freezes normalization, punctuation, input bounds and technical-name, accented-text, CJK and single-character fixtures before implementation without claiming semantic equivalence.
- [x] #4 Automatic context relevance and profile_search share matching primitives while keeping distinct result semantics, hard priorities, workspace overrides and context budgets.
- [x] #5 The frozen baseline shows improvement on declared lexical cases with no authority regression and reports held-out results honestly; semantic-paraphrase limits remain explicit.
- [x] #6 No embeddings, provider call, persistent plaintext index, new dependency, source lookup, new cross-workspace reads or extra full-store pass is added; existing repository-read cost remains explicit.
- [x] #7 Targeted tests cover both production callers, zero-match and adversarial-metadata cases, international text, private and expired records, stable limits and measured cost on bounded synthetic profiles.
<!-- AC:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Implemented a bounded field-aware matcher over semantic-key and human-readable payload text, then reused it in profile_search ranking and automatic-context relevance without changing authority, storage, limits, budgets or provider contracts. A fresh review found combining marks dropped after case folding; three RED regressions led to a Unicode category scanner, with 68 matcher/tool/context, 23 Chat/agent and 65 offline baseline tests passing. The post-fix 24-case report is byte-identical to lexical-v1; development recall@3 rose from 0.8 to 0.9 and held-out from 0.8 to 1.0. Existing disclosure gaps and semantic paraphrase misses remain explicit. Updated the plan, evaluation, roadmap, execution review and Unicode testing lesson. ADR-182 applies; no new ADR. One narrow equal-score/20-result regression-test gap was deferred as Minor.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Prevent current canonical device-only Personal Context records from reaching unqualified agent-facing reads and tool responses, while preserving owner access and eligible syncable behavior. This is a conservative native privacy correction before V2 admission, not a complete provider-disclosure or retrospective forgetting rollout.

Approved scope: existing agent view/context/search/get eligibility and agent mutation/proposal target checks, with generic private-duplicate handling. Keep V1 canonical storage unchanged. The accepted foreground source-inspection design remains gated on separately qualified V2 admission and metadata privacy controls.

ADR required: no new ADR. ADR path: backlog/decisions/102-personal-context-profile-authority-sync-and-encryption.md; backlog/decisions/187-personal-context-provider-disclosure-authority.md. Reason: bounded forward privacy correction enforcing existing device-only restrictions without changing storage, grants, provider contracts or V2 policy. Native execution preference persists.

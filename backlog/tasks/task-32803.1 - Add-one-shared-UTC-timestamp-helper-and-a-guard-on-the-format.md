## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Twelve distinct UTC string shapes are produced by 55 helper copies across the package, SQLite's `CURRENT_TIMESTAMP` adds a thirteenth in the 31 tables that default to it, and 100 sites compare the results lexically -- only two normalise. Three of those comparisons are already wrong for users. There is no shared time module in `Utils/` and no check anywhere on the format a timestamp is written in.

Source: core-runtime code review 2026-09-17 — `qa/core-code-review-2026-09-17/report.md`; per-slice evidence in `qa/core-code-review-2026-09-17/slices/`, reproductions in `qa/core-code-review-2026-09-17/phase4-verification.md`.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 A single helper module provides UTC-now formatting, a parser that accepts every shape currently in the wild, and the SQLite text format
- [ ] #2 A guard asserts that timestamp-bearing columns are written through the shared helper
- [ ] #3 The guard runs in preflight and in the derived-artifacts CI job
- [x] #4 An ADR records the chosen storage format (ADR-173, Status: Proposed — pending owner ratification)

## Implementation Notes

PR #2735 (`fix/core-review-time`). Delivered the helper + a draft ADR for
review, per the owner's 2026-09-20 decision ("draft ADR + helper for review,
then adopt"); the guard (AC#2/#3) and cross-site adoption (TASK-32803.5) follow

AC#1 — `tldw_chatbook/Utils/timestamps.py`: `utc_now()` (aware UTC),
`utc_now_iso()`/`to_utc_iso(dt)` (canonical shape), `parse_utc(value)` (tolerant
of every shape on disk — canonical, +00:00 ISO, T/space separator, sec/ms/us
precision, date-only, SQLite CURRENT_TIMESTAMP; naive interpreted as UTC).
Gate-free tests in `Tests/Utils/test_timestamps.py` (17 cases).

AC#4 — ADR-173 records the canonical stored shape `YYYY-MM-DDTHH:MM:SS.mmmZ`
(millisecond ISO-8601 UTC with Z; fixed 24 chars so TEXT sort == chronological
sort — the property whose absence caused the three shipped bugs in .2/.3/.4).
Status **Proposed**: the three earlier fixes each independently converged on
this shape; the ADR records it as the package contract. Alternatives
(microseconds, +00:00, epoch integers, per-module helpers) documented and
rejected.

AC#2/#3 — DEFERRED to ratification. The format guard (assert timestamp-bearing
writes route through the helper) wired into preflight + the derived-artifacts CI
job encodes the ratified decision, so it is built after the ADR is Accepted.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Define exclusive starred-first conversation ownership, independent Workspaces and Conversations search state, and bounded per-workspace paging with stale-result and Retry protection.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 A pure deterministic projection assigns every named-workspace conversation to exactly one workspace node and every Default/unassigned conversation to exactly one flat row; moves between owners apply atomically with no missing or duplicate record.
- [x] #2 Starred records remain in their one owner, sort before unstarred records with recency as the secondary key, and never create a Starred aggregate or duplicate ordinary/search result.
- [x] #3 Workspaces and Conversations own separate query, debounce, attempt-generation, result/error, cache, Retry, and worker state; actions or completions in one projection cannot cancel or overwrite the other.
- [x] #4 Expanded workspaces load bounded service pages with independent per-workspace attempt generations and cursors; same-cursor overlap commits once, stale membership/query/mount results are discarded, and search finds service-scope matches not yet materialized.
- [x] #5 Search and page failures preserve the last settled projection or loaded children, expose the correct scoped Retry target, replace failed generations on Retry, and remain independent of one another.
- [x] #6 Before projection production edits, deterministic small, representative, and stress fixtures capture an immutable checksummed raw baseline with total service and materialized-row counts; the same fixtures prove deterministic ordering, page boundaries, selected/active/run markers, literal titles, and incremental non-structural updates without querying or rebuilding unrelated owners.
<!-- AC:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Final persisted-cache interleaving corrections capture the canonical membership revision
immediately before service I/O and validate it before owner stamping or cache commit. A
stale result clears and syncs only its still-matching refresh key; it cannot overwrite a
newer key/cache, and the next ordinary state build schedules exactly one replacement
refresh without timers, polling, or a retry loop.

Final stale-search corrections add one controller-scoped canonical membership revision.
Each workspace and flat search request captures it in the existing full request identity;
a complete canonical snapshot advances it before publishing owner truth, so older search
completions are discarded without stamping rows or replacing either lane's settled state.
Partial conflict-only snapshots do not advance the revision, and no owner-map copy, wall
clock, timer, or generalized concurrency framework was added.

Final precedence corrections replace the unused observation generation integer with a
bounded conversation-ID-to-owner map whose dictionary replacement order is the event
order. Successful persisted/native, bounded search, and page commits stamp current owner
truth; complete membership snapshots stamp every included ID even when no cached/page row
moves. Scoped complete snapshots clear absent observations only for included owners,
partial snapshots stay conflict-only, and search clear is not an ownership event. Owner
facts are pruned to materialized/cached/pending IDs before atomic publish.

Quality-recheck corrections preserve full tokens, cursors, and generations when a
partial owner observation merely omits loaded children. The bounded owner observation
joins flat/current and workspace-search results before atomic publish and works in both
move directions. Complete snapshots remain authoritative after older page/search
observations.
One captured-attempt terminal helper settles owner/lifecycle replacement, cancellation,
membership change/unknown, service error, and success without mutating newer attempts.
Controller marker projection initializes explicit empty truth for every current row before
layering live session and unseen markers, clearing acknowledged/closed cached markers.

Quality re-review corrections wire already-materialized canonical owner rows into the
real publish boundary before either projection is exposed, without membership I/O. Page
attempts now capture screen lifecycle identity, publish loading before service I/O, and
suppress repeated requests while loading. Cached active-search rows receive full native
RUNNING/approval/terminal marker truth with unseen as fallback; an absent marker key
preserves the row while an explicit empty value clears a settled marker.

Independent quality review corrections removed production-build membership polling,
gave the workspace and flat search lanes separate owner identities plus a shared remount
generation guard, overlaid current star/selection/run-marker truth on cached search rows,
and replaced per-workspace search fan-out with one bounded `scope_type="all"` service
query. Immutable workspace nodes now expose loading, error, Retry cursor, and
membership-unknown state with safe defaults. Canonical membership reconciliation also
moves settled rows in both directions between named and Default owners without duplicates.

Final spec re-review added a public async completion race: when membership becomes
unknown after a valid page request begins, the controller now preserves the settled
page, marks membership unknown, and installs the page-scoped error/Retry. Structurally
stale attempts and valid changed-membership tokens remain silent discards, so they
cannot overwrite newer state.

Implemented the ADR-081 ownership split as a pure immutable workspace-tree projection
plus a flat Default/unassigned projection sharing one starred-first/recency rule. The
Console controller owns independent workspace and conversation search lanes and bounded
per-workspace page attempts guarded by generation, full request key, membership, query,
owner, and lifecycle identity.

Spec-review corrections tie settled page rows to canonical membership snapshots so owner
moves reconcile atomically without projection-time membership polling. A membership read
failure is explicit unknown state: it preserves settled children/cursor and exposes the
page-scoped Retry instead of treating the owner as empty. Normal wired search failures
restore each lane's settled projection independently, and workspace search matches literal
workspace labels (including markup, CJK, and emoji) as well as conversations outside loaded
pages.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
With Full agent tools off, a plain Console send offers only the light set. The agent runtime still dispatches the runtime's own tools when a model calls them unprompted: `find_tools`, `load_tools`, and the run-log tools. Small models do this reflexively; TASK-34100.5.3.2's live check saw a 0.5B model call find_tools 5 times and load_tools 6 times for "Reply with just: hi".

Nothing is granted. `load_schemas` rejects any tool outside `config.allowed_tools`, so `load_tools` cannot widen the light set. But the calls are recorded as dispatched tool steps, and `find_tools` answers with catalog entries the surface never offered. TASK-34100.5.3.2's upgrade check had to exclude these tools from its "agent use" signal for exactly this reason (review G532-R2-3). Found by TASK-34100.5.3.2's round-2 reviewers.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
`Research_Interop/server_research_search_service.py` probes the client for `run_paper_search`, `get_paper_search_detail` and `run_paper_search_ingest`, none of which exist; the client exposes `paper_search`, `paper_search_detail` and `paper_search_ingest`. The private `client._request` fallback is therefore the live path on every call, bypassing the typed client and its request/response schemas. It is the only Interop module that calls the private transport.

Source: architecture review 2026-10-25, `Docs/QA/architecture-review-2026-10-25/report.md` §F14; claim-by-claim verification in `Docs/QA/architecture-review-2026-10-25/verification.md` (origin/dev 7a5e2513c5).
<!-- SECTION:DESCRIPTION:END -->

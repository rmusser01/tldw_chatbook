## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The shared confirmation dialog does not set `markup=False`, so a conversation title containing a bracketed token renders mangled, and one containing `[/...]` raises `MarkupError` inside the dialog's `compose()` -- which means the irreversible 'Delete stored Full captures' confirmation never appears at all. Forty-five modules import this dialog. The correct pattern and a pinning test already exist in a sibling modal, but that test uses a lowercase tag, the one case the broken escape handles.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
**Impact (P1, triage NEW).** Trace export fails for any conversation with at least one turn answered from staged Library sources (Search Library, then a send with 'N staged'). All three profiles fail:
- Safe summary and Redacted diagnostic show 'Export failed: Invalid Trace events[0]: dangling parent_event_id 'event-000002''.
- Full trace, after its confirmation, also exposes an internal id ('…dangling parent_event_id 'console-trace:<uuid>:retrieval:retrieval_completed'').

No file is written, the dialog offers no recovery, and one such turn makes the whole conversation unexportable. Trace export is the documented way to share a diagnostic, and it fails exactly when a user needs it. Verifier correction to the original title: an ordinary two-turn chat with no Library sources does export successfully under Redacted and Safe.

**Verified cause.** On the staged-evidence paths (evidence_bundle and frozen capture), `context_attached` events reference a retrieval parent event that is never recorded, and the exporter rejects the whole bundle over the orphaned reference.

**Prior art:** TASK-19913 (Done; export v2 with privacy preflight); trajectory_export.py:1016-1030; commit 794128caf7; TASK-31714 (Done); TASK-32048 (Done); PR #2882 (229c570b5b).

**Suggested direction:** fix the producer so staged-evidence turns record the referenced retrieval event, or point their parents at a recorded event. Harden the exporter to clear or re-parent orphaned references to the turn root and record a 'reference_not_recorded' missing-metadata entry, so stored conversations become exportable again. Map TrajectoryExportError in TraceExportDialog to plain copy with a recovery action, and log the full error with the conversation id.

Evidence: qa/console-ux-review-2026-09-29/findings.md → GAP5-06; qa/console-ux-review-2026-09-29/evidence/evidence__GAP5__46c-trace-export-enter.txt, evidence__GAP5__46f-safe-export.txt. Code: tldw_chatbook/Widgets/Console/trace_export_dialog.py:340-357 (exception text shown verbatim).

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The media cleanup builds its cutoff in a different shape from the column's writer, so `hard_delete_old_media` and `get_deletion_candidates` skip rows soft-deleted on the cutoff's calendar date. Reproduced: a row older than the cutoff returns zero candidates, and the same predicate with the cutoff in the stored shape returns one. A third path compares with yet another shape, and one of them also uses a deprecated clock call.

Source: core-runtime code review 2026-09-17 — `qa/core-code-review-2026-09-17/report.md`; per-slice evidence in `qa/core-code-review-2026-09-17/slices/`, reproductions in `qa/core-code-review-2026-09-17/phase4-verification.md`.
<!-- SECTION:DESCRIPTION:END -->

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
`InputError`, `ConflictError` and `SchemaError` are defined separately in ChaChaNotes_DB, Client_Media_DB_v2, Prompts_DB and Evals_DB. The names match but the classes don't: their bases differ (`CharactersRAGDBError`, each store's own `DatabaseError`, `EvalsDBError`), and so do the `ConflictError` constructors. Code cannot catch, say, a conflict from any store with one handler. Well over 70 `except CharactersRAGDBError` handlers rely on the ChaChaNotes classes subclassing their store base, so the per-store hierarchy has to stay.

Source: architecture review 2026-10-25, `Docs/QA/architecture-review-2026-10-25/report.md` §F13; claim-by-claim verification in `Docs/QA/architecture-review-2026-10-25/verification.md` (origin/dev 7a5e2513c5).
<!-- SECTION:DESCRIPTION:END -->

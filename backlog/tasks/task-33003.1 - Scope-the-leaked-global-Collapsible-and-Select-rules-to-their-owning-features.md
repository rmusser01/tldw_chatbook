## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Three unscoped global rules shape every Collapsible and Select in the app, including those in the Chat settings modal:
- css/features/_conversations.tcss:298-303 forces every CollapsibleTitle to 3 rows. An .-active variant sits at :305-310.
- css/features/_conversations.tcss:313-316 makes every Select full width and puts a blank row beneath it.
- css/features/_evaluation_unified.tcss:59-63 gives every Collapsible a tall border and a bottom margin.

Add Textual's default padding and the section margin, and a collapsed section in Chat settings costs about 7 rows while every Select row gains a blank line (verified-claims C5, corrected points (a) and (b)).

The leak is already known. css/components/_agentic_terminal.tcss:1741-1744 overrides it for one canvas (task-2043) instead of fixing the source. Several MCP tests exist only to defend against the Select rule under the production bundle (Tests/UI/test_console_mcp_approval.py:1970, Tests/UI/test_mcp_tools_mode.py:825-897, Tests/UI/test_mcp_schema_form.py:581). Scoping these rules to the features that own them fixes the root cause for every screen at once. It is also the precondition for measuring one-row controls in Chat settings.
<!-- SECTION:DESCRIPTION:END -->

**Approach.** Neither sheet has a live owning root, so the leaked rules were deleted rather than rescoped, following the TASK-18960 Checkbox precedent (ruling 6):
- `features/_conversations.tcss` styles `#conversations_characters_prompts-window`. No Python composes that id or any `ccp-*` id; TAB_CCP aliases to PersonasScreen. Its child widgets do compose Selects and Collapsibles (for example the preview and lore panes), none inside the dead CCP root, so its layout changed with everyone else's (see `dest-personas` under AC#3).
- `features/_evaluation_unified.tcss` targets `EvalsWindow`. No such class exists, and the live EvalsScreen composes no Collapsible.

Retired rules: bare `Collapsible { margin-bottom }`, `Collapsible > CollapsibleTitle { height: 3; ... }` and `Select { width: 100%; margin-bottom: 1 }` (conversations), plus `Collapsible { tall border; $panel }`, `Collapsible > Container { padding: 1 }` and `Collapsible.-collapsed { margin-bottom: 1 }` (evaluation_unified). `Collapsible.-active > CollapsibleTitle` stays: nothing sets `-active`, and test_non_obscuring_focus_contract pins it (ruling 8).

Ruling 5: `ConsoleSettingsModal Collapsible { min-height: $ds-size-0; padding: $ds-space-0; border: none; background: $ds-surface-panel }` in `features/_console_panels.tcss`. It drops the global `_widgets.tcss` frame and Textual's padding-bottom, so a collapsed section is 1 title row plus the section's 1-row top margin. That is 2 rows; before it was 7.

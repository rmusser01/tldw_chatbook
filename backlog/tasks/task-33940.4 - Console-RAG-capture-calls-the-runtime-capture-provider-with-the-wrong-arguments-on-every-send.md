## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Every Console send logs "Console RAG capture unavailable; reason=capture_provider_failure". With exception logging added, the cause is `TypeError: ConsoleRuntime._capture_frozen_console_staged_rag() missing 1 required positional argument: 'launch'`. The production controller (built by ConsoleRuntime) is wired with a three-argument provider, but `_capture_rag_context` calls it with two, and ConsoleRuntime lacks the staged-evidence snapshot hooks that would select the frozen path. The exception is swallowed without a traceback, so Library retrieval for a send silently never happens and the trace records a false "Retrieval failed". This is review finding G2-37 (listed under TASK-33621), which has no task of its own.

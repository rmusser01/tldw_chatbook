## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Three Console surfaces pay the config-read cost per row or per tick: the turn-file-card row build reads a setting once per row (20 rows turn a 1.2 ms pass into 107.9 ms), the workspace switcher's `compose()` runs a synchronous sqlite select per workspace row and re-reads records its caller already fetched off-thread, and a workspace title is derived on every 0.2 s transcript tick and thrown away -- about 11.5 ms per second of main-thread sqlite for the whole of every streaming run. The fix for the last one already exists three methods away in the same file.

## Implementation Notes

Landed on PR #2739 (`fix/core-review-loop`), commit `perf(console): stop
per-row/per-tick config + registry reads`.

- **Per-tick title (session.py)** — `_sync_console_session_draft` already
  computed `creating_blank_session`; wrapped the `_workspace_initial_session_title`
  call in the same `if creating_blank_session else DEFAULT_CONSOLE_SESSION_TITLE`
  conditional the verified TASK-26839 sibling three methods up uses, and applied
  the same guard (plus the missing `creating_blank_session` computation) to
  `_replace_active_console_session_settings`. `ensure_session` discards `title`
  when a session is active, so the synchronous `get_workspace` SQLite query is
  now skipped on the 0.2 s streaming poll.
- **Turn-file-card per row (console_transcript.py)** — added
  `_turn_file_cards_enabled()` (reads the module-level `get_cli_setting` once)
  and threaded the bool through `_build_row_widget` / `_build_message_widget` /
  `_update_row_widget`, with each pass entry (`compose`, `_message_widgets`,
  `_reconcile_rows`, `_sync_assistant_turn_widget`) reading once. Kept the
  module-level `get_cli_setting` name so the existing
  `test_summary_row_stays_plain_marker_when_disabled` patch point (and its
  disabled-toggle behaviour) stays valid.
- **Switcher re-read (console_workspace_switcher_modal.py)** —
  `workspace_persona_label_suffix` now reads `assistant_defaults` off the
  passed-in `WorkspaceRecord` (which `_open` already fetched off-thread via
  `list_workspaces`) instead of a per-row synchronous `registry.get_workspace`.

Probes/pins: new gate-free `Tests/Widgets/test_workspace_switcher_persona_suffix.py`
asserts the switcher never re-reads the registry per row and still resolves the
label (AC#2/#4). The turn-file-card toggle is pinned by the existing CI test
through the now-threaded path (AC#1/#4). The session change mirrors the
already-covered TASK-26839 sibling; its cost was measured in the review
(uim_console_probe: 11.48 ms/s at 5 Hz for a real workspace) (AC#3/#4). The
full-harness `_sync_console_session_draft` path trips the ADR-126 storage gate
locally, so no new gate-bound test was added for it.

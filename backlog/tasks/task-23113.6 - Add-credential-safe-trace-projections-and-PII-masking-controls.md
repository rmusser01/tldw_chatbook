## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Apply mandatory credential filtering, optional built-in PII detection, immutable frozen mask projections, and Safe or Full display profiles to the same trace without redacting the ordinary saved transcript.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Known credential fields and credential-like values are filtered before durable trace storage in every header, artifact, event, response, error, export, and log path.
- [x] #2 Provider-only PII transformation is irreversible, while canonical-message content remains unchanged and resolves through immutable frozen mask projections.
- [x] #3 Safe and Full are display profiles over one trace; both honor active masks, and Full reveals no previously hidden field unless the user explicitly changes the current view.
- [x] #4 Settings migrate existing capture choices conservatively and make Capture On, display profile, and PII masking independently understandable.
- [x] #5 Inspector copy and export use the same projection policy as on-screen rendering and never bypass mandatory credential filtering.
- [x] #6 Dense credential-like and PII-like fixtures exercise bounded scanner work and all durable storage owners are inspected for leaks.
- [x] #7 ADR required: yes; this task implements the privacy and security policy in ADR-097.
<!-- AC:END -->

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Since TASK-33621.21 the in-app model download works, so what Cancel does to it is now visible. Cancel (or leaving the screen) ends the attempt at once, but the warm-up daemon thread keeps downloading the full model (2.4 GB for parakeet-mlx), and when it finishes it loads the model into a service that was already released, briefly holding a second copy in memory. The User Guide says the download continues; there is no way to stop the network and disk use short of quitting.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Pressing Cancel while a model download runs either stops the download within a bounded time, or the Console says plainly that it continues and how to stop it
- [ ] #2 A warm-up that finishes after Cancel does not leave a second loaded copy of the model in memory
- [ ] #3 A later Dictate press after Cancel reuses the bytes already downloaded instead of starting over
- [ ] #4 Cancel, timeout and screen replacement cannot admit overlapping Console model preparation; late completion cannot open a microphone or publish stale success

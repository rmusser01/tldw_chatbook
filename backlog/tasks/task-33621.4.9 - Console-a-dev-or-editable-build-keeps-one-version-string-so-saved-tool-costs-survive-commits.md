## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Round-6 review of TASK-33621.4 (2026-11-23). The saved agent tool cost is keyed by a signature that includes the app version, standing in for the built-in tool catalog. A source-tree or editable install keeps one version string (0.2.3) across commits, so a figure saved before a commit that grew the built-in tools stays in use after it, until the next send measures again. A released install changes the version with every release, so this affects development builds only. A possible fix is a git-describe suffix on the version when the app runs from a source tree.

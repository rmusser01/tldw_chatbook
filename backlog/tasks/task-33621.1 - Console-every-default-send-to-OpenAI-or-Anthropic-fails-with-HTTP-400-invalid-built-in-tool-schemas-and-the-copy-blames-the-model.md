## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
**Impact (P0, triage NEW).** On a default profile (setup complete, local tools on by default) every Console send to Anthropic `claude-haiku-4-5` and OpenAI `gpt-4.1-mini` fails with HTTP 400, including direct sends with no proxy and repeat sends. The user sees 'Assistant Failed / Response failed.' and a System row: 'Agent run failed: provider returned HTTP 400 (Provider error from <provider>: bad request. Status: 400. Selected model: <model>. The provider rejected this request. Confirm the model is still available, or choose another model from the model picker.)'. For the two most common cloud providers, the core loop is broken out of the box.

**Verified cause.** Three built-in tools in `tldw_chatbook/Agents/local_tool_provider.py` declare top-level schema combinators: `watchlists_update_collection_sources` (anyOf), `watchlists_check_sources` (oneOf) and `todo_update` (anyOf+allOf). Both providers reject each one on its own. The recovery advice is wrong: claude-sonnet-4-5, claude-opus-4-1, gpt-4o-mini and gpt-4.1 reject the same schema, so changing the model cannot help. The OpenAI path logs the provider body (`tools[34]`, `invalid_function_parameters`). The Anthropic path logs only 'Handler for anthropic directly raised; error_type=ChatBadRequestError; status=400', with no provider message.

**Prior art:** the tools were introduced by TASK-22862 and TASK-22863 (watchlists) and TASK-13216 (todo). The misclassified-400 family includes TASK-32342 (Done) and TASK-32369 (To Do). TASK-399 covers anyOf support in schema forms, which is unrelated to provider tool schemas.

**Suggested direction:** flatten the three schemas to type=object with properties, required and additionalProperties. Enforce 'at least one of add/remove', 'exactly one of source_ids/collection_id' and 'deleted excludes content/activeForm' in the handlers, and state each rule in the tool's description. Add a provider-schema conformance test over every disclosed tool schema, or sanitise at projection time. Classify provider 400s that name a tool or parameter as 'tool definition rejected: <tool>' and drop the 'choose another model' advice for that class. Log a redacted provider message on the Anthropic error path. The general copy mechanism is handled with G4-06.

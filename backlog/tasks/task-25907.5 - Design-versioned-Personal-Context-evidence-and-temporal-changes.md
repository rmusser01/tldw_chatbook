## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Define how a memory can cite an exact source safely and distinguish an explicit assertion, inference, correction, scoped exception, and real change over time.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 A reviewable ADR and shared-core design define authority-bound source locators, source versions and spans, evidence availability, and access checks without treating bare IDs as portable authority.
- [x] #2 The design distinguishes source presence, semantic support, user approval, confidence, salience, and temporal validity; quoted or attached instructions never become user intent automatically.
- [x] #3 Correction, supersession, and workspace exceptions have explicit behavior without automatic newest-wins overwrite or inferred certainty.
- [x] #4 Existing V1 records retain truthful unknown/legacy states; migration, schema negotiation, canonical-byte fixtures, and server compatibility obligations are specified.
- [x] #5 Retention and disclosure rules cover source evidence and derivatives, with synthetic acceptance examples for edited, missing, inaccessible, and conflicting evidence.
- [x] #6 The deliverable is a reviewed design; no production schema or behavior changes occur under this task.
<!-- AC:END -->

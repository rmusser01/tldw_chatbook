## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
**Impact.** This breaks the promise that 'each tab runs its own agent'. With a run live in tab B, the reviewer clicked tab A and typed a prompt; pressing Enter 1.5-2.2 s later queued it into B each time (B's tab showed 'Q1'), and B answered it. A received nothing. In one trial the screen already showed A (highlighted tab, A's transcript) at the moment of Enter. The composer, however, still held B's leftover draft, and the merged 68-character text 'Reply with the single word ECHO.Count from 1 to 20 in Swedish words.' was sent to B as one turn. The click is acknowledged late: during a run B stayed highlighted for over 2.6 s and the view flipped about 4.4 s after the click (about 2-3 s when idle). Idle, text typed 0.4 s after a tab click was lost from both composers, and its 'y' opened Trace. The prompt runs with the wrong chat's context, tools and approval authority, spends tokens, and nothing on screen reveals it. Reproduced 3/3 on dev 64579cce2c at 235x52 with a slow proxy. Verdict severity P1; the reviewer rated it P0.

**Cause (verifier-corrected).** The finding blamed `await begin_manual_read_visit` in session.py, but moving that alone will NOT fix this. `_activate_native_console_session` relies on the coalescable console-sync pass to rebind the composer. When a pass is already running (routine during live runs), the call only sets a 'sync requested' flag. The in-flight pass already synced the draft to the old session, then paints the new session's tabs and transcript. Enter then pins the send to the stale visible-draft session id.

**Severity / prior art.** P1, triage NEW. Related: session.py read-visit seam added in d6e2a46384 (PR #2725) under TASK-32826 (In Progress). TASK-26834 (To Do) covers switch latency only, not misrouting. TASK-14808 (Done).

**Suggested direction.** Bind the composer to the new session synchronously as part of activation, saving the old draft to its owner and loading the new one, before any await and independent of the sync pass. Update the tab highlight in the same step. In the send path, refuse visibly and keep the draft when the composer's bound session differs from the active tab. Keep typed keys going to the composer during a switch, so tab-button focus cannot route letters to single-key bindings. Coordinate with TASK-26834 and TASK-32826.

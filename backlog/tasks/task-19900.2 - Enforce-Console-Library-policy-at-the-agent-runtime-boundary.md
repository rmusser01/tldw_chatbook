## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Make the executed turn snapshot the sole authority for built-in assistant
Library access while preserving ADR-030's Direct-versus-RAG selection.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 The executed turn captures immutable Library authority after the durable
      policy coordinator's execution-time fresh read, then combines it with a
      post-gateway immutable resolved destination before retrieval or provider
      composition; a stale Allowed holder cannot survive a concurrently
      committed Blocked revision.
- [x] #2 Blocked or unreadable policy registers no built-in Library provider for
      the primary agent or any subagent.
- [x] #3 Allowed plus Direct exposes exactly the 18 ADR-030 tools; Allowed plus
      RAG exposes exactly `search_library_rag`.
- [x] #4 The union of all 19 built-in Library names remains reserved against
      Skill and MCP collisions in Blocked, Direct, and RAG states; the set is
      derived from the descriptor registry plus RAG constant and ratchet-tested
      against drift.
- [x] #5 Queued turns capture at actual execution, running turns remain immutable,
      and subagents inherit without widening the parent snapshot.
- [x] #6 Temporary sessions admit only the authenticated built-in Library provider
      and exact audited read-only names when Allowed; source spoofing, unknown
      names, and Blocked policy remain refused.
- [x] #7 Gateway-resolved endpoints classify as on-device, private network, public
      network, or external/unknown without provider-name/API-key heuristics;
      destination changes retain policy and expose a persistent pre-dispatch
      disclosure through UI-neutral runtime state whenever Automatic or
      Assistant Allowed can place Library data in the request.
- [x] #8 Targeted catalog/runtime/concurrency tests pass and mutation-check both
      provider absence, execution-time policy freshness, conservative egress,
      ephemeral gating, and permanent name reservation.
<!-- AC:END -->

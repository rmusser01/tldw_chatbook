## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Slice D5 (spec §4.3). In the reader, `q` inserts a quote at the working note's caret without moving focus. It quotes the mouse selection if there is one; otherwise it quotes the paragraph under a keyboard paragraph cursor that `j`/`k` move. The cursor is a focus-edge bar plus `¶n of N` in the status line. The attribution is `[title, ¶n](media://<uuid>#p<n>-<fp>)` with the paragraph fingerprint (spec §5.1). The receipt `Quoted ¶n of <title>` appears in the note's status. With the desk closed, `q` opens it first, using the Write in… picker if no working note is set.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 `q` with a mouse selection quotes the selection; without one it quotes the paragraph under the cursor; the inserted text is a blockquote followed by the attribution link carrying `#p<n>-<fp>`
- [ ] #2 `j`/`k` move the paragraph cursor on Rendered and Raw views alike (stored-text blocks); the status line shows `¶n of N` and a Quote button
- [ ] #3 Quoting from a second document into the same working note adds that document to the note's Sources on save
- [ ] #4 Items with no text show `○ Quote — no text in this item`
- [ ] #5 Pilot tests (quote insertion, cursor movement, Raw-only item, cross-document Sources) fail on dev before the change; verified live at 160x45 and 120x36
<!-- AC:END -->

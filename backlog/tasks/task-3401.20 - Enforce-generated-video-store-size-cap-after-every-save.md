## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Keep ephemeral generated-video storage bounded throughout a long-running app session. ADR-044 and TASK-3401.4 require the configured total size cap in every retention mode, but the current cap is evaluated only when retention enforcement runs and is not applied after new videos are saved.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 After each successful video save, the active store is at or below the configured total size cap.
- [ ] #2 Oldest live videos are evicted first and their existing cards resolve as expired without affecting newer videos.
- [ ] #3 Post-save cap enforcement never reapplies session-retention startup cleanup.
- [ ] #4 Focused tests fail if cap enforcement is removed from the save path or if eviction order changes.
<!-- AC:END -->

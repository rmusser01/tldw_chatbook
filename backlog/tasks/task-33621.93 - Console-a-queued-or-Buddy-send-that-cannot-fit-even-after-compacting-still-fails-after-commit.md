## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
From the TASK-33621.4 review. When compacting cannot make a send fit (the probe returns an alert), the composer refuses it before commit with the reason. A queued follow-up or a Persona Buddy reply in that state is not refused before commit: under Ask the refusal names /compact, which cannot help, and otherwise the send reaches the post-commit block and is marked Failed. Unchanged from dev before TASK-33621.4, which narrowed it for the Ask hold only. Widened 2026-10-30 (second review): Continue, Regenerate, Retry and Edit & resend (refuse_at_ask_trigger) and a send with no preparation (a dollar-sign or slash draft while capture is off; refuse_unprepared) also ignore the alert and say 'Run /compact' when compacting cannot help.
<!-- SECTION:DESCRIPTION:END -->

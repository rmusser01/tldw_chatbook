## Description

Establish a deterministic shared calculation for exact source representation and Unicode span identity so future evidence bindings can use the accepted conventions without changing current profile behavior.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 An explicitly imported data-only shared-core API returns immutable named lowercase SHA-256 digests for the entire exact UTF-8 representation and its zero-based half-open Unicode codepoint span.
- [x] #2 The accepted Hi 👋 — café vector matches both fixed digests; astral characters count once and normalization, line-ending conversion, altered offsets and outside-span source edits do not masquerade as the same identity.
- [x] #3 Wrong input types including boolean or fractional offsets and invalid span bounds are rejected without coercion or slicing truncation; unencodable Unicode anywhere in the representation is rejected before returning digests.
- [x] #4 Empty spans have explicitly documented deterministic hash behavior at valid boundaries and do not establish evidence support or authorize source use.
- [x] #5 Targeted synthetic tests exercise the actual API with fixed independent expected vectors and invalid controls; existing V1 canonical, model and schema fixture checks remain passing and unchanged.
- [x] #6 The helper and its limits are documented and reviewed; no source lookup, source body persistence, V2 schema advertisement, V1 canonical or wire change, migration, permission, grant, provider or background behavior is introduced.
<!-- AC:END -->

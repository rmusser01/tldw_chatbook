## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
In Switch model, typing a provider's name into Find ranks rows by text match alone, so an aggregator whose model ids start with that name (OpenRouter's openai/...) can outrank the named provider's own rows, and the named provider's row can be the last of the 30 listed. Found by Phase 8's Task 2 review (TASK-33008.2): after a return from Settings the reopened switcher highlighted an aggregator's model for a provider that lists none. Phase 8 fixed the reopen case only (never highlight another provider's row on a reopen). This rider is the typed-query ranking.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 When Find's text is exactly a provider's display name or id, that provider's rows are listed before other providers' rows that merely match the text

- [ ] #3 A test drives the two measured cases: a provider with an empty list beside a ready aggregator whose ids start with its name, saved and unsaved

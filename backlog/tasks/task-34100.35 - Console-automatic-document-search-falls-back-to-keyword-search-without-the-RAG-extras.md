## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
First-run setup's Search step and Console's "search my documents automatically" switch only do anything when the optional RAG extras are installed: without them Console's automatic retrieval refuses to run (the Library's local RAG search returns a blocked outcome for rag mode). Library keyword search (SQLite FTS5) works on every install, so a user without the extras could still get automatic, keyword-ranked context from their own documents.

The review finding [fulltrack-11] asked setup to offer the switch without the extras. On 2026-10-20 the owner ruled that setup should instead show the switch as unavailable and say why (TASK-34100.13 AC#5), and that the keyword fallback is this separate task.
<!-- SECTION:DESCRIPTION:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Both AC arms implemented (guidance AND sized-to-content); 16 modal tests green including 2 new pins.

- `Widgets/Console/console_context_modal.py`: the empty Current tab now renders a 3-line guidance label ("No conversation context yet. / Messages you send and receive will appear here. / The Next Send tab shows the exact payload …") instead of a bare one-liner; the kept prefix means the existing "No conversation context" pin still matches. `_update_view` toggles a `context-empty` class on `#console-context-modal` when `snapshot.current_messages` is empty; CSS `#console-context-modal.context-empty { height: 20; }` compacts the modal from the fixed 95×40 to a content-appropriate height (populated state keeps 95×40 — a full data viewer earns the room).
- The guidance label deliberately carries NO widget id: `_update_view` rebuilds children on every reactive fire and `remove_children()` unregisters lazily, so a fixed id collided on the second rebuild (DuplicateIds crash caught by the test sweep); tests locate the label by content in the Current container instead.
- Tests: `test_context_modal_empty_state_compacts_modal_and_guides` (class + guidance copy + region height ≤ 22) and `test_context_modal_populated_state_keeps_full_height` (class absent).

Files: `tldw_chatbook/Widgets/Console/console_context_modal.py`, `Tests/UI/test_console_context_modal.py`.

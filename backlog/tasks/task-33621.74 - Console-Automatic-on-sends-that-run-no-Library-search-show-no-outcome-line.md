## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
TASK-33621.51 shows what each Automatic Library search did on its USER turn, projected from the persisted library_preparation record. Some sends made while Auto is Automatic run no automatic search at all, so they persist no record and show no line, and a user cannot tell them from a turn sent before the record existed. Seen live 2026-10-29: an Edit & resend branch on an Automatic chat ran no search (the model had no evidence) and showed no line. Code reading says the same holds for a send whose evidence was already staged (manual Search Library or a Use in Console handoff) and for turns sent while a chat was temporary (no durable acceptance writes the record, and saving the chat later does not add it). Decide per case whether the send should search, record a 'no automatic search' outcome, or stay silent, and document the choice.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Each Automatic-on send path that runs no automatic search (Edit & resend, staged evidence, temporary chat) has a decided and documented behaviour: it searches, it shows a line saying why no search ran, or it deliberately shows nothing

- [ ] #3 A test on the real controller and transcript covers each decided path

## Implementation Notes

<!-- SECTION:IMPLEMENTATION_NOTES:BEGIN -->
Plan: make the modal's projection a public attribute and have the runtime read that.

Renamed `_console_hook_review_projection` to `hook_review_projection` on the hook-review modal (console_hooks_review_modal.py) and its two runtime reads (console_runtime.py `_hook_review_presentation_current`, `_project_pending_decision_to_attached_view`); test fixture retargeted. No other references under Tests/ or tldw_chatbook/.

Guard: `test_console_runtime_reads_no_private_screen_attribute` (AST, Tests/Chat/test_console_initial_hook_review.py). RED on base code (fails, offending reads), GREEN after rename.

Fix round 1: the guard is now general (`_private_screen_reads`): flags `_x` (non-dunder) attribute reads and `getattr(..., '_x')` on screen-valued expressions (names view/screen/current/modal/top, `.view`/`.screen`, `screen_stack[...]`, locals bound by iterating `screen_stack` or assigned from such). Values not statically screens (e.g. a bare callable named otherwise) are not flagged; the bound is that screens enter the runtime through those names. It found a second real violation (`getattr(self.view, '_start_console_transcript_sync_timer')`), now the public `ChatScreen.request_transcript_sync()`. Red via temporary edits, two shapes: `screen._x` in the `screen_stack` loop (line 5668) and `getattr(self.view, '_x')` (line 1656), both reverted; plus 4 parametrized detector-shape tests. Contract: `Chat/hook_review_screen.py` (`HookReviewScreen` Protocol + `screen_hook_review_projection`), used by the runtime; modal attribute commented as public.

Tests: 171 passed in the hook/runtime set; `Tests/UI/test_console_initial_hook_review.py::test_stopped_review_retires_after_covering_modal_is_removed` fails identically at base 5ca7ec6a03 (stop_active_run() False), pre-existing.

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
ConsoleRuntime no longer reads any private screen attribute. The hook-review projection is a public modal attribute read through a declared `HookReviewScreen` Protocol, the transcript-sync request goes through a public `ChatScreen.request_transcript_sync()`, and a general AST guard enforces it.

## Description

Remove the inset workspace side frame and redundant descendant borders so Context and Inspect own the application edges below the full-width header with one stable divider per rail.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 The full-width Console header remains unchanged while the workspace grid has no left/right padding or surrounding side frame and Context/Inspect touch the application edges whenever visible.

1. Add production-shaped compositor RED coverage using the exact `TldwCli.CSS_PATH` stack for expanded, collapsed, focused, responsive-width, and short-height edge/divider ownership.

3. Rebuild `tldw_cli_modular.tcss` only through the canonical CSS builder and verify source/bundle integrity.
4. Run the focused GREEN gate plus mutation checks for the grid inset, transcript/full inline frame, and focus full-edge regression.
5. Run scoped Ruff/format/diff checks and the one final Impeccable layout detector pass, then record evidence and complete the child task.

## Implementation Notes

- Removed the workspace horizontal inset and redundant full/rounded descendant frames. The grid now owns top/bottom only, Context and its handle own right, Inspect and its handle own left, and the transcript owns no frame edge.
- Corrected the approved plan before production work because source TCSS alone could not override Textual 8.2.8 inline borders. Narrowed the existing `frame_console_region()` and focus-painter seams to explicit edge ownership; focus repaints only the owned divider and adds a stable bold/underline/background control cue without geometry changes.
- Added exact-production compositor coverage at 100/120/150 columns plus short height, expanded/collapsed rails, physical hit ownership, single-divider geometry, focus stability, and canonical source/bundle rules. Initial RED was 8 failures: seven physical compositor cases at the inherited two-column grid inset and one source/bundle rule failure at `padding: 0 1`.
- Rebuilt `tldw_cli_modular.tcss` through `../../.venv/bin/python -B -m tldw_chatbook.css.build_css`. Focused GREEN: 75 passed with two pre-existing dependency warnings. Mutation checks each failed their intended oracle: grid inset moved content to x=1; transcript side framing restored solid left/right edges; focus full-frame shorthand moved rail content geometry.
- Scoped Ruff, format, CSS integrity, and diff checks passed. The one final Impeccable layout detector run returned `[]`: zero rules, zero findings, and therefore no locations or false positives.
- Existing ADR-081 applies; no new ADR was required. ADR-043 responsive floors, priority, single-pane behavior, stored intent, and focus handoff remain covered and unchanged. No generalizable new testing or implementation trap beyond the already-recorded inline-style/CSS lessons was surfaced.

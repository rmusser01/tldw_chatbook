## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Remove the inset workspace side frame and redundant descendant borders so Context and Inspect own the application edges below the full-width header with one stable divider per rail.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 The full-width Console header remains unchanged while the workspace grid has no left/right padding or surrounding side frame and Context/Inspect touch the application edges whenever visible.
- [x] #2 Context/transcript and transcript/Inspect each have exactly one divider owner across expanded, collapsed, focused, and responsive states; transcript, rail roots, handles, and descendants do not retain redundant full or rounded frames.
- [x] #3 Focus emphasis is paint-only, visible without color, and does not change any region, divider, hit target, or sibling position.
- [x] #4 ADR-043 explicit-open width floors, Inspector priority, single-pane behavior, transcript reachability, collapse/reveal focus handoff, and stored rail intent remain unchanged at the established width boundaries.
- [x] #5 Production CSS compositor tests load the exact `TldwCli.CSS_PATH` stack and prove containment, edge alignment, hit ownership, and single-divider geometry before and after resize; the canonical CSS build regenerates only the intended bundle changes.
<!-- AC:END -->

## Implementation Plan

1. Add production-shaped compositor RED coverage using the exact `TldwCli.CSS_PATH` stack for expanded, collapsed, focused, responsive-width, and short-height edge/divider ownership.
2. Remove the workspace grid's horizontal inset/side frame and redundant transcript/rail/handle frames in source TCSS. Narrow the existing `frame_console_region()` call seam and Console focus painter to explicit divider ownership because their inline borders outrank TCSS in Textual 8.2.8. Preserve omitted-`edges` helper compatibility, pass `edges=()` explicitly in both transcript compose paths, and recompute the same truthful focus paint on descendant focus and blur-to-none.
3. Rebuild `tldw_cli_modular.tcss` only through the canonical CSS builder and verify source/bundle integrity.
4. Run the focused GREEN gate plus mutation checks for the grid inset, transcript/full inline frame, and focus full-edge regression.
5. Run scoped Ruff/format/diff checks and the one final Impeccable layout detector pass, then record evidence and complete the child task.

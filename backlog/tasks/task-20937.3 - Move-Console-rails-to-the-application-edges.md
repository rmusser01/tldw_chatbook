The grid owns top/bottom only, Context and its handle own right, Inspect and its handle own left, and transcript owns no frame edge. Existing ADR-081 applies; no new ADR was required, and ADR-043 responsive policy remains unchanged.
- Corrected the approved plan before both production passes: first for Textual 8.2.8 inline-border precedence, then to authorize the four legacy regression files whose full-frame assertions conflicted with ADR-081. The exact five highlighted legacy nodes reproduced 5/5 RED and now preserve their sizing, keyboard, structural-separator, empty-region, and decomposition intent under single-divider ownership.
- Transcript F6/native focus reproduced RED with no non-color title cue (`text_style.bold is None`). A narrow existing focus-painter class now drives declarative bold/underline/background on only the stable transcript title; a monochrome oracle equalizes the title and transcript palette and still sees the typographic cue. Focus leave clears it, transcript content is not underlined, and regions/hits do not move.
- Added same-pilot production compositor checks at 150 → 120 → 100 → 100x24, reasserting application edges, divider/outer/near-edge hit ownership, stored rail intent, focus handoff, and transcript reachability after every resize. Added focused/unfocused collapsed Context and Inspect handle cases with stable geometry and non-color button cues.
- Rebuilt `tldw_cli_modular.tcss` only through `../../.venv/bin/python -B -m tldw_chatbook.css.build_css`. Expanded focused GREEN: 84 passed with two pre-existing dependency warnings. Scoped Ruff, changed-range format, CSS integrity, and diff checks passed.

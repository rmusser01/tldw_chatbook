## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
**Approach.** New zero-import leaf `tldw_chatbook/Widgets/glyph_fallback.py` owns the opt-in substitution: a char→ASCII `ASCII_GLYPH_FALLBACKS` map keyed by CHARACTER (so every import path to the same glyph resolves identically), process-wide module state (`set_ascii_glyph_mode`/`ascii_glyph_mode`), and two resolvers — `resolve_glyph` for single markers, `resolve_glyph_text` for composed labels. ASCII mode is OFF by default, so the shipping glyph set is byte-identical; every resolver is mode-gated and unknown glyphs pass through untouched. Resolution happens at glyph-PRODUCTION points, so string pipelines (tab labels, chip text, browser rows) carry the resolved forms downstream unchanged.

**Config + settings.** `appearance.ascii_glyphs` (bool, default false) in the `config.py` template; `app.py` `compose()` applies it once via `set_ascii_glyph_mode` before widget construction. Settings > Appearance gains an "ASCII glyphs" toggle replicating reduce_motion's full surface (ownership record, validation message key, field selector, focused-field guidance, compose row + tooltip, toggle handler, post-save label re-sync) with `settings_appearance_defaults.py` load/coerce/validate/save support; the handler also applies the mode live so repaints switch without relaunch.

**Resolved production points.** Console: session tab temporary + run markers, tab close + fleet-coachmark dismiss buttons, sidebar run-marker rows, voice warmup prefix, both rail collapse handles, workspace-context section/group disclosure toggles, scope-picker source glyphs, composer draft caret (focused + placeholder paths), attachment 📎 indicator, "Composer ▾" collapse button, ✕ clear-attachment button, voice-chip recording head and transcribing label (both use-sites). App-wide: `destination_rail` disclosure property, which fixes every rail handle consumer. `conversation_browser_state._RUN_MARKER_URGENCY` gained the four ASCII keys as literals, preserving its no-Chat-import discipline (ADR-034).

**Deliberate scope cuts.** Emoji action icons (👍👎🗑♻🖼) are action labels, not status markers, and stay as-is; non-Console destinations' own literals (Evals library rail, watchlist tree caret, settings indicators, legacy Chat widgets' 📎) are out of Console scope; `console_rail_state.py`'s CONTEXT/INSPECTOR label constants stay unicode because `console_rail_handle.py` compares against them by equality — resolving there would break the handle's identity check.

**Tests.** Extended `Tests/Chat/test_console_glyphs.py` with map-completeness over the full vocabulary (console_glyphs constants + run-marker glyphs + rail disclosure pair + CURSOR_GLYPH + 📎), pure-ASCII/nonempty fallbacks, default-mode identity, mode-on substitution incl. unknown-glyph passthrough, `resolve_glyph_text` over composed labels, and a mode-on `_tab_label` stacking assertion (`[~] [*] scratch`) behind an always-restoring fixture. `Tests/UI/test_settings_appearance_defaults.py` gained the strict-bool rejection case, the exact-dict save-sections pin (`"ascii_glyphs": False`), and a default/coercion load test. **Evidence:** 1,382 passed / 0 failures across glyphs + settings-appearance-defaults (19), tab strip/budget + voice chip + scope picker (48), composer menu/collapse/cursor/overflow + workspace context + rail sections (236), dictation + destination rail + browser state + voice model (93), native-chat-flow (304), settings configuration hub (301), dictation firstrun/streaming + composition retirement (96), internals decomposition (127), destination visual parity (116), parallel runs (28), UI responsiveness (14). One load-dependent flake (`test_the_transcribing_indication_reverts_on_a_mid_capture_stop`, mic-label race — TASK-2155 family) passed in isolation and in a full-file rerun.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Sixteen byte-size formatters exist with no shared public helper, and their output drifts in ways users see: kilobytes against kibibytes, one decimal place against none, ladders that stop at gigabytes, terabytes or petabytes, and one that mixes decimal thresholds with binary divisors so 1,000,000 bytes renders as '1.0 MB'. A private helper in the shared utility module already does this correctly.

Source: core-runtime code review 2026-09-17 — `qa/core-code-review-2026-09-17/report.md`; per-slice evidence in `qa/core-code-review-2026-09-17/slices/`, reproductions in `qa/core-code-review-2026-09-17/phase4-verification.md`.

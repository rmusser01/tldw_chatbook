## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
ADR-036 keeps `TldwCli` as the composition root and defers a typed immutable services bundle until there is more than one real composition root. MCP's standalone server, the mobile web service and config's lazy singletons now each compose their own databases. Whether that meets ADR-036's trigger, and what shape the bundle takes, is the owner's decision. This task records it; it does not implement it.

Source: architecture review 2026-10-25, `Docs/QA/architecture-review-2026-10-25/report.md` §F1; claim-by-claim verification in `Docs/QA/architecture-review-2026-10-25/verification.md` (origin/dev 7a5e2513c5).

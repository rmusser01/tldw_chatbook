## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Found in the TASK-33621.5/.6 review (2026-10-29). TASK-33621.6 made Cancel send on a Trace capture blocked card discard the paused turn and return its message to the composer. The session refill rule never overwrites typed text, so if the user has typed in the composer since the send paused, the held message is restored nowhere: trace pauses are not shelf-releasable, so it is not returned to the conversation's own draft either, and Cancel has already discarded the turn. Separately, and predating TASK-33621.6, Cancel is refused with 'Accepted send cancellation could not be saved.' while the chat database cannot be written (for example a held write lock), so Cancel is not unconditional. The first gap was traced by reading the session refill rule (ConsoleSessionController's card-action path), not reproduced live: reproduce it first.

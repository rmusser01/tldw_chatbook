## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The 'More actions' open-flag survives a recompose into the import branch, which never composes the region the key handler dereferences, so pressing Escape raises `NoMatches` into the app exception handler and the app exits. The root fix is to reset the flag in `sync_state` so it cannot outlive the region it describes.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Two changes in library_prompts_canvas.py.

Root cause, sync_state (:330): more_actions_open is now cleared whenever the incoming mode is not 'editor'. compose() only builds #library-prompt-more-actions-region in editor mode, so the flag must not outlive it; sync_state is the controller's only state funnel (it ends in refresh(recompose=True)), so that is where the 'open implies editor mode' invariant belongs.

Defence in depth, on_key (:564): the Escape handler now uses query()/first() instead of query_one() for both the region and the opener. mode is a plain attribute, not a reactive, so a future path that changes it outside sync_state would otherwise re-open this crash.

Tests (Tests/UI/test_library_prompts_canvas.py): test_sync_state_out_of_editor_mode_clears_more_actions_flag pins the invariant, and test_escape_after_more_actions_survives_recompose_out_of_editor_mode pins the handler. Both fail on the pre-fix source (NoMatches on the dereference; flag still True after sync_state).

Note on the second test: driving Escape through pilot.press() passed against the UNFIXED code, because after the recompose the canvas no longer holds focus and on_key was never reached. It calls the handler directly instead. A green test proves nothing until it has been seen to fail.

Regression evidence: Tests/UI/test_library_prompts_canvas.py is 202 failed / 140 passed at HEAD before the change and 202 failed / 142 passed after; the failing NAME sets are identical (comm on sorted FAILED lists, both directions empty). The 202 are a pre-existing baseline red in this suite, untouched by this work; the +2 are the new tests. ruff E9,F63,F7,F82 clean.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Auto-titled Console tabs are labelled from the first message, so a Temporary tab's label is a clipped prefix of what the user typed. Since TASK-33628.1 the quit dialog names the affected tabs (its AC#2) with that same label, so a live quit read: Affected tabs: "Reply with exactly: OK temp...". The tab strip and the close dialog already showed this label, but it sits in tension with the loss inventory's content-free rule (TASK-14806 AC#7; TASK-33628.1 AC#2 says message content never appears in the quit dialog).

Decide whether the content-free rule allows the tab-strip label, or whether auto-titled tabs that were never renamed get a generic label in the loss dialogs.
<!-- SECTION:DESCRIPTION:END -->

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Credential resolvers disagree on whether an environment variable or the stored `api_settings` key wins. The hosted provider engine (33 presets) resolves explicit, then environment, then stored, citing an env-first repo rule; moonshot, zai and qwencloud resolve explicit, then stored, then environment; the custom-endpoint registry resolves environment then stored. CLAUDE.md states the stored key outranks the environment variable. A user with both set gets a different key depending on the provider family. Which order is correct is an owner decision; this task records it and makes every resolver follow it.

Source: architecture review 2026-10-25, `Docs/QA/architecture-review-2026-10-25/report.md` §F11; claim-by-claim verification in `Docs/QA/architecture-review-2026-10-25/verification.md` (origin/dev 7a5e2513c5).
<!-- SECTION:DESCRIPTION:END -->

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Fresh-lens review follow-up FU-2 (spec §5.13 "From spec to plan", item 2; cited by R33 in §0.6 and risk K11). The shared `DestinationHeader` renders its subtitle and status as markup, so untrusted text there (an item or server name such as `[/]` or `[@click=…]`) can raise `MarkupError` or run an app action. Sub-project B escapes the text at Roleplay's own call sites; this follow-up gives the shared header a literal (markup-off) mode so every destination is safe by construction.

Parent: TASK-33910 (Roleplay on the Library frame, sub-project B). Spec: `Docs/superpowers/specs/2026-10-02-roleplay-library-frame-design.md` (PR #2960).

**Scope:** a literal mode for the `DestinationHeader` subtitle and status, then re-run the Console, Lab and Roleplay header pins.
<!-- SECTION:DESCRIPTION:END -->

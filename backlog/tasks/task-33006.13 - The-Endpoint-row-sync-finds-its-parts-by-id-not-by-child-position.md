## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
`_sync_endpoint_row` (`Widgets/Console/console_settings_field_row.py`) no longer unpacks the row's children by position. It reads the Base URL input by id (`console-settings-base-url`), the label by its class (`.console-settings-modal-label`, what `_modal_label` builds) and New endpoint… by id. `ENDPOINT_NEW_BUTTON_ID` moved from `console_settings_modal.py` to the field-row module beside `ENDPOINT_ROW_ID`, and the modal imports it (its net line count is unchanged).

Test (red at fc9f3ec375 with `ValueError: too many values to unpack (expected 3)`, green after): `Tests/UI/test_console_settings_disclosures.py::test_the_endpoint_row_syncs_with_an_extra_child`. It mounts an extra Static at the front of the row, then moves the chat with pick mode's real callback and the controller's rebaser (llama.cpp to OpenAI and back), and checks that the label shows only beside the input and that New endpoint… keeps the row. The file is on the UI PR census whole.

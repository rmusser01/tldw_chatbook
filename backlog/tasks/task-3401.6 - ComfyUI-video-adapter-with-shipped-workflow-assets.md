## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Base and Spectrum MiniMax H3 API workflows ship as renamed sanitized copies; original exports and prompts are absent from the repository.
- [ ] #2 Base H3 is the ComfyUI default; Spectrum is opt-in and names `SpectrumApplyMiniMaxH3` when unavailable.
- [ ] #3 Prompt, seed, width, height, duration, numeric ratio, native 24 FPS, and MP4 format are applied or rejected before submission.
- [ ] #4 Submit, polling, cancellation, output enumeration, download, image upload, and trusted-origin behavior remain covered.
- [ ] #5 Real ComfyUI evidence confirms required classes, output descriptor, MP4, 864×480 defaults, five-second duration, 24 FPS, and audio.

## Implementation Plan

1. Follow the approved [MiniMax H3 workflow design](../../Docs/superpowers/specs/2026-08-09-comfyui-minimax-h3-video-workflows-design.md) and its [implementation plan](../../.superpowers/sdd/2026-08-09-comfyui-minimax-h3-video-workflows/task-1-brief.md).
2. Replace stale Wan/SVD workflow assets with sanitized, renamed MiniMax H3 API workflows, preserving only the approved H3 topology and control contract.
3. Enforce strict pre-submission parameterization and validation, then preserve the existing ComfyUI transport, cancellation, output, upload, and trusted-origin behavior.
4. Add focused adapter tests and obtain real ComfyUI evidence for the packaged H3 workflows.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Rider from the TASK-33001 final review (M4), pre-existing. ADR-012 treats `credential_source` as an explicit auth decision, and TASK-33001.7 relies on it: a keyless save records `credential_source = "none"`, because quitting writes the shipped template's `api_key_env_var` back into the section, and only "none" keeps that name inert (resolve_provider_credential honours it).

The legacy summarizer path does not. `_resolve_provider_credential` in LLM_Calls/Local_Summarization_Lib.py (used by the koboldcpp and tabbyapi summarizers) falls back to the environment variable named by `api_key_env_var` whenever no stored key resolves. It never reads `credential_source`. So for a section that says "none" and still carries the template's env-var name, exporting that variable later makes these summarizers send it as an API key to a local server, while resolve_provider_credential (and so Console readiness) resolves no key for the same section.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 A provider section with credential_source = "none" makes the legacy summarizers send no API key, even when the environment variable named by api_key_env_var is set
- [x] #2 The summarizers resolve a credential the same way as resolve_provider_credential for every credential_source value, or the difference is recorded in ADR-012
- [x] #3 A test with the variable exported covers the "none" case for koboldcpp and tabbyapi and fails if the env fallback ignores credential_source
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Pin it first (TDD): with the named variable exported and `credential_source = "none"`, each summarizer must resolve no key and put none on the wire. Add a table that compares the summarizer's key with `resolve_provider_credential` for every source value, stored-key shape and variable state.
2. Make `_resolve_provider_credential` take its key from `resolve_provider_credential`, keep the legacy `[API]` rung and the blank-versus-absent result, and keep ciphertext out.
3. Record the two differences that remain in ADR-012, then run the files that cover the module.
<!-- SECTION:PLAN:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
The shared ingestion textarea constructor now uses the existing DetachSafeTextArea. This protects both custom_prompt and system_prompt while preserving IDs, CSS classes, multiline values, TextArea queries, and Changed events.

Added two parameterized regressions in Tests/UI/test_library_ingest_option_event_order.py. Each mounts the real ingestion options, removes its editor before compositor reflow, verifies the stale hit, invalidates cached Rich styles via public refresh(), and dispatches MouseMove through App.on_event. It then rebuilds the options and verifies multiline content and ordinary OptionValueChanged delivery from the replacement.

Verification:
- RED: both cases failed with the user's exact text-area--gutter KeyError and compositor/theme call chain before the constructor change.
- GREEN: both cases passed after the change.
- Final targeted run: 53 passed across test_library_ingest_option_event_order.py, test_library_ingest_option_journeys.py, and test_detach_safe_text_area.py. Existing Pydantic/audioop deprecation warnings only.
- Ruff check and format checks pass for both edited Python files; git diff --check passes. Independent review found no actionable issues.

The first broad run had 20 environment failures before UI assertions: the two private-profile option-order cases, 16 option-action journey cases, and two compact-shell cases used Windows' shared TEMP ancestor. A disposable private profile plus TEMP/TMP redirection resolved all 20 in the final run, without changing security checks. This follows the existing Native Windows private-path temporary-ancestor lesson in backlog/docs/lessons-testing-evidence.md. No new lesson or ADR is required.

Modified library_ingest_canvas.py and test_library_ingest_option_event_order.py. No dependency, persistence, layout, or visual contract changes. No full-suite sweep. PR preparation transfers only this scoped change to an isolated worktree and rebases its commit onto dev.

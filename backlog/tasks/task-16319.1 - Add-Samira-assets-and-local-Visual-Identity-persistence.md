## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Establish the local, server-aligned persistence and immutable asset foundation required to ship Samira and her complete reaction pack safely on fresh and upgraded profiles.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 The local database migrates to a documented four-table Visual Identity semantic subset with packs, immutable versions, assets, and bindings, without a broken or implied draft foreign key.
- [ ] #2 The sanitized V2 JSON card, metadata-embedded canonical PNG, manifest, license notice, and exact 31 valid 1024x1024 WebP reactions are explicit package resources with verified hashes and bounded size.
- [ ] #3 Fresh and upgraded profiles seed one Samira card and bound pack idempotently without overwriting, duplicating, or resurrecting renamed, customized, collided, archived, or deleted data; a valid active user-owned binding is preserved as a terminal customized state.
- [ ] #4 Built-in package assets remain immutable, local IDs and owner sentinel remain explicitly non-server identities, and existing character expression BLOB storage is unchanged.
- [ ] #5 Wheel, sdist, installed-resource, database migration, FTS first-edit, lifecycle, and failure-recovery tests pass from a current origin/dev baseline.
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Add and verify the ChaChaNotes v37-to-v38 four-table Visual Identity migration and installed migration resource.
2. Implement the focused VisualIdentityRepository with atomic activation/publication invariants.
3. Add the pinned server normalization contract, manifest validation, and package/user resource loader.
4. Produce, sanitize, inspect, and package Samira’s V2 JSON/PNG card plus exact 31-reaction manifest and AGPL-3.0-or-later inventory.
5. Implement create-only, tombstone-safe, cheap-preflight Samira seeding across eager, lazy, and injected profile DB startup.
6. Prove wheel/sdist contents, isolated installed-resource behavior, lifecycle/FTS integrity, and close the child only after review.

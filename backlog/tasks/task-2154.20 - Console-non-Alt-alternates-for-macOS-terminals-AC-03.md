## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Alt+M/Alt+W/Alt+V/Alt+1-9 break on default macOS terminals (Option-as-Meta off); only fallback is the palette. Alt+H already moved to Ctrl+Shift+H for this reason. Provide Ctrl+Shift alternates or document the limitation in F1 help. See findings doc section 7.

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
ADR required: no
ADR path: N/A
Reason: palette-entry + help-copy additions only; no binding changes, no storage/boundary/contract change. ADR-031 governs the (non-)choice of new chords.

1. **No new Ctrl+Shift letter chords** — ADR-031 forbids ctrl+{c,v,x,s,d,z,a,r,w} (kills ctrl+shift+W/V) and ctrl+M aliases Enter in terminals (kills ctrl+shift+M). ctrl+shift+H only worked because H is free; there is no compliant free letter for M/W/V, and nine digit chords would be worse. The AC's non-Alt path is therefore the **command palette + existing Ctrl+K switcher**, documented in F1.
2. **Palette gap**: add "Console: Paste image from clipboard" → `action_paste_clipboard_image` (Alt+V had no palette entry). Model (Alt+M), Workspace (Alt+W), Switch session (Ctrl+K, covers Alt+1..9 tab jumps) already have entries.
3. **F1 caveat**: append a "macOS terminals" group to `CONSOLE_WORKBENCH_SHORTCUT_GROUPS` — Alt chords type composed characters when Option isn't Meta (the Alt+H → Ctrl+Shift+H precedent); Ctrl+P palette lists every Alt action; Ctrl+K covers tab jumps.
4. **Tests**: extend the palette-provider tests (internals_decomposition :4229 pattern) — search "paste image" yields the new entry routed to `action_paste_clipboard_image`; verify entries exist for model/workspace/session-switcher; help-panel state includes the macOS group (direct constant assertion).
5. Run command-provider/help/internals suites, then Notes + AC + Done + commit.

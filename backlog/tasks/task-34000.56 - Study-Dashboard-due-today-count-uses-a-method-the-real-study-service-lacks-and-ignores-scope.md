## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Why: the Study Dashboard's "N due today" should count the cards the user is due to review in the scope they are working in. TASK-34000.6 and its review found that it does not:
- `UI/Screens/study_screen.py` (~:1108) looks up `get_due_flashcards` on the study service with `getattr`. `StudyScopeService` has no such method, so the lookup always misses.
- It then quietly falls back to `db.get_due_flashcards(limit=25)` on the local DB. That fallback is unscoped, so in workspace scope (and server mode) "due today" counts every local card, not the workspace's.
- `count_due_flashcards` exists but is local-only and also unscoped.
- These loaders sit in try/except, so a wrong signature degrades silently instead of failing. That is why TASK-34000.6's keyword guard deliberately excludes this block.
<!-- SECTION:DESCRIPTION:END -->

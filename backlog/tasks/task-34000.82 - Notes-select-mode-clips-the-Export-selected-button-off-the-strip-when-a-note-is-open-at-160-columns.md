## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Why: the only way to bundle a chosen set of notes is Select -> check rows -> **Export selected**. With a note open beside the list at 160 columns the Notes list pane is 62 columns wide and the select strip renders `1 selected   Done     Select all 100 shown     Clear` with the **Export selected** button cut off entirely (the pane edge falls inside it, so not even a truncated label shows). The guide's compact rule ("on a compact terminal the row shortens to Done, All N, Clear and Export") did not engage at this width, so the strip neither shortened nor wrapped.

Repro (2026-10-24, TASK-34000.31 live walk, isolated seeded profile, 160x45): Library -> Notes -> open any note -> **Select** -> check one row. The strip shows four controls and no Export; the count line below reads "1 selected". Leaving the editor (Esc) is the only way to reach a wider list. Workaround used: the toolbar **Export** (whole-list bundle).

Pre-existing; found while verifying TASK-34000.31 (N-20). Review finding(s): fix round 1 follow-up.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The wizard's choice lists treat a highlight as a selection, and its Enter key means something different on every control. After the first interaction, each arrow press in the Provider list selects a provider. It re-lays out the panel, starts model discovery (a real request when a key is exported) and leaves an error behind for a provider the user never chose. At 100x30 and 80x24, one Down press can scroll the focused list completely off screen, so the user picks a provider without seeing the list. On Model, one Down press wipes a typed model id. The hint line says 'Enter … next', but Enter selects, tests, skips or saves depending on focus. It also replaces a detected local server with the pre-highlighted OpenAI. Sam presses Enter in the key field twice, sees nothing advance, and has to find the mouse. Jo loses a detected server with one key press.

This task implements structural fix SF8 (one input policy). A highlight moves the cursor. Enter, Space or a click selects, through one dispatch path. Enter on a settled control advances, and the hint line describes the focused control. Report: Docs/superpowers/qa/first-run-wizard-ux-review-2026-10-02/README.md (§5.1 SF8, §6 register). Resolves: new-a11y-terminal-visual-01, cross-cutting-04, cross-cutting-06. All three were re-checked and are still present on dev 3c439d606e.

Coordination:

- Focus returning after Test and Hear (voice-speech-05) is in TASK-34100.8.
- The short layout tier that gives the list room at 80x24 is in TASK-34100.12.
- Keep the accepted decisions behind today's behaviour. From TASK-21142, short radio groups (6 options or fewer) keep selection-follows-highlight. Also from TASK-21142 (UAT N-1), Enter in a free-text field continues. From TASK-32555, the empty-key Enter skip stays one press. Do not make Enter in free-text fields only move focus, and do not add a two-press skip.
- Risk is Medium: overcorrecting would reverse accepted UAT decisions, and any per-field Enter exception must be shown in the hint line.

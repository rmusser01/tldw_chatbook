## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Analysis generation, save and the bulk Analyze run still execute on LibraryScreen, and tests patch the analysis provider and chat dispatcher on the screen module to control them. Moving the bodies gives analysis one home, and the patches must follow the code they intercept or they stop testing anything.

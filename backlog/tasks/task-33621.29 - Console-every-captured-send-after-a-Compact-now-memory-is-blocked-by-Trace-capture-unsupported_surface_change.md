## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Found live by the TASK-33621.3 verifier (PR #2939). Once a conversation memory comes from Compact now, the next request's trace surface is a replacement (the memory replaces older messages) plus an append (the new user turn), and the trace planner rejects that with error_category=unsupported_surface_change. Every later captured send then shows 'Trace capture blocked … The provider was not contacted' and needs 'Send without capture' each time. Now that Compact now works in a live session (TASK-33621.3), this becomes the common path.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
After a successful Compact now, later captured sends in the chat reach the provider with trace capture intact.

**Root cause (shared with TASK-33621.7).** Compact now commits a conversation memory; the next request drops the compacted turns from `messages_payload` and sends the memory as a system message. No captured call records that change, so the next captured send carried a rewrite of the recorded surface's whole tail plus the new turn, and the planner refused it as `unsupported_surface_change` (`count_or_span`). Measured live on dev f9baac8706: prefix 0, 13 recorded entries changed, 3 incoming (evidence bd5/U04/05-06 "before").

**Approach.** Reuses TASK-33621.7's rewritten-tail admission (ADR-097 amendment 2026-10-27) and adds one anchor: the oldest replacement row may hang off the `boundary_message_id` of an active conversation memory in the attached conversation. `RewrittenTailWitness.memory_anchor` records which anchor was proven; the dispatch-binding recheck re-reads that the memory is still active and fails closed otherwise. No schema change.

**Found on the way, filed as TASK-37417:** on the plain-provider path (character chats, `agent_runtime = false`) a Capture-On send dispatches the trace request frozen before the memory preflight, so after Compact now it still sends every older turn and no memory. That path never hit the refusal, so this task's AC#1 holds there; the compaction tests run on the agent path (the Console default). Re-confirmed on dev 3efe8476ce.

## Implementation Notes

**Approach.** FB-07's notify inventory (1 success against 29 information) turned out to be a SEVERITY problem as much as a coverage one: the four Save-as savers already toasted on completion, but at `severity="information"`, and retry/settings/handoff completions were silent. The fix is deliberately small — no new notification machinery, just correct severities and three honest one-shot toasts.

**Changes (all `UI/Screens/chat_screen.py`).**
- Save-as savers (Note :20431, Media :20482, Prompt :20556, Chatbook :20643): `severity="information"` → `"success"`; copy unchanged (already positive).
- Retry accepted (`_retry_console_message`): new `severity="success"` toast, always "Retrying failed response." — never `result.visible_copy`, which on an accepted retry is the recovered assistant TEXT and belongs in the transcript (caught by the new test: gateway's "recovered" payload surfaced as the toast in the first draft). Rejected retries keep the existing warning path.
- Console settings save (`_apply_modal_result`): "Console settings saved." success toast; a modal dismiss (None) still toasts nothing.
- Save Chatbook handoff (`_save_console_chatbook_from_visible_action`): "Saved — opening the artifact in Artifacts." success toast on the staged-handoff branch; copy is honest because the button is gated on a completed live-work launch, so the artifact already exists.

**Spam guard.** Routine sends gain nothing: a dedicated test drives a successful send and asserts zero success-severity toasts. The retry toast is one per deliberate click on a failed row; progress continues on the run-state surface.

**Tests.** New FB-07 block in `Tests/UI/test_console_native_chat_flow.py` (5 tests): all-four-savers success severities via a (message, severity) notify capture, retry-accepted toast (baseline-count +1 assertion, immune to unrelated startup toasts), settings-save toast via the inspector-rail modal route (the palette action is setup-guarded; first draft's direct call never opened the modal), Save-Chatbook handoff toast with a stubbed `open_console_live_work_primary_action`, and the routine-send silence guard. **Evidence:** 481 passed / 0 failed — native-chat-flow 309 (full file, sliced ×3), console session settings 139, parallel runs 28, plus the 5 new tests' focused runs.

**Modified files.** `tldw_chatbook/UI/Screens/chat_screen.py`, `Tests/UI/test_console_native_chat_flow.py`.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Root cause was NOT grid space starvation but Textual Button's line-pad (1 cell/side) eating 2 cells inside each fixed-width button on top of the rule's `padding: 0 1` — 'Temporary' (9 chars) got 8 cells -> 'Temporar', and 19-char session tabs lost their ellipsis. Fix: dropped `padding: 0 1` -> `padding: 0` in the tab-strip button rule (`tldw_chatbook/css/components/_agentic_terminal.tcss`), bundle regenerated via `./build_css.sh`; label budget is now w-2 (10>=9, 19==19). Multi-tab overflow keeps the strip's existing scroll semantics (active tab auto-scrolls into view; controls reachable via focus/wheel/End) — fixed-width tab contract deliberately preserved.

Files changed: `tldw_chatbook/css/components/_agentic_terminal.tcss`, `tldw_chatbook/css/tldw_cli_modular.tcss` (regen), `tldw_chatbook/Widgets/Console/console_session_surface.py` (scroll-retry), new `Tests/UI/test_console_tab_strip_budget.py` (5 pilot tests @140/160, Inspector closed+open, 4-tab overflow, 19-char ellipsis).

Verification: targeted 6 passed (incl. rail_title); new file 5/5 green; wide `Tests/UI -k console -q` gate run in background by orchestrator. UAT (sandboxed harness): `p2c-reply-complete.txt` (160) and `p7b-140-after-inspector-click.txt` (140, Inspector open) both render `Temporary` whole; close and New tab adjacent/reachable; narrow bands (<100) behavior unchanged.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The diagnostic reports all 70 optional feature groups as not installed even with the libraries present, because it reads a registry no probe has populated -- confirmed with two libraries installed and both reported missing. The provider check in the same diagnostic always reports no providers configured, because it iterates flat dotted keys a nested configuration never produces. Both are user-facing wrong answers that a user will act on. The underlying registry defect is already filed.

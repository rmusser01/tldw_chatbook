## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
In Chat settings, capture_suspended_draft writes raw_values['console-settings-streaming'] = None when the Streaming control is Inherit (no per-chat override), and ConsoleSettingsDraftSnapshot.__post_init__ accepts only a bool there, so it raises ValueError('raw modal values are invalid'). The ValueError is unhandled in the Configure credential button handler, so the app exits. It reproduces on origin/dev 88e6967590 and at the TASK-33003.5 base: production app, a llama.cpp chat switched to OpenAI with no key (the switch sets Streaming to Inherit), then Configure credential. The Phase 3 final review found that any Inherit Streaming draft reaches it; the provider switch is only one way there. This is the headline credential round-trip flow. Found in TASK-33003.5 review round 2.

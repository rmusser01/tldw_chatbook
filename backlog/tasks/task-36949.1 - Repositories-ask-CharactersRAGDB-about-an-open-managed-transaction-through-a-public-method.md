## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Ten sites in five files read the private `db._local.transaction_depth`: the Persona_Visual and Actor_Packs repositories, `console_trace_repository` and others. Some ask whether a managed transaction is open. Others ask whether the caller owns the outermost one: `Persona_Visual/repository.py:1322` and `:1342` test `transaction_depth == 1` inside an authority guard.

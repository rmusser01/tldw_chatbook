## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Found by the TASK-33625.1 final verifier (PR #2934) and reproduced identically on clean dev 857b3dd7d0 through the collapsed-strip Stop. Stopping a run after 'agent reply start' but before trace reservation ends the turn with status=failed exception_type=CancelledError phase=durable_commit, and 'runtime turn ended with exception_type=ValueError'. The next send is refused with a RuntimeError and parked as 'Queue 0/10 · Unsent turn needs attention'. PR #2934 makes Stop reachable from the composer, Ctrl+G, /stop and the palette, so users will reach this wedge much more often. Evidence: the U6-final captures 30-35 and app-base-235x52.log from the batch-1 run.

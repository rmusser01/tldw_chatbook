## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Strict-JSON parsing exists in three drifted families: the wire family caps depth and node count but accepts duplicate keys, the storage family rejects duplicate keys but has no depth cap, and neither does both. A tool-call argument accepted on the wire can therefore raise an uncaught validation error on the way to storage. Fifteen copies exist across provider, chat, MCP and persona modules; a private validator in the shared input-validation module is the natural home.

Source: core-runtime code review 2026-09-17 — `qa/core-code-review-2026-09-17/report.md`; per-slice evidence in `qa/core-code-review-2026-09-17/slices/`, reproductions in `qa/core-code-review-2026-09-17/phase4-verification.md`.
<!-- SECTION:DESCRIPTION:END -->

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Applies the numbering rule recorded by TASK-36943.2 to today's 50 shared ADR numbers. That is 117 files: the oldest of each number keeps it and 67 younger files are renumbered. About 7,400 existing references use an ambiguous number (6,508 in 2,484 files outside backlog/decisions, 891 inside it), mostly in Done task files and superpowers specs and plans. Each reference has to be attributed to the right file before it is rewritten, so the sweep is scoped to living material. Historical records stay as written and resolve through the provenance notes and an old-to-new index. Owner decision 2026-10-25: renumber the younger file. This scope was chosen by the filer; the owner can widen it to every reference.

Source: architecture review 2026-10-25, `Docs/QA/architecture-review-2026-10-25/report.md` §F17; claim-by-claim verification in `Docs/QA/architecture-review-2026-10-25/verification.md` (origin/dev 7a5e2513c5).

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Applies the numbering rule recorded by TASK-36943.2 to today's 50 shared ADR numbers. That is 117 files: the oldest of each number keeps it and 67 younger files are renumbered. About 7,400 existing references use an ambiguous number (6,508 in 2,484 files outside backlog/decisions, 891 inside it), mostly in Done task files and superpowers specs and plans. Each reference has to be attributed to the right file before it is rewritten, so the sweep is scoped to living material. Historical records stay as written and resolve through the provenance notes and an old-to-new index. Owner decision 2026-10-25: renumber the younger file. This scope was chosen by the filer; the owner can widen it to every reference.

Source: architecture review 2026-10-25, `Docs/QA/architecture-review-2026-10-25/report.md` §F17; claim-by-claim verification in `Docs/QA/architecture-review-2026-10-25/verification.md` (origin/dev 7a5e2513c5).

## Implementation Notes

<!-- SECTION:IMPLEMENTATION_NOTES:BEGIN -->
Renumbered the 67 younger files of the 50 shared ADR numbers to ADR-287..ADR-353, in number order, oldest first; the next free number is 354. The oldest file of each number was decided by its `Date:` field, else its add-commit time. Ties on the same Date were broken by add-commit time (16 numbers). Where Date and commit time disagree, the Date field won (029, 093, 150 and 184).
- **Renamed files.** Each one carries a "Renumbering provenance" section naming its old number and the file that kept it. Its own self-references were updated.
- **Old-number index.** `backlog/decisions/renumbered-adr-index.md` lists every file that held each formerly shared number and the number it holds now. The README links it.
- **Living references (AC#3).** 3,326 ambiguous references in living material (decision records, code, tests, live docs, open tasks and backlog/docs) were each attributed by reading their context: links and filenames first, then topic, then age. 1,658 now use their renamed file's number; 1,666 mean the keeper and stay as written. 358 links to the renamed files' old filenames were repointed in 217 living files. `backlog/decisions/renumbered-adr-references.tsv` records every rewritten reference with the file it was attributed to and a confidence level; 26 rewrites are marked low. A diff check confirmed that every changed line differs only in its ADR numbers.
- **Historical records (AC#4).** Done tasks, `Docs/QA/`, `qa/` evidence, `Docs/superpowers/`, `.superpowers/` and `backlog/archive/` are untouched; 672 historical files keep their old links and resolve through the index.
- **Guard (AC#5).** `scripts/adr_shared_numbers_frozen.txt` is removed, and `check_adr_numbers.py` now fails on any collision. Its two frozen-list tests went with it.
- **Pins re-set on purpose.** `Tests/test_config_load_settings_table_guard.py` re-pins the default config template's sha256, because three of its comments now name ADR-343, ADR-344 and ADR-332. `Packaging/speculative_voice_source_paths.txt` is re-sorted after its renamed decision path.
- **Left alone.** The comment in `.github/workflows/derived-artifacts.yml` (~line 157) that mentions the frozen list was not edited, to keep this PR out of workflow files; its ADR-228 example is generic.

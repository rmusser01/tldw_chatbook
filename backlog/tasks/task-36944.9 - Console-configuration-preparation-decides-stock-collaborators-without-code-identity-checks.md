## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
`Chat/console_configuration_preparation.py` imports UI-private symbols (`_CONSOLE_TURN_CAPTURE_SELECTOR`, `_STOCK_CONSOLE_SCRATCH_SNAPSHOT`) and compares `__code__` and `__defaults__` identity against them to decide whether injected callbacks are the stock ones. The callbacks are injected, but the identity check couples Chat to UI internals. Chat has 51 `__code__` references in 20 files.

Source: architecture review 2026-10-25, `Docs/QA/architecture-review-2026-10-25/report.md` §F12; claim-by-claim verification in `Docs/QA/architecture-review-2026-10-25/verification.md` (origin/dev 7a5e2513c5).

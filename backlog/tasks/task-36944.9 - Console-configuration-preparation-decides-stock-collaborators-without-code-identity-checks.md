## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
`Chat/console_configuration_preparation.py` imports UI-private symbols (`_CONSOLE_TURN_CAPTURE_SELECTOR`, `_STOCK_CONSOLE_SCRATCH_SNAPSHOT`) and compares `__code__` and `__defaults__` identity against them to decide whether injected callbacks are the stock ones. The callbacks are injected, but the identity check couples Chat to UI internals. Chat has 51 `__code__` references in 20 files.

Source: architecture review 2026-10-25, `Docs/QA/architecture-review-2026-10-25/report.md` §F12; claim-by-claim verification in `Docs/QA/architecture-review-2026-10-25/verification.md` (origin/dev 7a5e2513c5).

## Implementation Notes

<!-- SECTION:IMPLEMENTATION_NOTES:BEGIN -->
The identity check defends against a substituted/monkeypatched capture selector, scratch provider or selection source (the mounted fast path then falls back). That defence is unchanged: the same `__code__`/`__defaults__` comparisons now live in UI (`turn_admission.stock_mounted_capture`, `is_stock_session_provider`), next to the snapshots they compare against, and Chat only calls these public functions. Preparation lost its `session`/`wiring` UI imports (two layer-allowlist rows removed); the UI snapshots keep their other users. Chat `__code__` references 60 -> 56 (pin in `Tests/Architecture/test_chat_code_identity_ratchet.py`).
Red: both new tests failed at base (60 > 56; three UI-private imports); pin 55 fails at head. Covering Chat/UI console tests: 42 failed/256 passed at base and at head, identical failure set.

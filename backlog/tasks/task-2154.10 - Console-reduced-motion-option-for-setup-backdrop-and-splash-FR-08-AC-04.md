## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
`appearance.reduce_motion = true` now renders both full-screen animations as static frames.

- Mechanism: a single new config key in the existing `[appearance]` section (default `false`, also added to the config template). Readers: app.py compose (passes `reduced_motion` into `SplashScreen`) and ChatScreen `_sync_console_setup_modal` (sets `modal.reduced_motion` on every guidance sync). Old config files without the key behave exactly as before (all readers default False).
- Splash: `SplashScreen(reduced_motion=...)` — animated cards route to `_display_static_fallback()`, which renders the SAME card's static `content`; no animation timer is started. Fade-out needed no gating (already a no-op immediate close, TODO in code).
- Setup backdrop: `ConsoleSetupBackdrop.reduced_motion` makes `resume_snow()` a no-op (tick timer never arms) while the flake field still renders one static frame per mount/resize — same dim + layout, zero motion. `ConsoleSetupModal.reduced_motion` property propagates to the mounted backdrop and is honored by `_sync_snow_timer`.
- Settings hub: beyond the AC's config-only requirement, the option is discoverable in Settings > Appearance ("Motion and scrolling" group, next to "Animations") — extended `settings_appearance_defaults.py` (constant/dataclass/load/validate/save) and `settings_screen.py` (ownership record, selector + validation maps, toggle row, press handler, focused-field detail, label re-sync). This matches the ownership boundary already used by `animations_enabled`/`smooth_scrolling`.
- Tests: new Tests/UI/test_console_reduced_motion.py (6 pass — static frame rendered + timer never resumes under reduced motion; default still animates and ticks; modal propagation both ways; splash static/no-timer vs default timer). Extended Tests/UI/test_settings_appearance_defaults.py (save-sections expectation, invalid-value case, load/coerce test; 10 pass). Neighbors: setup_lock_polish + workbench_contract + setup_card_fit + splash config read + splash viewer (82 passed); settings hub appearance subset (7 passed).
- UAT: f2/f3 re-run ok; f3b capture shows the snow field + card intact on the default (animated) path — no regression; the static path is pinned by unit tests.

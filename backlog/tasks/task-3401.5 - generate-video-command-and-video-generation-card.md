User-facing surface for video generation in the native Console: same command grammar as /generate-image; long-running generation with progress and cancellation; a card that plays or tombstones depending on file presence; paid-backend cost confirmation. ## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Console accepts /generate-video [:backend] <prompt> with the same token grammar as /generate-image
- [x] #2 A per-session in-flight guard mirrors image generation so at most one generation runs per session
- [x] #3 Generation runs off the UI loop with progress status updates and cooperative cancellation
- [x] #4 Card shows metadata and poster frame when available with play and save-a-copy and regenerate actions plus an expired tombstone state when the file is gone

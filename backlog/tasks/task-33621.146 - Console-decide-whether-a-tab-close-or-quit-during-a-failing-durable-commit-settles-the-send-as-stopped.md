## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Found in the TASK-33621.59 review (2026-11-06). The ordinary commit owner's explicit_stop flag is set by the controller's _signal_stop for a session close and for app shutdown as well as for a user's Stop. Since TASK-33621.59, a send whose durable commit fails after that flag is set is cancelled and its text restored instead of pausing as 'Send could not be saved'. So a commit failure during a tab close or a quit now takes the stopped path, and no test covers either case. Decide whether only a user's Stop should win.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
From the PR #2949 (TASK-33622.10) round-2 fix-up. #2949 makes SafeModalDismissMixin.dismiss refuse while its modal is covered (ADR-031: only the still-mounted active top screen may dismiss), and the quit flow finishes the interrupted close for its own prompts. Outside the quit path, nothing finishes a close that was refused because something else was pushed on top. The known case is LibraryCharacterRepairDialog._apply_owned, which a background push can cover mid-close. The modal then stays open under the new screen until the user closes it again. The lessons-textual entry for #2949 names this case.

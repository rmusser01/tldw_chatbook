## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The roadmap's Phase 3 exit gate requires that ChaChaNotes_DB imports neither Chat nor Sync_Interop. TASK-36949.3 removed the semantic coordinator import, and TASK-36949.4 removed every Sync_Interop import. Seven Chat imports remain, and three layer-allowlist rows record them (`DB.ChaChaNotes_DB → Chat.assistant_generation_state / console_exchange_capture / console_library_policy`, all lazy):
- four lazy imports of `Chat.assistant_generation_state` in the message insert, update and projection writers;
- `Chat.console_library_policy`, under TYPE_CHECKING for the migration-seed annotation and in a migration;
- `Chat.console_exchange_capture`, in a migration.

The DB layer must not depend on the Chat feature package.

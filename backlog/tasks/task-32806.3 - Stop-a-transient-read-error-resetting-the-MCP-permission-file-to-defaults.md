## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
A read `OSError` is treated as corruption: the live permission file is renamed to a backup and the store resolves from fresh permissive defaults, so the kill switch flips off and a tool set to Off resolves to Allow. The next mutator persists the reset, making it permanent. Reproduced by making the file unreadable. The module's own docstring says uncertain persistence failures must not reset policy, and the specification only calls for a backup on an unknown schema version.

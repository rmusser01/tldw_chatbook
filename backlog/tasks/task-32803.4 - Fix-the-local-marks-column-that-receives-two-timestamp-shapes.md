## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
`conversation_local_marks.updated_at` is written in two different UTC shapes by two paths, and the table's only `ORDER BY` over it is lexical, which inverts the order across the two. Separately, the voice-promotion reconciler's canonical-timestamp validator rejects the shape the table's own public writer produces, which is a latent runtime error rather than a live one only because no mark type is written by both paths today.

Source: core-runtime code review 2026-09-17 — `qa/core-code-review-2026-09-17/report.md`; per-slice evidence in `qa/core-code-review-2026-09-17/slices/`, reproductions in `qa/core-code-review-2026-09-17/phase4-verification.md`.
<!-- SECTION:DESCRIPTION:END -->

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Found while implementing TASK-33620.8. A Temporary (unsaved) Console chat never persists its messages, so no citation record or Cited sources row can exist for its replies. Its staged or Automatic Library evidence still goes to the model with [Sn] labels and citation instructions, so the reply shows markers that can't be traced. TASK-33620.8 sends label-free evidence when the citation key or store is unavailable. It does not cover the per-session 'will not be saved' case, because the capture step does not know the session is temporary.
<!-- SECTION:DESCRIPTION:END -->

- [ ] #3 A mounted test covers a Temporary send and a saved send.

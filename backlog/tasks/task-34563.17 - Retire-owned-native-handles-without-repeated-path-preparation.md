## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Remove repeated filesystem preparation during cleanup of already-owned handles so Console operations finish promptly while preserving exact native ownership and all effect gates.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Already-owned native descriptor retirement performs no repeated source or parent filesystem scan and still positively closes the exact descriptor.
- [x] #2 Foreign actors, substituted operations and unrelated descriptors cannot borrow retirement ownership; uncertain close outcomes keep their existing resources and leases retained.
- [x] #3 Source, parent, pause and permission changes still refuse subsequent opens, reads, writes or publication; custom and unowned routes keep their established behavior.
- [x] #4 Original-call counts, focused integrated tests, native cleanup and sequential whole-Send timings are recorded without treating a local reduction as overall latency acceptance.
<!-- AC:END -->

## Implementation Notes

Separated cleanup of exact already-owned native descriptors from filesystem preparation, using the existing operation, actor and descriptor records and the original close/uncertainty owner. Added 27 product lines in raw_participants.py/private_paths.py and nine focused ownership controls. No new cache, registry, storage format or permission policy. Existing ADR-225 and ADR-126 apply.
The original regression changes from 21 closes/21 checks to 21 closes/zero checks, with actual handle closure and retirement verified. Nine new and 11 existing cases pass; two native Windows alias/pinning controls pass separately. Eight legacy fixture failures plus a teardown error are retained. Five representative failures reproduce on exact HEAD source; three other raw variants remain unqualified. No deadlines were relaxed and no full suite was run. Scoped static review finds no new lint issues; inherited whole-file formatter/E721 debt remains.
Final sequential Send samples: 9.197429 / 5.789172 / 4.819775 seconds versus 10.554331 / 9.535932 / 8.773512 previously. Typical hook checks fall from 254 to 150. All three replies and linked traces complete, with no checkpoints, current source and normal contained cleanup. The overall subsecond and universal 100 ms feedback targets remain unmet. Evidence and limitations: Docs/Development/2026-10-06-console-send-phase-attribution.md.

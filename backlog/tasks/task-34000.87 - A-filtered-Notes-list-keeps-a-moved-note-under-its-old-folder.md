## Description

Minimal repro (seeded power profile, isolated harness, 120x36): Library ▸ Notes ▸ `/` ▸ `quotes` ▸ Enter ▸ open Quotes ▸ Move note ▸ type `thes` ▸ Down ▸ Enter. The notice reads "Folder organization updated."; the database holds Quotes in Projects/Thesis; the filtered list still reads `Quotes · Unfiled · 1h`.

Evidence: reproduced identically on a `git archive 5e746fe393` export (before polish-1a Task 5), during TASK-34000.28's live walk (polish-1a Task 5). TASK-34000.28's Task 4 fixed the unfiltered tree's stale Unfiled row (the move reconcile reloads the root placements slice); the filter window is a separate snapshot the reconcile does not refresh.

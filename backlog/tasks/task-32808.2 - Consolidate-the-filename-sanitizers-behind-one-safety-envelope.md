## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Seven filename sanitizers and validators exist with different safety envelopes. The one in the shared text module keeps NUL and control characters -- verified, a traversal-and-control-character input passes through mangled but intact -- while the path-validation module raises on the same input. Two same-named validators have opposite contracts, and two copies reach disk or a zip archive unvalidated.

Source: core-runtime code review 2026-09-17 — `qa/core-code-review-2026-09-17/report.md`; per-slice evidence in `qa/core-code-review-2026-09-17/slices/`, reproductions in `qa/core-code-review-2026-09-17/phase4-verification.md`.

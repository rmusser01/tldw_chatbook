## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The return-settlement machinery, the adaptive reader layout sync and the media review actions are the last media bodies on LibraryScreen and the largest group of controller callbacks (eleven). Several of them test whether a widget belongs to the screen, which a pure move would silently break, so they move with an explicit receiver.

Source: architecture review 2026-10-25, `Docs/QA/architecture-review-2026-10-25/report.md` §F2; slice 7 of 8 in the TASK-36952.3 split plan, measured at `08b3c9d337`.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Gave active-run copy a persistent visible home and silenced the empty-local-catalog traceback.

- FB-08: new `ConsoleRunChip` in `#console-status-chips` (composed right after the Temporary chip so it survives horizontal-scroll overflow; the stable readiness chips keep their learned relative order). Visible only while the viewed session's run status is in `CONSOLE_ACTIVE_RUN_STATUSES`; label `Run: {visible_copy}` with an "Open the Inspector for run details" tooltip; Enter/Space/click opens the Inspector rail (`_reveal_console_inspector_rail`) — same activation contract as the sources/tools chips. Driven from `_sync_console_mode_bar`, which already runs on send/stop transitions and every 0.2s transcript-poll tick while a run is active — no new timer. First-frame correctness via a `run_copy` constructor arg (the F1 precedent) fed by the new `_console_active_run_copy()` helper; `sync_run_chip` is equality-guarded so unchanged poll ticks are free.
  - Design decision: active-only visibility. Terminal states (COMPLETED/FAILED/STOPPED) hide the chip even though their copy lingers — terminal outcomes already have ambient signals from task-2154.16 (failure toast), task-2154.17 (success toasts), and the tab markers; a persistent terminal chip would need a dismissal model (out of AC scope).
- FB-09: `_merged_model_entries_from_scope` (`provider_model_resolution.py`) now catches the local catalog service's "Unknown or ambiguous local LLM provider" `ValueError`, logs at debug, and degrades to saved-only — an empty local catalog or cloud-only provider is a routine state, not an error. Previously this tracebacked via `logger.exception` in `_providers_models_for_console_settings` on every Alt+M popover open; the model search picker path had NO handler, so the same raise could escape into its message handler. Other exception types still propagate (pinned by test).
- Tests: `test_console_status_chips.py` (widget show/hide/guard, first-frame compose, integration through `_sync_console_mode_bar` incl. the terminal-hides contract); `test_provider_model_resolution.py` (ValueError → saved-only; RuntimeError still raises).

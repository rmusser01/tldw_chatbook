## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
From TASK-33621.80's review. A wake paused at the Ask compaction trigger (code compaction_ask) is released once the chat's policy is no longer Ask, but only when the fleet-wake coordinator next tries a delivery (ConsoleFleetWakeCoordinator._attempt), for example after the user's next message. Changing When limit nears to Automatic or Off does not itself prompt that attempt, so the agent stays paused until something else in Console settles; the User Guide states this as a caveat. The policy is written by more than one path (per-chat Chat settings, the global Context and memory settings), so there is no single hook to add the retry to today.

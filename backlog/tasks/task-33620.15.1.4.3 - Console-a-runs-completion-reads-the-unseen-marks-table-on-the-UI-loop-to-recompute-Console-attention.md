## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Found while measuring TASK-33620.15.1.4 live on origin/dev 3be493413a (isolated profiles, Anthropic claude-haiku-4-5 through the review proxy, 235x52, host load 5-16). ConsoleRuntime._finish_custodied_turn runs as a UI-loop callback at each run's completion and calls recompute_console_attention, which reads ConversationLocalMarksService.list_console_unseen_marks inside a ChaChaNotes transaction, storage admission included. Over 16 completions that callback took 101 ms (16 ms CPU), 76 ms (11 ms), 46 ms (10 ms), 45 ms (8 ms) and under 30 ms otherwise: the time is waiting on the admission syscalls and the database, so it grows with host load, and keyboard input waits behind it. Evidence: p14pt-T1.jsonl (done#0, +431 ms) with p14an.py (local-only: kept in the measuring session's private probe kit, not in the repository. TASK-33620.15.1.4's notes describe the probe and the set-up, so re-measure rather than look for these files).

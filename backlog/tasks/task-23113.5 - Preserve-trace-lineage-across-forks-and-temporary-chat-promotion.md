## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Keep prior trace history coherently visible after forks and require temporary chats to become durable before Capture On can dispatch, without duplicating inherited trace payloads.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Forked conversations inherit reachable prior trace history by shared ownership or references and do not duplicate inherited artifacts, surfaces, events, or calls.
- [x] #2 Each fork records its own subsequent semantic revisions and call chronology while the viewer presents the combined history coherently.
- [x] #3 Editing or regenerating either branch after a fork does not rewrite the other branch or historical trace records.
- [x] #4 Capture On in a temporary chat pauses before dispatch and offers Save & Send or explicit Capture Off; Save & Send promotes the chat and reserves the call atomically enough to prevent an untraced dispatch.
- [x] #5 Promotion or fork persistence failure leaves the source conversation and its trace ownership intact and no provider request is sent.
- [x] #6 ADR required: yes; this task implements the ownership and conversation-lifecycle policy in ADR-097.
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Repair the two fork baseline contract drifts and pin the intended seams.
2. Add failing lineage tests for durable and temporary forks, shared boundaries, row/byte non-duplication, and divergent branches.
3. Persist and project immutable inherited trace boundaries through fork commit and later promotion.
4. Add failing temporary Capture On admission tests, then implement Save & Send or explicit Capture Off with no silent dispatch.
5. Run the focused fork, preparation, persistence, trace, and UI matrices; review privacy/storage invariants; document evidence and close the task.
<!-- SECTION:PLAN:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Independent pre-merge review found three blockers: production capture mode is frozen Off before policy resolution; Save & Send retains temporary library authority after promotion; and inherited/restored fork boundaries can lose lineage. Reopened for fixes and production-shaped regressions.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Found by the TASK-33621.13 verifier and reproduced on the merge-base 857b3dd7d0. After the Conversation Inspector has been opened once, Ctrl+Q exits the UI but the Python process stays alive for 20-65 s or more. With no Inspector opened, the process exits in about 1 s. A lingering process can hold database locks and profile leases, which blocks a prompt relaunch.
<!-- SECTION:DESCRIPTION:END -->

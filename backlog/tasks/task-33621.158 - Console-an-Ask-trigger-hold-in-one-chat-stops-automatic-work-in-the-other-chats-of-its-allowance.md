## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
From TASK-33621.153's review (found by reading; not reproduced; pre-existing since TASK-33621.80). A wake held at the Ask compaction trigger pauses the whole allowance root durably: ConsoleFleetWakeCoordinator._pause calls AutomaticWorkLedger.pause, which writes the root's status paused / pause_reason compaction_ask. check_active refuses every chain under a paused root (other than autowake_disabled) with the root's pause reason. So a turn that is already running in another chat under the same allowance (for example a wake in a chat the agent started) is stopped: its deadline watcher (_watch_deadline) calls context.check(), gets AutomaticWorkRefused('compaction_ask'), signals Stop and cancels the delivery. _finish_attempt then pauses that chat with the root's reason, so its fleet section reads 'Paused: context limit. Results saved. Run /compact to continue.' although that chat is over no trigger. Only compacting that other chat, or leaving Ask there, would lift its pause.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Setup has no single source for what things are called or where they live, so every surface hard-codes its own answer and they disagree. The setup task goes by seven names, and the tracker's 'Voice' and 'Speech' read as synonyms. Re-running setup takes about 11 keys under Settings ▸ Troubleshooting ▸ Diagnostics, and the palette finds nothing for 'api key' or 'getting started'. When an optional step fails to render, it blocks as 'required', and 'Use manual setup' opens raw TOML or a page with none of the step's controls. Dictation has no Settings home at all, though Welcome promises everything can be changed in Settings. The Summary hides the data folder and where each key comes from. The User Guide contradicts the shipped wizard in about seven places and carries 'Verified against' stamps that CLAUDE.md forbids. Users who come back to change one thing can't find it, and the guide sends them to the wrong place.

This implements enabler E-b (the setup registry) plus the User Guide pass from the review report, Docs/superpowers/qa/first-run-wizard-ux-review-2026-10-02/README.md (§4.4, §5.2). E-b is one mapping from each setting to its display name, owning destination and route. Step copy, Summary rows, manual-setup routes, palette aliases and a guide claim-check all read from it. Resolves: [cross-cutting-13] [voice-speech-16] [cross-cutting-11] [cross-cutting-12] [protect-summary-13] [cross-cutting-16] [cross-cutting-18].

Coordination: task-33623 (Console action registry and glossary, To Do) overlaps. This task takes over its setup-registry slice ([cross-cutting-11] [cross-cutting-12]), and task-33623 should be updated to point here instead of duplicating it. The guide claim-string gate is task-32589, and the drift check here should feed it. TASK-33008 AC#8, which still asks for Verified-against stamps, gets amended. The task runs last among the implementation groups (after TASK-34100.6-.10 and .13) so the registry and the guide describe shipped behaviour: final step names, Notes removed, the Speech engine choice, re-run behaviour.

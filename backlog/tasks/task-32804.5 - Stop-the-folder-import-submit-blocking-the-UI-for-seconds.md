## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
A folder import runs a registry listener that deep-copies the whole job queue before any of its early returns, which is O(n-squared): 1.65 s per 1,000 files, and 1,000 is the designed scan-limit maximum rather than a pathological input. The listener then fires again on each later job transition. A second component, one fsync'd commit per job, was measured at 2.8 ms per job by the reviewing agent and 0.03 ms on re-run, so that half is environment-dependent and should be measured before being treated as a cost.

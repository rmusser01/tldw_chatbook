## Implementation Notes

<!-- SECTION:IMPLEMENTATION_NOTES:BEGIN -->
Approach: each import-time read now happens when used.
- Document_Processing_Lib: `media_config` -> `_document_chunk_defaults()` (read in `process_document`); PDF_Processing_Lib `media_config` was unused, deleted.
- rag_service: 20 `[rag.service]` constants -> `_RAG_SERVICE_CONSTANTS` table + `_rag_const(name)`; module `__getattr__` keeps the names importable. NOTE the old read (`load_settings().get("rag")`) never matched anything (no top-level "rag" key), so these knobs were always defaults; they now read `get_cli_setting("rag","service")` like `active_config.py`, so they can take effect. Failed reads fall back to defaults.
- optional_deps: env-var eager flag stays at import; the config flag moved to `apply_config_eager_dependency_check()`, called from `TldwCli.on_mount`.
- app.py: unused `APP_CONFIG = load_settings()` deleted.
- Ratchets: rag_service size pin 4507 -> 4517; diagnostic inventory regenerated (3 warnings only swap a constant for `_rag_const(...)`); `PRE_EXISTING_DROPS["rag"]` removed from the table guard (the read it listed is gone); fusion-knob test patches the new table.
Red at base (9bbd5c2515): `test_import_time_settings_are_read_when_used_after_reload` (assert 3 == 5) and `test_settings_modules_import_without_reading_config` (11 reads recorded). Green at head.
The import test arms its recorder after `tldw_chatbook.config` is imported (config.py loads settings at import itself) and counts reads made directly from the five modules.
Files: the five modules, Tests/test_config_hot_reload.py, Tests/Local_Ingestion/test_ingest_import_weight.py, Tests/RAG_Search/test_fusion_config_knobs.py, Tests/test_config_load_settings_table_guard.py, Tests/Architecture/{test_module_size_ratchet,test_persistent_diagnostic_inventory}.py, Docs/security/production-diagnostic-inventory.json.

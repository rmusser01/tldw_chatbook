## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
When the emergency stop holds a running research run (TASK-33620.1.12), `LocalResearchEngine._check_emergency_stop` checks the run's execution lease and then calls the service's `cancel_run`. The cancel itself is not fenced by the lease, so if the lease passes to another executor between that check and the cancel, this engine cancels a run it no longer owns. The window is small. Found in the TASK-33620.1.12 review (round 5).

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
`test_new_focus_supersedes_pending_suspended_anchor_and_is_revealed` passes 20 of 20 serial runs. No assertion changed and no production code changed.

Isolation first. Tests/UI/test_console_settings_geometry.py had no isolation marker, so run on its own every node errored at setup with `RecoveryRequired: raw_source_selection_changed` (20 errors); it only ran when another file had imported the app first. The module now carries `pytestmark = pytest.mark.bootstrap_profile`. No test in the file writes config, so the shared bootstrap profile is safe. Run alone, serially: 20 passed.

Measured flake. With the marker and nothing else, the test passed 15 of 20 serial runs. All five failures were the same line, the test's own precondition: `assert snapshot.scroll_anchor > 0` with `scroll_anchor=0`.

Cause. The test focused Change and scrolled the body away from it in the same breath. Focusing a control arms the modal's focus reveal, a 0.06 s timer (`_FOCUS_REVEAL_SETTLE_DELAY_SECONDS`). `pilot.pause()` waits for the process to go idle, so under load it can outlast that timer. When it did, the reveal scrolled Change (virtual y 0) back into view before the snapshot, and the anchor was 0. A mounted probe shows it both ways: scroll inside the reveal window and wait, and the reveal moves the body from 4 back to 0; let the reveal settle first, or disable it, and the body stays at 4.

Fix. The test waits for Change's reveal itself before it scrolls the body. Its reveal recorder (a wrapper around `_reveal_focused_control` that the test already had) is now installed before Change is focused, and a local `wait_for_reveal` polls, bounded by 10 s of wall clock, until that control's reveal is recorded; a timeout fails with the control's id. The later wait for the new target's reveal uses the same poll. Every assertion is as it was, including the precondition that failed, and `reveal_records[-1]` is still the new target.

Review round 1. The first fix waited `pause(0.12)` then `pause()`. It measured 60 of 60 but only narrowed the race, so it was replaced by the poll above. Controls, run from scratch copies that were not committed:
- Product timer 0.2 s and a 0.3 s pause after the scroll (the load case, made repeatable): the `pause(0.12)` version fails on `assert snapshot.scroll_anchor > 0`; the polling version passes.
- Product timer 0.5 s: the `pause(0.12)` version fails (`reveal_records` is empty); the polling version passes.
- Reveal disabled: the polling version fails with `no reveal for #console-settings-model-change`.

Verification: 20 of 20 serial runs (`-p no:xdist`) of the test with the poll; 15 of 20 with the marker alone. The file under `-n 6`: 20 passed.

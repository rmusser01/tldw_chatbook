## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Remove the Models destination's unverified direct-write GGUF download surfaces after managed import and runtime source selection are available, without removing legitimate external directories, Hugging Face IDs, provider-owned caching, or the Hugging Face inference provider.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria

- [ ] #2 The Transformers huggingface-cli download controls worker and direct-write destination path are removed
- [ ] #3 The separate Hugging Face inference provider and provider-owned model-ID caching remain unchanged
- [ ] #4 Existing local-directory scanning arbitrary external model directories Hugging Face IDs and previously downloaded unmanaged GGUF discovery remain usable
- [ ] #5 The Models destination contains no callable unverified direct-write downloader and its empty states direct users to Import or External selection
- [ ] #6 Dead-reference action-census mounted UI and regression tests prove removal without deleting unrelated provider functionality

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Why: all three Library personas, the first-timer (j2), the power user (j4) and the researcher (j7), ran RAG Answer with Console and `[chat_defaults]` set to gpt-4.1-mini. Before Run, the panel said only "To openai: question + evidence". The paid call went to the OpenAI handler's own default, gpt-5.6-terra, a reasoning model none of them chose. The app log shows "dropping explicit temperature/top_p for reasoning model". The model was named only after the call: "openai · gpt-5.6-terra · $0.0006 (90 tok)". The verifier found it wider than reported: with Console set to Anthropic, RAG Answer still billed OpenAI. PRODUCT.md requires authority and cost to be visible before an action, and here users pay for a model they never picked and find out only afterwards.

Observed (verify/nl-v-l-06 at 160x45):
- 04-prerun shows "To openai: question + evidence" above Run.
- 13-postrun-anthropic-console shows "openai · gpt-5.6-terra · $0.0006 (95 tok)" while Console was set to Anthropic.

Verified cause (origin/dev 2d34cbf80d):
- `resolve_library_rag_answer_provider` (Library/library_rag_answer_service.py:163-189) returns `(config.default_api_endpoint, None)` by design.
- The provider therefore comes from `[llm_api_settings] default_api` (config.py:10837-10847, which falls back to 'openai'), not from `[chat_defaults]`.
- The model is always None, so the OpenAI handler's own default applies (config.py:2753, where `openai_model` defaults to 'gpt-5.6-terra').
- The pre-run line (Library/library_rag_state.py:327) can name only the provider.
- The scheduled-automation path falls back to the same resolver (Scheduling/automation_execution.py:152-157).

Suggested direction (the review's refined fix; a direction, not a mandate):
- Resolve the provider and model from the persisted `[chat_defaults]` the way briefings do: Subscriptions/briefing_service.py:325-354 goes through `resolve_remembered_provider_model`, which never borrows a model across providers.
- Pass the model through to the call.
- Name both provider and model before Run, for example "To OpenAI · gpt-4.1-mini: question + evidence".
- Apply the same resolution to the scheduled-automation fallback.
- Out of scope unless the owner rules otherwise: following an unsaved, live Console session selection (the briefings precedent treats that as session state) and a model chooser next to the mode toggle (the review's roadmap item R-04).

Review finding(s): L-06. Source: qa/notes-library-ux-review-2026-10-02/report.md

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Found by the review of TASK-33620.15.8. Send's readiness is synced from two places. The screen's sync (ChatScreen._sync_console_composer_action_state) counts a draft or a staged image (_console_pending_image_attachment). The composer's own sync (ConsoleComposerBar._sync_current_action_state) counts a draft or any pending attachment label. Whichever runs last decides Send's state. Since TASK-33620.15.8 the composer's own sync runs one callback after a Send's acceptance, so after any screen sync in the same step, and its reading wins there. The divergence predates that task and matters only if a non-image attachment label can stay staged; whether it can has not been checked.

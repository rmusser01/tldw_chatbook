## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
These are the review's minor observations (report.md 'Minor observations') that belong to model-configuration surfaces and need no layout change. Each is small, and none has an open task.
- ModelSearchPicker says '1 models available' (Widgets/model_search_picker.py:594). It also truncates results to MAX_RESULTS = 20 (:68, :640) without saying that more matched.
- SettingsURLInput renders endpoint URLs with a zero-width break after the scheme (UI/Screens/settings_screen.py:1318, :2231-2236, :2353). The stored value stays clean. The break exists only to stop textual-web autolinking, but it is drawn in native terminals too, so a URL copied from the screen may carry it.
- Saving a keyless provider writes api_key_env_var and credential_source keys it never uses: the save builds its mutation with a credential source for every provider (settings_screen.py:30088). ADR-012 already omits credential fields from writes in the Anthropic subscription case.
- Inputs clear to their placeholder on focus, hiding the committed value while it is edited. This came from a live run and is not yet traced to code.

Out of scope: toast and tooltip placement, which are app-wide.
<!-- SECTION:DESCRIPTION:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
- AC#1/#2 (Widgets/model_search_picker.py): `_count()` pluralises "1 model available" / "N models available" (and the "Live catalog unavailable. Showing N configured model(s)." line). `_render_match_status()` replaces the two copies of the no-match tail in the flat and provenance paths and adds "Showing 20 of N matching models. Type to narrow the list." whenever MAX_RESULTS cut the list; narrowing under the cap restores the plain count.
- AC#3 (UI/Screens/settings_screen.py SettingsURLInput): `_breaks_autolinks` = not password and `self.app.is_web`; `_value` and `_display_index` fall back to Input's own when it is false, so a native terminal paints the raw URL. Tests/UI/test_settings_url_input.py is rewritten on purpose: its display-math pins now run on a `_WebURLInputTestApp` (is_web True), and a new native test asserts no zero-width character, focused and selected. The hub's pure-helper pins describe the web display and are kept, annotated.
- AC#4 (ruling R10, AC amended): the cause was Settings prefilling the shipped template's `api_key_env_var = "LLAMA_CPP_API_KEY"` and `_provider_current_credential_source` treating any env-var name as an "environment" choice, so a model save wrote the name plus `credential_source = "environment"`. Now, on a legacy keyless section (no persisted credential_source), an untyped name is not a credential choice; the existing readiness fallback returns "environment" only when the variable holds a key, else "none" (which the shared builder turns into deleting the name). A typed name, an explicit persisted source, and keyed providers are unchanged. The shared `build_provider_setup_mutation` is untouched: it and its validator require credential_source outside ADR-012's Anthropic-subscription preserve case, so "writes no credential_source" was not reachable from Settings; and legacy mode on a section still carrying the template name would pick up that env key later. Hence the amended AC#4 records the explicit "none".
- AC#5 (ruling R11: Python cause, fixed here): ModelSearchPicker and ConsoleProviderPicker `on_descendant_focus` set their Input to "" to show an unfiltered list, which painted the placeholder. They no longer blank it; Input's `select_on_focus` selects the value so the first keystroke replaces it. The BASE-vs-HEAD comparison caught that a focusing CLICK then collapsed that selection (test_popover_apply_returns_replaced_settings failed at HEAD only), so both inputs now derive from `PickerSearchInput` (model_search_picker.py), whose focusing click selects all (same mechanism as the Library rail's SelectAllOnFocusingClickInput, which is off the UI-ready path; no new module, ADR-097 census has zero headroom). Settings ▸ Providers & Models never hid values; its probe guards that.
- AC#6: console_settings_modal.py is not modified (7807 lines, ratchet green).
- Tests: Tests/UI/test_focus_keeps_committed_value.py (new, modal + private-profile Settings probes at 211x44 via real Tab presses, painted text and fg != bg); picker widget tests (copy, focus, focusing click); the rewritten pin `test_blur_restores_committed_model_after_uncommitted_filter` (value no longer "" after focus); `test_settings_keyless_provider_save_keeps_template_env_name_out` (private profile, real writer, 3 cases incl. env set and explicit "environment"; a mutant dropping the explicit-source clause fails its case).

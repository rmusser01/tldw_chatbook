## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
`Tests/UI/test_settings_search_index.py::test_speech_provider_form_fields_match_the_panel_source` is red, and nothing in the environment causes it. It is a source-only test, and it fails on "only in table: omnivoice model_root, voice_resource_directory". The test checks that the Speech index table `SPEECH_TTS_PROVIDER_FORM_FIELDS` and the panel's `_compose_provider_form` name the same fields. OmniVoice's Model root and Voice resource directory are composed with `self._path(...)`, so the scan never sees them, and both table rows read as stale even though the panel renders them.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Four smaller wire defects: the vLLM summarizer raises `UnboundLocalError` on every call that passes an explicit key, because the configuration is only bound on the no-key branch; the Anthropic summarizer mounts a retry adapter on a session it never uses, so a 429 returns nothing and the configured retry count is inert; three summarization stream generators yield the accumulated full text again after the deltas, doubling the summary for any consumer that joins chunks; and two providers honour a `Retry-After` header with no upper bound, sleeping it on the worker thread.

Source: core-runtime code review 2026-09-17 — `qa/core-code-review-2026-09-17/report.md`; per-slice evidence in `qa/core-code-review-2026-09-17/slices/`, reproductions in `qa/core-code-review-2026-09-17/phase4-verification.md`.
<!-- SECTION:DESCRIPTION:END -->

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Summarization_General_Lib.py::_dispatch_to_api calls each provider's summarizer with positional arguments, and two of the nineteen calls bind them wrongly. Listed by Phase 9's Task 9 with ast, each call's arguments against the callee's parameter names: KoboldCpp receives its temperature as system_message, its system message as temp, and the streaming flag as kobold_api_ip; Ollama receives the streaming flag as model. The other 17 calls pair name to name. No credential is affected. In the same file summarize_chunk (marked FIXME, no caller under tldw_chatbook/) passes its text to analyze as api_name. Found while fixing TASK-33001.14; read from the code, not run.
<!-- SECTION:DESCRIPTION:END -->

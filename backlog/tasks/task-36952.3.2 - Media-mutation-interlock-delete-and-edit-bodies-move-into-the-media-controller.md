## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The ADR-055 mutation interlock, bulk and single-item delete, undo and the edit save still live on LibraryScreen while the controller drives them through callbacks, so the one audited claim seam sits in a different class from most of the handlers that use it. Moving them together keeps the interlock and its callers in one home.

Source: architecture review 2026-10-25, `Docs/QA/architecture-review-2026-10-25/report.md` §F2; slice 2 of 8 in the TASK-36952.3 split plan, measured at `08b3c9d337`.

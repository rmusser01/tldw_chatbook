## Description

Implement the approved local-first Ctrl+K operational switchboard with durable activity receipts, bounded Active/History projections, exact destinations, onboarding, domain-semantic search, and consequence-aware acknowledgement.

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Ctrl+K opens immediately in Active with ordered Waiting for you, Working, New results, Current, and Other open groups; lifecycle never hides active execution or attention.
- [x] #2 Canonical subjects and unavailable-session notices deduplicate deterministically and carry immutable explicit activation or receipt-keyed Mark seen payloads with no nullable or positional target inference.
- [x] #3 History searches every persisted local conversation, groups by local calendar recency, pages bounded results, and remains usable when activity storage is degraded.
- [x] #4 Nonblank Active search widens to History only after zero Active matches; F3 retains the modal-lifetime query and modal close resets it.
- [x] #5 Ordinary and FLEET terminal outcomes persist as idempotent revisioned receipts; corrections supersede obsolete revisions, in-turn children do not duplicate outcomes, and migration creates no historical flood.
- [x] #6 Success acknowledges only after exact destination and receipt notice visibly load; unsuccessful outcomes and unavailable sessions clear only through exact receipt-keyed Mark seen actions, and newer arrivals remain unseen.
- [x] #7 Receipt publication, compatibility marks, hydration, and orphan repair are race-safe and failure-isolated without deleting or rebuilding AgentRunsDB or interrupting execution settlement.
- [x] #8 Ordering, paging, async-generation rejection, focus retention, strict F2, pointer/keyboard parity, literal-safe two-row labels, width omission, and a visible Cancel are deterministic; scope, current tab, and Enter destination are unambiguous; rows use a left-aligned scan path and semantic theme colors; the modal sizes to content up to a 35-row ceiling.
- [x] #9 Ctrl+K and F3 perform no network request, mount at most 50 result rows plus bounded controls, reconstruct no transcript, and leave Console Context/Inspector ownership unchanged.
- [x] #10 Blank-query Enter targets the MRU other open tab, explicit navigation and nonblank search target the highlighted committed result, and inline onboarding plus plain-language domain-semantic state/workspace search expose contextual consequences and distilled metadata without transcript inspection, embeddings, or network calls.
- [ ] #11 Focused DB/Chat/UI suites, production-stylesheet compositor evidence, real-path acknowledgement verification, scoped static checks, and equal-cell terminal parity satisfy the approved spec; Windows Terminal evidence may remain the sole final closeout blocker until TASK-20937.6 supplies it.
<!-- AC:END -->

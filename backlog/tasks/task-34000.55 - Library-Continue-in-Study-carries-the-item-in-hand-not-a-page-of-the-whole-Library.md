## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Why: a researcher who opens one paper or note and chooses Continue in Study expects to study that paper or note. TASK-34000.6 found that the hand-off stages the Library snapshot PAGE instead: up to 100 notes (the page size), never the item that is open. The review saw this as "Carries forward: … and 134 more" (j7).

TASK-34000.6 made the hand-off and Study describe that scope from one shared describer, so both now agree ("and 7 more"). What gets carried is unchanged. It is still not the item in hand, and the count depends on page size rather than on what the user chose.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Continue in Study from an open media item or note carries that item (and only items the user explicitly added), not the snapshot page

- [ ] #3 Continue in Study with nothing open states what will be carried before the user commits, rather than silently carrying a page of the Library
- [ ] #4 A real-app Pilot test that fails on dev: open a non-first note, Continue in Study, and assert Study's carried scope is exactly that note

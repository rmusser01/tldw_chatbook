## Description

Why: The folder pickers TASK-34000.28 (polish-1a task 3) rebuilt for Move note, Move folder and Add to folder page every active folder through `LocalNoteFolderRepository.page_folders`, ordered by `normalized_path, id`. A space (0x20) sorts before the path separator `/` (0x2F), so a sibling whose name extends another folder's name lands between that folder and its children. Repro: with folders "Projects", "Projects/App launch", "Projects/Thesis" and "Projects archive", open Move note: the list reads "Projects", "Projects archive", "Projects / App launch", "Projects / Thesis". Evidence: Task 3's review (M-5, parked) and the final whole-branch review's triage, which filed it here at low priority. Every row shows its full breadcrumb, so nothing is ambiguous and nothing is chosen wrongly; the tree order just breaks where a reader expects a folder's children to follow it. A fix changes `ORDER BY` on a paged query, so the index-plan rule in CLAUDE.md applies.

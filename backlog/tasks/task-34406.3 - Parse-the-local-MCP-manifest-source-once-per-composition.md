## Implementation Notes

<!-- SECTION:IMPLEMENTATION_NOTES:BEGIN -->
Implemented one fresh source parse per local MCP capability manifest, sharing the AST through the existing walkers. Independent calls and zero-argument helpers remain fresh, schemas remain detached, and source errors propagate. No cache, dependency, permission, audit, native admission, worker owner or public service contract changed. Existing ADR-126/230 apply; no new ADR is required. Docs/Architecture/tool-catalog.md and the concrete testing-evidence lesson are updated. Implementation commit: 6e84f1dda178925f39575a3f0edaddb5cbe50b5f.

Causal baseline failed 3 parses versus 1; final four new/original manifest controls pass. Connected testing: 202 passed, 14 failed, one optional-extra skip. Exactly the same 14 failing nodes failed unchanged baseline production; source was restored exactly. The broad cohort is not green. Ruff adds no findings; 85 baseline diagnostics remain. Fatal checks, production/new-test formatting and diff checks pass. Independent source and raw measurement reviews found no new blocker.

The clean committed-head manifest-only benchmark measured 10.668021 to 3.953146 ms median wall time (62.94% lower), 60 samples per arm in B/C/C/B blocks; complete ordered manifests match. This is warmed parser evidence, not a cold Console result. A complete balanced four-profile-per-arm first-send experiment made eight HTTP-200 calls with exact synthetic content, 27 identical schemas each, matching settings/headers, verified traces, zero pending checkpoints and audited owned cleanup. Post-save median was 3980 to 4064 ms; three of four candidate pairs were slower. Input-to-POST median was 8.030831 to 7.381325 seconds but only two pairs improved. Host load rose 10.67 to 37.06 on 18 logical CPUs. No whole-Send speedup is demonstrated.

The original 232 ms inclusive composition varied to 43 ms without source changes. A separate final diagnostic shows inventory is small relative to permission/catalog path spans and concurrent startup imports. Inclusive spans do not isolate I/O from scheduling, GIL contention or instrumentation, and async thread time is not self CPU or an additive cost. Earlier partial typing/rendering/mouse/idle experiments are retained and excluded. The final protocol measures one first send per fresh app using atomic draft insertion and Enter, not later sends or mouse submission. Task remains In Progress: inherited connected failures and broader cold-Send validation remain unresolved. Full suite, hosted CI and native Windows/paint checks were not run. Evidence: cold-tool-composition-report-r1.md, cold-manifest-final-measurement-review-r1.md and the immutable packets in this chat evidence directory.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
**Impact.** With Capture On (the default), every send in a Temporary tab pauses on 'Save chat to capture this send', and the runtime records a turn recovery. The queue shelf then reads 'Queue 0/10 · Unsent turn needs attention' with a clipped 'Rest' and 'Discard', even while the pause callout is still on screen. After 'Send without capture' the turn is sent once and answered ('OK 7'), but nothing settles the recovery. The shelf still reads 'Unsent turn needs attention' more than 30 s after the reply. Clicking 'Rest' (Restore) puts the already-answered prompt back in the composer, so one more Enter sends a duplicate paid request. The label is clipped because the button is 8 cells wide.

**Severity / prior art.** P1, NEW. Related Done work on send recovery: TASK-31976, TASK-32197, PR #2882 (task-32953). The code is in `prompt_queue.py:190-195,355-361` and `wiring.py:2246-2258`.

Not part of this task:
- A shelf after a blocked send in an archived tab is a legitimate recovery.
- Parked recoveries are lost on quit or restart; that is finding G4-11.

**Suggested direction.**
- Do not record a turn recovery for a paused, non-terminal preparation that its callout already owns. Otherwise, discard the matching recovery once Send without capture or Save & Send reaches durable acceptance.
- Make restore refuse an entry whose turn has since been accepted.
- Size the shelf buttons to their labels.

Evidence: qa/console-ux-review-2026-09-29/findings.md → G1-13 (source J3-05); qa/console-ux-review-2026-09-29/evidence/evidence__J3__17-temp-stale-shelf.txt, evidence__J3__18-restore-stale.txt.

Reproduced: the new mounted Cancel tests are red on a2a04f5052 at the image-return assertion. The text itself did come back -- the store's cancel writes the executed draft back for a manual send -- so the review's voice-text loss did not reproduce; the voice-shaped variant (text never in the composer) checks the image too.

Fix: the runtime records the turn again, held off the shelf. `card_holds_refusal` (PAUSED in `CARD_OWNED_PAUSES`) sets `_ConsoleTurnRefusedError.card_held`, and `_record_turn_recovery` holds that preparation. The compaction hold keeps TASK-34350's no-record exemption (its own attachment loss is TASK-37810). The card dispatch in session.py gives a card-owned pause the shelf-releasable lifecycle:
- an accepted action forgets the turn;
- Cancel returns text and attachments through `return_turn_recovery_to_draft`;
- a re-pause, or an interrupted action that leaves it paused, stays held;
- anything else goes back on the shelf, so nothing is lost.
A trace pause (after the durable commit) keeps no turn, so its Cancel refills nothing. The `console_unsent_turn` import now happens only on a refusal. Ratchet rows: console_runtime.py 6686 -> 6701, session.py 7004 -> 7011 (dated, owner rule).

Tests: `test_cancel_on_a_capture_pause_gives_back_the_message_and_its_image[composer|voice]` is red on dev and on a2a04f5052 and green here. Mutations, each restored by Edit: the session lifecycle off turns 3 mounted tests red; card_held off turns 3 red; the keep-held branch off turns 2 unit tests red. New unit tests cover card_holds_refusal per pause kind, the interrupted keep-held, and clear_answered_draft's follow-up, expansion and attachment-only branches.

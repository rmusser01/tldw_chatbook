## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
C8(1), UI half. For Anthropic, the modal renders Min P, Seed, Presence and Frequency unconditionally (console_settings_modal.py:1976-2017).
- PROVIDER_PARAM_MAP['anthropic'] has none of them (Chat_Functions.py:281-300).
- project_chat_handler_kwargs forwards only mapped keys, with no warning (:1431-1435).
- The data root cause, _supported_console_settings_fields treating every sampler as universal (console_chat_controller.py:774-802), is fixed in P1 by one supported-fields function (capability projection ∩ PROVIDER_PARAM_MAP). This task makes the modal honour it.

Only the reasoning and thinking controls have support treatment today:
- _GENERATION_CONTROL_INPUTS (:848-854).
- PROVIDER_CHOICE_NO_EFFECT_SUFFIX (:846).
- Per-row 'Support not verified' statics (:847).

Constraints:
- ADR-006: an unsupported control is omitted or shows unavailable copy.
- TASK-30012 AC#3: a control is hidden only on authoritative evidence, and unknown support stays available with neutral copy (pinned by Tests/UI/test_console_session_settings.py:5653 test_console_settings_modal_keeps_unknown_support_visible_with_neutral_copy).

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Chat settings now hides the fields the chat's provider does not accept and names them on the Sampling title.

**Approach**
- `Widgets/Console/console_settings_field_row.py` owns `_sync_generation_control_support` (same name, so its call sites and two tests that patch it are unchanged). Samplers follow `supported_generation_fields(provider, model, app_config)`; the reasoning and thinking controls hide only on an authoritative `console_generation_control_support(...) == "unsupported"`, and an "unknown" one stays visible with "Support not verified for this model." leading its own help line (R16, TASK-30012 AC#3). Both functions live in `console_provider_support.py`; the modal keeps no table.
- The Sampling title is `hidden_fields_line(...)`: "Sampling · hidden for Anthropic: Min P, Seed, Presence penalty, Frequency penalty, Reasoning effort, Reasoning summary, Verbosity (this provider does not accept them)". Names come from `MODEL_FIELD_LABELS` (R3), the provider from `provider_display_name(provider, app_config)` (a registry entry shows its own name).
- `_apply_rebased_state` now runs the sync, so a provider or model change through the controller's rebaser (the seam pick mode's dismissal lands on, and the path the Connection pickers already take in the live app) updates the hidden rows and the line in the same call. Before this, the rebaser path never refreshed support at all.
- A focused field that becomes hidden hands focus to where the view opens (R13).
- Removed from the modal: `_GENERATION_CONTROL_INPUTS`, `PROVIDER_CHOICE_NO_EFFECT_SUFFIX` (it only ever showed on hidden rows' tooltips), `GENERATION_CONTROL_UNKNOWN_COPY` (now in the field-row module) and the per-row `-support` Labels. The modal shrinks 7,516 -> 7,466 lines; its ratchet row is lowered to 7,466.
- CSS: `ConsoleSettingsModal CollapsibleTitle` joins the existing full-width rule, so a long title wraps inside the frame instead of running under the border (Textual's `width: auto` title does not wrap). Boot CSS 608,049 -> 608,089 B (limit 608,090); T4's -494 B is still to come.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
`config.py` keeps three module-level DB singletons filled by `get_*_db_lazy()` and an `initialize_all_databases()` that no production code calls. Remaining consumers are the app, `app_feature_glue`, the CCP character handler, `Character_Chat_Lib`, `Utils/doctor.py` and `MCP/local_runtime_delegate.py`. Each process that needs a DB should construct or receive it at its own composition root.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Found in the pre-merge review of TASK-33620.15.1 (2026-10-20). The config-sync cadence reads the Agent rail's section lines and fleet rows as projection inputs on every 0.2 s poll tick, and a tick that projects then computes the same lines again to render them. While the rail is drilled into a sub-agent each computation makes one subagent-run DB read, so a projecting tick makes two where dev made one, and a skipped tick still makes one. The cost is small (one keyed read) but it runs at the poll's rate during a run and is pure duplication.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Measure Character controls and contain the complete image in the remaining rows with one equality-bounded layout follow-up across graphics and mosaic fallbacks.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 The Character section's 35-row ceiling covers image, character name, reaction state/action, and real spacing; mounted non-image controls are measured rather than represented by a hard-coded row count.
- [ ] #2 Valid portrait, landscape, square, and very large images render completely with aspect-ratio-preserving contain behavior, remain centered with acceptable letterboxing, and never crop, stretch, or push controls outside the initial 35 rows.
- [ ] #3 Graphics and mosaic fallback paths reuse the existing fit/contain utilities and settle to the same cell box for the same rail geometry; no new parallel aspect-ratio implementation is introduced.
- [ ] #4 Width, terminal height, image, metadata, control, and scrollbar changes update the image only when the computed box changes and permit at most one equality-guarded follow-up reconciliation without a layout loop.
- [ ] #5 Missing, corrupt, and unsupported images keep the short textual body at natural height, preserve existing recovery copy/actions, and leave every control keyboard- and pointer-reachable.
- [ ] #6 Production-shaped tests prove exact body containment, local hint/scroll behavior above 35 rows, focus recovery after image/control replacement, collapse/reopen offset continuity, and no Inspector or other Context ceiling regression.
<!-- AC:END -->

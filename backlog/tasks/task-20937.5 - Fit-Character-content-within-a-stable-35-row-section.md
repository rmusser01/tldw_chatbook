## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Measure Character controls and contain the complete image in the remaining rows with one equality-bounded layout follow-up across graphics and mosaic fallbacks.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 The Character section's 35-row ceiling covers image, character name, reaction state/action, and real spacing; mounted non-image controls are measured rather than represented by a hard-coded row count.
- [x] #2 Valid portrait, landscape, square, very small, and very large images render completely with scale-down-only, aspect-ratio-preserving contain behavior, remain centered with acceptable letterboxing, and never upscale merely to fill the available box, crop, stretch, or push controls outside the initial 35 rows.
- [x] #3 Graphics and mosaic fallback paths reuse the existing fit/contain utilities and settle to the same cell box for the same rail geometry; no new parallel aspect-ratio implementation is introduced.
- [x] #4 Width, terminal height, image, metadata, control, and scrollbar changes update the image only when the computed box changes and permit at most one equality-guarded follow-up reconciliation without a layout loop.
- [x] #5 Missing, corrupt, and unsupported images keep the short textual body at natural height, preserve existing recovery copy/actions, and leave every control keyboard- and pointer-reachable.
- [x] #6 Production-shaped tests prove exact body containment, local hint/scroll behavior above 35 rows, focus recovery after image/control replacement, collapse/reopen offset continuity, and no Inspector or other Context ceiling regression.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Implemented measured scale-down-only Character containment under the complete 35-row body contract. The mounted rail measures real non-image rows, centers natural-sized small art, shrinks only oversized portrait/landscape/square art without crop or stretch, and uses one shared exact cell-box calculation for graphics and mosaic. Geometry replacement is equality-guarded, serialized, cached, and limited to one follow-up per invalidation epoch; source or real viewport invalidation starts a new epoch. Collapse/reopen preserves the section's local scroll offset, and missing/corrupt/unsupported art retains the existing natural-height recovery body.

The main changes are in `left_rail.py`, `chat_screen.py`, the new `character_avatar_layout.py`, shared `mosaic_render.py`, source/generated Console TCSS, and production-shaped Character/rail/reaction tests. The production stylesheet exposed a one-cell thumbnail-rounding disagreement hidden by the lightweight harness; the fix shares the canonical mosaic grid calculation, and the incident is recorded in `lessons-testing-evidence.md`.

Fresh verification: 138 focused Character/controller/rail/mosaic tests passed; 125 adjacent left-rail/CSS/reaction/bounded-section/edge-geometry tests passed. Scoped Ruff checks, Ruff format check, compileall, CSS bundle reproduction, and `git diff --check` passed. Mutation evidence proved removal of the equality guard remounts repeatedly, forcing a full box breaks shape/parity cases, and unserialized replacement reproduces duplicate-id mounts. The final independent review reported no Critical, Important, or Minor findings. The Impeccable detector reported only two pre-existing palette advisories outside this task's changed CSS.

ADR required: no new ADR. ADR-083 already owns the complete-body ceiling, measured-control, shared-fit, and bounded-reconciliation policy; this task implements that decision with the user's scale-down-only clarification.

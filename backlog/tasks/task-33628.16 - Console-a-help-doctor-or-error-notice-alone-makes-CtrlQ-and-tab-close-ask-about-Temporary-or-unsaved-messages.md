## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The Console loss inventory (UI/Console_Modules/loss_inventory.py) counts every transcript message that has no persisted id. Console's own system rows (command output such as /help and /doctor, and error notices) are never persisted, so in a saved chat with nothing else at stake a single /help listing makes Ctrl+Q ask "Quit Chatbook? Temporary or unsaved messages: 1", and tab close shows the same row. This was reproduced through the real system-message seam (_append_native_console_system_message) during the TASK-33628.1 review. The close dialog already behaved this way; TASK-33628.1 AC#3 (quit totals equal the per-tab close sum) carries it into quit. The row's wording also misdescribes command output as a Temporary or unsaved message.

Owner call needed: leave command and notice rows out of both dialogs, or count them under wording of their own.
<!-- SECTION:DESCRIPTION:END -->

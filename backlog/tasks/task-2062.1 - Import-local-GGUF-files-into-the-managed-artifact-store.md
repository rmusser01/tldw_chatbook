## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Provide a safe, optional way to copy a user-selected local GGUF file into Chatbook's managed artifact store without modifying the original or claiming runtime compatibility.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 A user can select a regular local GGUF and create an immutable managed copy while the original is never written renamed or deleted
- [ ] #2 The managed descriptor is path-private and content-addressed by the full SHA-256 so identical bytes under different filenames converge on the same exact artifact reference
- [ ] #3 The staged managed bytes receive bounded structural GGUF validation and authoritative digest verification before atomic promotion
- [ ] #4 Import is cancellable before promotion; failures remove only operation-owned staging; activation failure leaves a recoverable installed artifact
- [ ] #5 Successful import activates readiness but does not change llama.cpp or llamafile source preference
- [ ] #6 Installed-view import progress cancellation recovery and 80-column keyboard behavior are covered by mounted tests on supported platforms
<!-- AC:END -->

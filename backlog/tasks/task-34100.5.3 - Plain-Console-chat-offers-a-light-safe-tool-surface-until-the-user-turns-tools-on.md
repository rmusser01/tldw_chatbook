## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Implements the owner's ruling of 2026-10-04 on TASK-34100.5's owner question 1, "Light surface by default". Plain Console chat should keep a small, safe tool set (for example date/time, calculator and ask-user). It should offer no sub-agents, skills, web or other autonomous or costly tools until the user turns them on. Setup and the Summary should say exactly what is on, and small local models should get the minimal prompt.

Today a fresh profile with every tool gate off still hands plain chat the whole default agent surface. Live on TASK-34100.5's branch, gpt-4.1-nano listed sub-agent, skill, run-log, chat, web, Watchlists, todo and character tools. It answered "Reply with just: hi" by calling `spawn_subagent`; the sub-agent errored (TASK-34100.5.1) and the reply came after the tool noise (evidence g5-v-oai 03, g5-r2b-oaihome 04). The Summary's Tools row can only hedge ("gates off; the assistant may still use chatbook's own tools … when the model's context window has room"). The context meter does not count the tool surface that is sent, because the controller's `preview_tool_schemas` hook was never implemented (TASK-34100.5, AC#6 notes).

TASK-34100.5 already removed `chat_with_llm` from the catalog and plans a guessed small window without tools. This task changes what plain chat is offered by default, which that task left to the owner.
<!-- SECTION:DESCRIPTION:END -->

## Implementation Plan

Narrowest set satisfying the ruling's examples: `get_current_datetime`, `calculator`, `ask_user` (`ask_user` still follows its own gate). Everything else stays reachable once the user turns on its switch.

1. AC#1/#2 -- new helper module `Agents/plain_chat_tool_surface.py`: `LIGHT_SURFACE_TOOL_NAMES` (the one definition), the new `[tools] full_agent_tools_enabled` gate (default off; title/blurb), the config readers, and the pure narrowing: in light mode the request keeps the safe set, every built-in whose own default-off gate the user switched on (setup's Tools step / MCP Tool gates), `web_deep_search` when its gate is on, Library tools when the session allows assistant Library access, and tools from MCP servers the user added. It drops sub-agents/fleet, skills (install, script, skill file, managed promotion), fork/new chat, run-log tools, find/load discovery, Canvas, profile tools, workspace/web/Watchlists/todo/character local tools, virtual CLI/raw shell, and the built-in tldw_chatbook MCP source.

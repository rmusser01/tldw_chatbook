## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The trajectory import guards its read with a file-system error handler and its parse with a JSON error handler only, so a non-UTF-8 or deeply nested file raises a decode or recursion error straight past the seam, and the only caller catches the seam's own error type alone. The picker deliberately offers an all-files filter. The repo already uses the correct combined handler at about fifteen sites, three of them in the same package.

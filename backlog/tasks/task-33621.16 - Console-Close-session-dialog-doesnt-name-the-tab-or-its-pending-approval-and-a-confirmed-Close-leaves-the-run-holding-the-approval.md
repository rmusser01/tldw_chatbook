## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
**Impact.** Clicking ✕ on a background tab that is waiting for a tool approval opens 'Close Console session?'. The dialog:
- never names the tab;
- says the ambiguous 'Closing removes this open tab';
- always lists all six count rows, zeros included;
- does not list the pending tool approval.

Stay has focus by default, which is correct. After the user confirms Close, nothing happens: the tab (◆), its run and its approval card all stay, with no toast and no log line. Users cannot tell which tab they are closing, and after a confirmed destructive action they get no result. The background run keeps holding an approval the user meant to abandon.

The no-op half shares its root cause with finding G2-04 (the `_console_runtime()` AttributeError at `session.py:2796`, swallowed by `exit_on_error=False`). This task owns the dialog content and the post-confirm outcome for at-risk tabs: pending approvals, questions, skill confirmations and live runs. The finding's claim that the '⌃2 Console !' nav badge lit up after Close is wrong; it was already lit because of the pending approval.

**Severity / prior art.** P1, NEW. Adjacent work:
- TASK-28001 (Done) fixed only the close-impact predicate for saved conversations.
- TASK-32864 (To Do) covers the general modal dismissal and confirmation pattern, and nothing about this dialog's copy or outcome.

**Suggested direction.**
- Put the tab title in the dialog title.
- Enumerate only the non-zero consequences, and name pending approvals, questions and skill confirmations explicitly (for example '1 tool call waiting for your approval will be denied and its run cancelled').
- After Close, either complete the close or show a specific reason and re-offer the dialog. Never return silently from the confirm/re-check loop (`session.py:2811-2835`).

Evidence: qa/console-ux-review-2026-09-29/findings.md → GAP1-05; qa/console-ux-review-2026-09-29/evidence/evidence__GAP1__46-close-A-pending.txt, evidence__GAP1__47-after-close-A.txt, evidence__GAP1__52-A-approval-intact.txt.

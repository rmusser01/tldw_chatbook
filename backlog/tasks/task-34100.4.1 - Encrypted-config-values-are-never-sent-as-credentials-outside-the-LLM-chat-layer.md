## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
TASK-34100.4 made `enc:` ciphertext read as absent in provider-key resolution, readiness, every LLM chat handler, both summarizers, `get_openai_embeddings` and the recovered OpenAI settings. Other services still read their credential straight from config. If that value is still `enc:` ciphertext, they send the ciphertext as the key, token or HMAC secret.

That happens in two cases. In the first, encryption is off but `enc:` values remain: the non-strict disable before TASK-34100.4 wrote them, or a hand edit or a copied config did. In the second, a session never ran the startup unlock. The startup unlock decrypts strictly, so a normal unlocked session does not reach these paths with ciphertext. The values matter anyway, because enabling encryption encrypts every key that matches `is_sensitive_config_key`, including all of the ones below.

This task finishes the "no encrypted value is ever sent as a credential" half of TASK-34100.4 AC #10 for the paths outside the LLM chat layer.

Known outbound sites when this task was filed (TASK-34100.4 review round 2; a starting point, not a complete list):
- Web search: Web_Scraping/WebSearch_APIs.py reads the Bing (~2742), Kagi (~3735), Serper (~4014; sent as `X-API-KEY`), Exa (~4092) and Yandex (~4297) keys.
- TTS: TTS/TTS_Backends.py ~225-246 reads the OpenAI TTS and ElevenLabs keys.
- Remote Whisper: Local_Ingestion/transcription_service.py ~3145.
- OCR: Local_Ingestion/OCR_Backends.py ~826 (`openai_api_key`).
- Image generation: Media_Generation/config_machinery.py ~355, and the SwarmUI token at Media_Creation/swarmui_client.py ~111.
- Embeddings config: Embeddings/Embeddings_Lib.py `OpenAICfg.api_key` (~258-283) is sent as `Bearer` (~533-536); also RAG_Search/simplified/embeddings_wrapper.py ~428.
- tldw server token: runtime_policy/bootstrap.py ~214-223 and runtime_policy/server_context.py ~920.
- Confluence api and OAuth tokens: Web_Scraping/Confluence/confluence_auth.py ~361 and ~370.
- GitHub subscription token: Subscriptions/scrapers/github_scraper.py ~73.
- Agent-run webhook HMAC `secret`: Agents/run_webhooks.py ~338.
- Still to classify: Evals model `api_key` (Evals/eval_orchestrator.py ~386/403, eval_runner.py ~1312), Local_Ingestion/local_file_ingestion.py ~1043, Local_Ingestion/audio_processing.py ~789, and the custom-endpoint probe credential (UI/Console_Modules/connection_probe.py ~102-119).

Survey method: grep for config reads of keys that `is_sensitive_config_key` accepts, outside `resolve_provider_api_key` and `config.without_ciphertext`. Then keep the reads whose value reaches an outbound request, a client constructor or a signing key.

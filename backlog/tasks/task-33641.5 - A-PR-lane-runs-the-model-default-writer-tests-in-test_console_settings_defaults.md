## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
`Tests/Chat/test_console_settings_defaults.py` holds the full-path tests for the Save as model default and Ctrl+N writer (`apply_console_default_intent`), including the ADR-095 D3 quick-mask cases Phase 4 added. No pull-request lane collects it: `derived-artifacts.yml`'s PR fast lane lists four `Tests/Chat` files and not this one, `test.yml` runs on main pushes and dispatch only, and `nightly-deep.yml` (which tests dev's commit) failed or was cancelled on each of its last five runs, up to 2026-09-27. That is how 23 of its tests stayed red on origin/dev unnoticed (origin/dev dd2f1589b7, local run: 23 failed, 56 passed). Phase 4 (PR #2947) made 85 of them pass with an autouse `install_config_source` fixture. Two remain red at origin/dev and at the Phase 4 head: `test_externally_reserved_newer_generation_invalidates_inflight_precondition` and `test_newer_generation_cannot_reserve_between_precondition_and_replacement`. They monkeypatch guarded config functions, which the ADR-126 wrapper refuses as `config_source_not_installed`. The cubic review of #2947 asked for the file to be gated. Gating it is a CI-lane decision that predates Phase 4, so it is filed here.

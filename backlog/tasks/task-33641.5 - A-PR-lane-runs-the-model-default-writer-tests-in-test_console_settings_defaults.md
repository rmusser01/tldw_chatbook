## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
`Tests/Chat/test_console_settings_defaults.py` holds the full-path tests for the Save as model default and Ctrl+N writer (`apply_console_default_intent`), including the ADR-095 D3 quick-mask cases Phase 4 added. No pull-request lane collects it: `derived-artifacts.yml`'s PR fast lane lists four `Tests/Chat` files and not this one, `test.yml` runs on main pushes and dispatch only, and `nightly-deep.yml` (which tests dev's commit) failed on each of its last five runs (2026-09-23 to 09-27). That is how 23 of its tests stayed red on origin/dev unnoticed (origin/dev dd2f1589b7, local run: 23 failed, 56 passed). Phase 4 (PR #2947) added an autouse `install_config_source` fixture; at its head 85 of the file's 87 tests pass. Two are red at origin/dev and at the Phase 4 head: `test_externally_reserved_newer_generation_invalidates_inflight_precondition` and `test_newer_generation_cannot_reserve_between_precondition_and_replacement`. They monkeypatch guarded config functions and drive the writer from threads; the writer logs `RecoveryRequired` (phases `read` and `cache_reload`). The cubic review of #2947 asked for the file to be gated. Gating it is a CI-lane decision that predates Phase 4, so it is filed here.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Phase 9, plan Task 14 (Wave 5); base 0af11c2871 (after Task 4's raw-scope change, TASK-33641.6).

**Premise at the base.** One of the two generation tests is red, not two: `pytest Tests/Chat/test_console_settings_defaults.py -n 8 --dist load` gave `1 failed, 88 passed`, serially the same. `test_newer_generation_cannot_reserve_between_precondition_and_replacement` passed 10 of 10 serial runs alone and in both full-file runs; it is not flaky (its only timed waits expect False, so a slow runner cannot fail them).

**Cause (AC#1).** `test_externally_reserved_newer_generation_invalidates_inflight_precondition` paused generation A in a wrapper it installed over `config._read_raw_cli_config_unlocked`. That function is a guarded config body (`Backup_Recovery/config_participants.py::guarded`), and the guard refuses to run once the module attribute is no longer its own wrapper: A's real read raised `RecoveryRequired('config_source_not_installed')` (seen by a one-run probe in the wrapper, reverted), the writer logged `phase=read`, and A never reached the pause. The guard is right and the product unchanged; the test's seam was wrong.

**Fix.** The test, rewritten on purpose, pauses A at `console_settings_defaults._acquire_current_intent_commit_fence`, which the transaction calls after the read with the config write lock held: the same point in A's write, with nothing guarded replaced. The file's `install_config_source` fixture still selects each test's scratch config through the real admission; no node is `bootstrap_profile`. Negative control (one run, reverted): with the fence accepting any generation the test fails on its own assertion (`outcomes["a"].file_replaced` is True).

**Lane (AC#2).** The PR Fast Lane's sandboxed step ran two of this file's nodes (ruling C16); it now runs the file whole in their place (`FAST_LANE_TARGETS` in Tests/CI/test_ci_queue_pressure_contract.py and the matching line of `.github/workflows/derived-artifacts.yml`). In the lane's install set (a scratch blocker hid every package outside `-e . pytest pytest-asyncio pytest-timeout packaging`, plugins loaded as the lane loads them), serial: `89 passed` in 22.34 s, 22.14 s and 22.13 s. The two nodes it replaces took under a second each, so the step gains about 21 s against its median 16.1 / max 20.8 min with setup (TASK-34916's replay) under a 35-minute cap.

**Negative control (AC#3).** With the quick-mask write changed to write a fallback Max tokens (4096) instead of deleting the override, the file gives `6 failed, 83 passed`: `test_quick_blank_max_tokens_deletes_the_exact_profile_override[save_model_default]` and `[make_new_chat_default]`, and the four `test_quick_blank_max_tokens_rebased_to_a_model_still_deletes_its_override` cases. The two nodes the lane ran before passed with that write. Reverted.

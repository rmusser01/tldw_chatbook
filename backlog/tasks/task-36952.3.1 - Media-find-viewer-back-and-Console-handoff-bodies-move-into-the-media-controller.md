## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The media controller still calls back into LibraryScreen for the reader's find, Escape-label and viewer-back behaviour and for the Console handoff, through seven constructor lambdas, so one behaviour spans two classes and its tests reach it through screen fakes. Giving these bodies one home on the controller removes those callbacks and lets the tests address the owner.

Source: architecture review 2026-10-25, `Docs/QA/architecture-review-2026-10-25/report.md` §F2; slice 1 of 8 in the TASK-36952.3 split plan, measured at `08b3c9d337`.
<!-- SECTION:DESCRIPTION:END -->

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
TASK-36942.2 froze the agent runtime's import footprint; this task empties it. Three chains load the UI, DB, HTTP and config layers:
- `agent_runtime.py:22` and `project_instruction_runtime.py:15` import `EPHEMERAL_ORIGIN_KEY` from `Chat.console_project_instructions`, which imports httpx (`:12`) and runs `Chat/__init__`, which loads the DB.
- `agent_runtime.py:23` and `agent_models.py:24/:28` import Chat provider modules, which also run `Chat/__init__`.
- `project_instruction_runtime.py:40` imports `tool_catalog`. That module itself imports `Chat.console_library_policy` (`:37`) and `Library.library_tool_contract` (`:40`, whose package init loads `library_collections_service`, sqlite3 and `DB.Library_Collections_DB`). Its built-in providers (`:44-45`) reach `RAG_Search`, `config`, the DB and `UI.destination_recovery`.

TASK-36944.1 moves the provider types. The constant and the tool-catalog import chain are this task's to fix.

Source: architecture review 2026-10-25, `Docs/QA/architecture-review-2026-10-25/report.md` §F5; claim-by-claim verification in `Docs/QA/architecture-review-2026-10-25/verification.md` (origin/dev 7a5e2513c5).

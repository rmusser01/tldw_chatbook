## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
TASK-36942.2 froze the agent runtime's import footprint; this task empties it. Two chains load the UI, DB, HTTP and config layers. First, `agent_runtime.py:23` and `agent_models.py:24/:28` import Chat provider modules, which run `Chat/__init__` and load the DB. TASK-36944.1 moves those types out of Chat. Second, `project_instruction_runtime.py:40` imports `tool_catalog` at module level, and the built-in provider chain reaches `RAG_Search.ingestion_indexing`, `config`, the DB and `UI.destination_recovery` through `Library.library_local_rag_search_service`.

Source: architecture review 2026-10-25, `Docs/QA/architecture-review-2026-10-25/report.md` §F5; claim-by-claim verification in `Docs/QA/architecture-review-2026-10-25/verification.md` (origin/dev 7a5e2513c5).

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Someone who came to chatbook for their documents or notes has to get through Provider and Model first, or skip setup through a dead-end dialog and find Import alone [entry-exit-handoff-28]. Skipping also raises the "Check model lists online?" modal on the first navigation.

The approved spec adds a third Welcome choice, "Start with my documents or notes — set up AI later" (decision D8). It finishes setup at once through the single finish path (TASK-34100.10), opens Library Import with "Write a note" beside it, and records that AI setup was deferred, so the next "set up AI" opens Quick at Connect rather than a dashboard of empty rows. It takes over task-28019's documents-first ACs (#1 and #2); task-28019 keeps only its startup-modal AC. It needs the setup core and exit-route table (TASK-34100.20).

Spec: Docs/superpowers/specs/2026-10-03-first-run-setup-shape-design.md (revision 3, approved by the owner on 2026-10-03; ADR-217): D8, §3.1, §4.2 (deferred_ai), §4.3, §10 F7.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Normalize adapter-approved displayable reasoning and content-free proprietary evidence into explicit Console stream events, replace start-anchored think stripping with a safe two-channel splitter, and resolve optional thinking plus mandatory private continuation through one provider-specific history projection used by both serialization and token accounting.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 The provider gateway exposes bounded `ProviderThinkingDelta` and content-free `ProviderProprietaryThinkingEvidence` events beside visible strings and terminal tool calls; provider/model/protocol resolution is frozen for every event and raw values stay out of representations and logs.
- [ ] #2 Only provider adapters explicitly classify reasoning as displayable, proprietary evidence, or ignored; capability, request settings, empty visible content, timing, provider family, and generic field names never fabricate evidence.
- [ ] #3 A streaming start-anchored `<think>`/`<thinking>` splitter handles arbitrary chunk boundaries, leading whitespace, empty prefixes, mid-answer literals, non-streaming responses, and unclosed failure without leaking partial tags or relabeling partial thinking as complete.
- [ ] #4 Direct Console and agent-provider consumers accumulate ordered round-owned thinking, settle complete/stopped/failed state, preserve answer/tool ordering, and project only the selected generation through the foundation API.
- [ ] #5 Auto/Include/Exclude resolve against the fully prepared target; effective Required reflects ADR-063 continuation without overwriting the saved optional preference.
- [ ] #6 One owner-atomic history projection feeds exact provider serialization and token budgeting, prevents duplicate reasoning or continuation, never sends proprietary/failed/unknown blocks, and evicts a complete owner group rather than individual pieces.
- [ ] #7 Compatible adapters replay complete displayable blocks in their exact retained source encoding; Include fails before provider contact when an eligible block cannot be serialized safely, and no generic cross-provider assistant-text translation exists.
- [ ] #8 Focused splitter, provider disposition, no-evidence, event-order, stopped/failed, direct/agent, hosted/local, prepared-request identity, compatibility, overflow, and negative log tests pass.
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Replace start-anchored stripping with a bounded two-channel streaming splitter and retain the compatibility wrapper.
2. Add explicit provider thinking/proprietary events plus adapter-owned dispositions and persistence capability facts.
3. Accumulate round-owned evidence identically for direct and agent turns with terminal settlement.
4. Resolve optional replay and mandatory continuation into one owner-atomic prepared request used for counting and dispatch.
5. Run targeted provider/history suites and static checks, document the adapter disposition table, and complete only after serial review.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Normalize adapter-approved displayable reasoning and content-free proprietary evidence into explicit Console stream events, replace start-anchored think stripping with a safe two-channel splitter, and resolve optional thinking plus mandatory private continuation through one provider-specific history projection used by both serialization and token accounting.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 The provider gateway exposes bounded `ProviderThinkingDelta` and content-free `ProviderProprietaryThinkingEvidence` events beside visible strings and terminal tool calls; provider/model/protocol resolution is frozen for every event and raw values stay out of representations and logs.
- [x] #2 Only provider adapters explicitly classify reasoning as displayable, proprietary evidence, or ignored; capability, request settings, empty visible content, timing, provider family, and generic field names never fabricate evidence.
- [x] #3 A streaming start-anchored `<think>`/`<thinking>` splitter handles arbitrary chunk boundaries, leading whitespace, empty prefixes, mid-answer literals, non-streaming responses, and unclosed failure without leaking partial tags or relabeling partial thinking as complete.
- [x] #4 Direct Console and agent-provider consumers accumulate ordered round-owned thinking, settle complete/stopped/failed state, preserve answer/tool ordering, and project only the selected generation through the foundation API.
- [x] #5 Auto/Include/Exclude resolve against the fully prepared target; effective Required reflects ADR-063 continuation without overwriting the saved optional preference.
- [x] #6 One owner-atomic history projection feeds exact provider serialization and token budgeting, prevents duplicate reasoning or continuation, never sends proprietary/failed/unknown blocks, and evicts a complete owner group rather than individual pieces.
- [x] #7 Compatible adapters replay complete displayable blocks in their exact retained source encoding; Include fails before provider contact when an eligible block cannot be serialized safely, and no generic cross-provider assistant-text translation exists.
- [x] #8 Focused splitter, provider disposition, no-evidence, event-order, stopped/failed, direct/agent, hosted/local, prepared-request identity, compatibility, overflow, and negative log tests pass.
<!-- AC:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Implemented bounded start-anchored thinking splitting, explicit typed provider events,
round-owned direct/agent capture, generation-token fencing, and one owner-atomic replay
projection shared by token budgeting and dispatch. Compatible llama.cpp and vLLM
targets replay complete displayable blocks in their retained `<think>...</think>`
encoding; Moonshot/Kimi and Z.ai/GLM produce content-free proprietary evidence only
when an actual terminal reasoning field is present; generic/unknown dispositions are
ignored. Proprietary, stopped, failed, malformed, incompatible, and opaque copies are
never replayed.

Auto/Include/Exclude now resolve from the live conversation-owned session policy,
with ADR-063 Required applied only as an effective overlay. Continuation and thinking
share exact owner markers, trim atomically, serialize once into the frozen prepared
artifact, and are identical in direct and agent paths. Auxiliary summary, title,
citation-repair, and compaction calls discard typed thinking without persisting
evidence.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Found by TASK-34100.5.3.2 (review round 1, F8-9) and re-checked on origin/dev e8eeae7db9.

Backup and recovery look for Console run logs in the tool sandbox and in every folder bound to a workspace. The discovery in `tldw_chatbook/Agents/recovery.py` (`_RunLogs.discover`) asks the workspaces database for bindings whose kind is `local_filesystem`, with an underscore. Folder bindings are stored as `local-filesystem`, with a hyphen (`Workspaces.models.RuntimeBindingKind.LOCAL_FILESYSTEM`), so the query never matches. Run logs kept inside bound folders are therefore never discovered for a backup, unless the change-snapshot roots happen to cover the same folder. The user gets no sign of this.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Found in TASK-33620.8.3's review. `Tests/conftest.py` hands the shared bootstrap profile's config.toml back after every `bootstrap_profile` test (TASK-36478), but not `citation_records_choice.json`, which TASK-33620.8.3 keeps beside it. Today every test that writes the answer cleans it up in a fixture teardown or `finally`, which runs even when the test fails, and each pytest process makes its own bootstrap profile. A future test that writes an answer without that cleanup would leak it into later `bootstrap_profile` tests in the same process, where it silently changes whether citation records are on.

## Description

Found while verifying TASK-33621.59's review fix live (2026-11-06, real app, Anthropic haiku through the review proxy, isolated profile, a stdlib BEGIN EXCLUSIVE holder on the profile's ChaChaNotes database). After a first save failed and the card offered Retry send, Retry was pressed with the database still locked. The card read 'Working… actions are temporarily disabled.' and controller_submit was only entered about 16 s later (twice, 18:55:09 -> 18:55:25 and 18:56:26 -> 18:56:42), so something in the retry path waits on the database before the durable commit starts. A palette 'Console: Stop this tab's run' pressed inside that wait did nothing: the commit then ran, failed, and the card offered Retry send again ('Run: Blocked — send not saved'). A Stop pressed after the commit had started settled the send as stopped, as TASK-33621.59 intends. Evidence: F59 live round s05-s07 (ignored Stop) and s08-s10 (honoured Stop).

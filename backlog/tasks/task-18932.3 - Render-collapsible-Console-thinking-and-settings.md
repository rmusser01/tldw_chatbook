## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Render actual model thinking as lazy, collapsible disclosures inside the owning Console Assistant turn. Add the default-on device-local visibility setting and per-conversation history policy control, preserve live selection and scroll behavior, and rename safe synthetic model-step activity to Planning so it cannot be confused with actual reasoning.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 A displayable block streams expanded in place, then auto-collapses once at the first answer/tool boundary or terminal fallback; a manual mouse, Enter, Space, or `o` action cancels its pending automatic transition.
- [ ] #2 Actual proprietary evidence renders `Thinking · unavailable` and expands to exactly `Proprietary thinking obfuscated - not available`; absent evidence renders no block or notice, and late terminal-only evidence does not flash open after the collapse boundary.
- [ ] #3 Historical model-thinking disclosures restore collapsed, expand independently, expose complete detail through copy/Inspector, and lazily avoid mounting the full body while collapsed.
- [ ] #4 Presentation state maps trusted assistant/session ownership to internal block identities without using imported IDs as Textual DOM IDs; selection, navigation, pruning, regeneration, and variant switching retain correct owner relationships.
- [ ] #5 `Show model thinking` is a canonical F9 Console Behavior setting, persists device-locally, defaults On, applies immediately to live and mounted history, and changes neither capture nor replay; hiding a selected row clears only that selection.
- [ ] #6 Context/Memory offers Auto/Include/Exclude for the current conversation, shows effective read-only Required when applicable, and can save the optional value as the default for newly created conversations without rewriting existing conversations.
- [ ] #7 Model-thinking statuses render honestly as live/done/stopped/failed/unavailable at supported widths; bodies are wrapped, dim, literal, and terminal-safe, with no new global key binding or footer hint.
- [ ] #8 Existing privacy-safe intermediate model-step activity is labeled Planning only when no actual model-thinking block owns that round; the sanitizer remains conservative and no duplicate Planning row is produced.
- [ ] #9 Focused model, settings, disclosure, live-update, auto-collapse/manual-win, restored, no-evidence, proprietary, variant, selection/navigation, pruning/windowing, narrow-width, keyboard, and painted Textual tests pass with the generated CSS bundle in sync.
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Project generation blocks into trusted Assistant-turn activities with deterministic internal ownership IDs.
2. Reuse ConsoleActivityDisclosure and transcript expansion state for lazy live/historical thinking, one-time auto-collapse, manual override, keyboard, copy, Inspector, pruning, and in-place updates.
3. Add default-on device visibility in canonical F9 Settings and Auto/Include/Exclude conversation controls in Context & memory without coupling capture or replay to visibility.
4. Rename privacy-safe synthetic model-step rows to Planning and suppress them when actual thinking owns that round.
5. Regenerate CSS, run targeted model/settings/UI suites, perform one batched 60/80/100/140-column visual inspection plus at most one confirmation pass, run Impeccable detector/static checks, and complete only after serial independent review.

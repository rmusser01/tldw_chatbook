## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
After a decode failure, the controller may return the same graph's prior prepared frames. The mounted widget must not accept those pixels as a new render for the folded mode or a different viewport. Keep this widget repair separate from the final graph assignment race and collector retirement.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->

- [x] #3 The existing static frame, portrait, reduced motion, lifecycle and size controls pass; no dimension, preference, authority or security limit changes.

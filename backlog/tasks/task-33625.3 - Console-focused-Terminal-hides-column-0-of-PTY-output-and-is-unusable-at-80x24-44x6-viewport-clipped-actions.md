## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
**Impact.** A terminal that silently drops a column misreports command output, and the narrow layout is unusable for real shell work.

Unfocused, the prompt renders `➜  proj-alpha git:(main) ✗`. After clicking Focus, a 1-cell accent border appears and column 0 of the PTY is hidden:
- `git status --short` shows `M README.md` and `? untracked.txt` (really ` M` and `??`).
- The prompt loses its `➜`.

At 80x24 the Inspect rail stays open, so the terminal viewport is about 44x6. The tab label reads `Ter`, and the action row reads `Ren    Focu    Clos    Jum     Return to`.

**Severity / prior art.** P1 (the reviewer rated it P2; it was raised to P1 because the output is silently misreported). Triage: NEW, with no prior-art task. It was reported by one reviewer and carries no independent verifier verdicts, so reproduce it before fixing. The persistent terminal comes from TASK-22512 (Done). The Focus button and the action row are in `tldw_chatbook/Widgets/Console/console_terminal_workspace.py`.

**Suggested direction.**
- Reserve the focus border in both states, so focus changes only the border colour and never shifts content. An outline, or a constant border that only changes colour, both work.
- Compute PTY columns and rows from the visible content region, and resize the PTY whenever that region changes.
- When the Terminal owns the center at narrow widths (below about 100 columns), yield the rails.
- Give the actions compact labels or key hints that never clip mid-word.

The cross-region width-priority model belongs to the Theme 5 umbrella task.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
A focused Terminal shows every PTY cell, the PTY is sized to exactly the visible cells, and a narrow Console gives the Terminal the center with whole labels.

- The focus outline (drawn OVER the viewport's outermost cells, hiding column 0, the last column and the top/bottom rows while the PTY stayed sized to the whole widget) is replaced by the dense-form one-column left edge reserved in both states; focus changes only its weight, colour (`$ds-active-fg`) and fill. The viewport's content region is now the PTY size in both states. CSS through build_css.py; the focus edge passes `test_focus_edges_clear_non_text_contrast_on_every_theme`.

- Deviation, AC #6 added: a rail the user explicitly asks for while the Terminal is open (Alt+C, Alt+I, a handle -- any `_set_console_rail_preference` with a side) is exempt from the yield for that visit (`ConsoleTerminalController.reclaim_rails`), otherwise the toggles wrote a preference and showed nothing (the TASK-24604 "way back").

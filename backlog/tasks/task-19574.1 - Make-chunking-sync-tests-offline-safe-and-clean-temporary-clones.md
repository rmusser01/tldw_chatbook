## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Prevent the vendoring sync test from starting an unbounded network clone when its pinned local source is absent, and ensure manual temporary clones are removed on success or failure.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Sync tests skip before mutation when the configured pinned source clone is absent
- [x] #2 The test subprocess has a bounded timeout and cannot hang the suite indefinitely
- [x] #3 The sync helper removes its owned temporary clone on success and failure
- [x] #4 Existing local-source idempotence and local-edit rejection remain covered
- [x] #5 Focused Chunking tests and static checks pass
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Reproduce the absent-source fallback and five-minute watchdog hang without contacting the network.
2. Make the test require and validate a configured local pinned source before any sync or vendored-tree mutation, with a bounded subprocess timeout.
3. Wrap helper-owned temporary clone lifecycle in guaranteed cleanup on success and failure.
4. Preserve local-source idempotence and local-edit rejection coverage and verify no repository mutation remains after tests.
5. Complete independent review and task hygiene.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Made the sync contract test explicitly opt in through
`TLDW_SERVER_SYNC_SOURCE`, skip before spawning anything when that source is
missing, validate the source's exact pinned HEAD, and bound both validation and
sync subprocesses. Preserved the manual no-source clone workflow while moving
its clone, checkout, sync, and cleanup into one owned lifecycle whose `finally`
removes only the directory created by that call on success or failure.

Regression tests cover the absent-source no-subprocess contract, pin rejection,
the sync timeout, owned-clone cleanup on successful and exceptional syncs, and
preservation of caller-supplied source directories. The existing idempotence and
local-edit rejection test remains intact and opt-in; no safe pinned local source
was present for this run, so it skipped with the documented reason.

Verification: the offline module passed with 9 passed / 1 skipped; the related
Chunking suite passed 433 tests with 33 skips, 2 deliberate deselections, and 1
expected failure after excluding two unrelated environment/baseline failures
(`test-tokenizer` is absent from the offline HF cache and the existing
`tokens-cjk` golden differs). Ruff lint and full-file formatting, `py_compile`,
and `git diff --check` passed. No source, vendored, or ported-test files were
left modified.

Review follow-up made both `_sync_worktree` monkeypatches strict so removal or
renaming of the lifecycle seam fails the tests. A mutation that temporarily
renamed the seam produced the expected three `AttributeError` failures before
the implementation was restored. Ruff's full-file changes were inspected as
mechanical wrapping and quote normalization; pre/post formatting AST SHA-256
digests matched exactly for both Python files (`51371508...` for the tests and
`03ffee03...` for the helper).

### Compatibility and invariant review

- Pointer activation uses Textual's native click chain and the stable key
  captured at mouse-down. A single click only selects and may expand; there is
  no new timer and click release does not resolve a second screen coordinate.
  Load-more and Retry remain immediate actions. Truncation-only tooltips clear
  on local/outer reflow, and contextual F1 exposes the full selected label and
  implemented grammar.
- Global layout uses the collision-safe `shared-layout-v1` scope. Existing
  Default, named-workspace, legacy, and shared records remain independent;
  switching scope deletes none of them. The one-time seed copies an effective
  saved layout without persisting scroll, focus, search disclosure, Tree
  selection, or tooltip state. Responsive compact collapse remains render-only.
- The pinned heading plus five facts is exactly six rows above/outside the
  Inspector outer scroll owner. Summary and Inspector receive the same
  `ConsoleInspectorState` instance on initial composition and each sync.
  Actionable Tools/Approvals/Artifacts promote in fixed order; empty groups
  remain under More. Focus recovery remains inside Inspect unless a newer
  explicit valid focus already exists outside it.
- ADR-083 was reviewed against the final implementation and still owns these
  boundaries. Its 2026-08-24 amendment remains accurate; no second ADR is
  required.

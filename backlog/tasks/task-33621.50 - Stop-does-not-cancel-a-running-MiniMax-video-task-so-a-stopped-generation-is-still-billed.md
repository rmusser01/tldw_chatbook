## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Found in PR #3006's live check (2026-10-04, real MiniMax). Pressing Stop about 40 s into a /generate-video run logged 'MiniMax remote task cancel failed; local stop still honored (error_type=HTTPStatusError)'. The app stops locally, but the remote task is not cancelled, so the generation is probably billed in full. Docs/User_Guide/console/video.md says a queued MiniMax task 'is cancelled remotely and does not bill to completion'. The adapter's docstring says a task already running cannot be cancelled. Whether MiniMax offers any cancel for a queued or running task, and whether the request the adapter sends is right, is unverified.

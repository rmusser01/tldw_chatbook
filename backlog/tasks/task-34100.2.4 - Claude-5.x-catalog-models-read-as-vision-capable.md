## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
TASK-34100.2 (AC#17) replaced the retired Anthropic catalog ids (the claude-3.x and claude-*-4-2025 ids, which `model_capabilities.is_vision_capable` reads True) with current ids. Three of the replacements, `claude-sonnet-5-5`, `claude-opus-5-5` and `claude-fable-5-1`, read False, because `MODEL_CAPABILITY_PATTERNS['Anthropic']` only matches `claude-3`, `opus-4` and `sonnet-4`. `claude-sonnet-5-5` is also the setup wizard's '(recommended)' Anthropic model. The gap predates TASK-34100.2 (`claude-opus-5` and `claude-fable-5` already read False), but the catalog swap widened it, so an image attached in Console to the default Anthropic models is treated as unsupported (TASK-34100.2 review round 2, R3-8; isolated probe: False for claude-sonnet-5-5, claude-opus-5-5, claude-fable-5-1; True for claude-opus-4-8, claude-sonnet-4-6, claude-sonnet-5).

Check Anthropic's model documentation for which 5.x models accept images before adding a pattern, and keep context-window resolution unchanged (a pattern row that adds a `context_window` changes the capacity verdict TASK-34100.2 AC#1 pins).

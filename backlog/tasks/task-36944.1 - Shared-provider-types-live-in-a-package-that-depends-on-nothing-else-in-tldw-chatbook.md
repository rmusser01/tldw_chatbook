## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Agents and LLM_Calls import provider-level types and helpers from Chat (provider exceptions in `Chat_Deps`, `provider_continuation`, `sampling_params`, `thinking_blocks` and similar leaf modules); `ChatProviderError` alone is imported by 12 LLM_Calls files. Each such import runs `Chat/__init__`, which loads ChaChaNotes_DB. A neutral package removes most of both mutual dependencies.

Source: architecture review 2026-10-25, `Docs/QA/architecture-review-2026-10-25/report.md` §F7; claim-by-claim verification in `Docs/QA/architecture-review-2026-10-25/verification.md` (origin/dev 7a5e2513c5).
<!-- SECTION:DESCRIPTION:END -->

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The agent note tools read `config.chachanotes_db` at call time, and the document expansion tool calls `get_chachanotes_db_lazy()`. Both work in the TUI only because app start-up filled the global first; in a fresh process the note tools fail with 'No unified database template for NotesInteropService' (reproduced). Their tests replace the service with a fake, so the real path is never exercised.

Source: architecture review 2026-10-25, `Docs/QA/architecture-review-2026-10-25/report.md` §F9; claim-by-claim verification in `Docs/QA/architecture-review-2026-10-25/verification.md` (origin/dev 7a5e2513c5).

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Implemented the modal full-player screen with audio and sync (ADR-044 decision 4). Media_Playback/player_pipeline.py: AC6 single-demux -- ONE ffmpeg process (-ss offset, -re native-rate pacing, CFR fps=N video to stdout, s16le PCM to an inherited fd) plus ffplay -nodisp -autoexit reading the audio pipe end-to-end (the source is fetched exactly once; the parent brokers the fds, audio never round-trips); CFR video makes pts = index/fps exact; sync clock is pause-adjusted wall time with ffplay buffer-lag correction (documented upgrade path: -progress fd telemetry for streaming stalls, task-3401.11); render-when-due / drop-forward past 80ms with drift/dropped SyncStats; seek = generation-bumped restart so the frame pump re-enters safely (no false EOF); pause/resume via SIGSTOP/SIGCONT with paused-time folded out of the clock; idempotent stop. Media_Playback/render_mode.py: kitty -> sixel -> halfcell -> ascii conservative env detection (plain xterm deliberately NOT sixel) plus a TermTube-style ASCII ramp. UI/Screens/video_player_screen.py: ModalScreen with decision-031 bindings (space pause/resume, s stop, left/right seek +-5s clamped to duration, q close -- hints line names only implemented actions), status line at 4Hz (state, position/duration, drift +ms/max, dropped, render mode), bounded early-wait frame pump, kitty via TGP renderable updates / sixel via textual_image.widget.sixel with in-place image swaps / halfcell rich_pixels / ascii ramp; pauses any playing transcript preview on mount (one-active rule); missing ffmpeg/ffplay dismisses with guidance (AC5). Video card Play action now pushes the player screen when tools exist, else OS-player fallback + one guidance notice. CSS classes added and the bundle regenerated.

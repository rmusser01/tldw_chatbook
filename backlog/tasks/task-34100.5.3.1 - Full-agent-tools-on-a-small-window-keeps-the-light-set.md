## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
TASK-34100.5.3 gives ordinary Console chat the light set and an opt-in Full agent tools switch. Full mode can still offer fewer direct tools than light mode on a small window. Current ADR-253 behavior tries ordinary direct/discovery, then compact find_tools/load_tools with already-gated progress, then plain chat if compact discovery cannot fit. Compact discovery retains eventual catalog reachability; it is incorrect to claim every 8k full-mode request loses all tools. The 2026-10-19 tool-less gpt-4 and 2026-10-27 inbox-only llama.cpp observations are historical, pre-ADR-253 evidence, not the current guaranteed shape. A runtime-free direct light tier remains deferred: it needs matching prompt, runtime closures, live-work policy and preview accounting, not just a fallback schema list. PR3295 review scope explicitly preserves this follow-up as To Do; enabling full mode may select discovery or plain chat where direct light tools would fit.

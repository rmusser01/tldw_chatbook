## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Define how a user can inspect exact local evidence without turning memory metadata into authority to read another conversation. This task delivers a reviewed architectural contract, not a source resolver or Profile V2 rollout.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 The written contract separates foreground profile inspection from conversation access and defines trusted host issuance, current source ownership, namespace matching and imported-data rejection.
- [x] #2 The contract specifies coherent current-message/version reads, exact representation and Unicode span verification, bounded work and honest unavailable behavior without historical fallback.
- [x] #3 Legacy references, role labels, capture times and matching hashes cannot grant access, establish authorship or imply semantic support, approval or current truth.
- [x] #4 The contract defines request, profile, source-policy and publication fencing, visible-result invalidation and explicit cross-process freshness limits.
- [x] #5 Quotes remain disposable local UI data with bounded plain-text rendering; retained excerpts, tools, providers, export, sync and background inspection are outside this release.
- [x] #6 A concrete positive, negative and race test matrix plus implementation entry gates identify the missing V2 and source-owner integration without claiming deployed inspection.
- [x] #7 Alternatives, scoped native document checks and technical self-review are recorded, a proposed ADR is linked, and user acceptance of the new source-access boundary is recorded before implementation planning.
<!-- AC:END -->

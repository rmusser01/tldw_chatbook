## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Define a bounded maintenance workflow that turns eligible new conversation evidence into reviewable memory changes through existing owners.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 The design uses Personal Context proposals and existing Notes or Agent Lessons boundaries without adding a fourth authoritative memory store.
- [x] #2 Only eligible new source revisions trigger work; checkpoints, retry idempotency, lock/unlock behavior, cancellation and missed-run handling are specified.
- [x] #3 The workflow may propose durable facts, corrections, duplicate merges and archival but cannot approve its own changes, rewrite user goals or bypass existing grants.
- [x] #4 Provider disclosure, source suppression, concurrent deletion and exact-evidence requirements are applied before and after any model call.
- [x] #5 Opt-in controls, per-run and daily cost budgets, batch review and quiet no-change behavior are defined; repeated summaries do not count as independent evidence.
- [x] #6 A synthetic evaluation and first-release acceptance plan compare supported useful proposals, duplicate rate, rejection rate, cost and forbidden disclosure; implementation is outside this design task.
- [x] #7 The release gate requires shipped and verified evidence, forgetting/suppression, disclosure and recovery controls; completed design documents alone do not authorize or unblock enabling consolidation.
<!-- AC:END -->

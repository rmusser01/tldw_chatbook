## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
**Impact.** Setup: a named workspace with a bound git folder. The Inspect pin 'Choose folder · Project' opens the Conversation Inspector. Pressing its 'Choose folder' button hard-locks the app, reproduced 3 of 3 times.

Mechanism:
- `_recover_project_instructions` is a plain @on message handler, not a worker, and it awaits `app.push_screen_wait(ProjectInstructionSetupModal(...))` at `session.py:5420`.
- Textual pushes the modal and then raises `NoActiveWorker`.
- The TASK-32533 keep-alive swallows the error and shows 'Something went wrong in _select_project_instruction_binding'. The Inspector's message loop is dead, but the Inspector stays on the screen stack.
- The first Esc, Cancel or folder click closes the picker, but the result goes to a future nobody awaits. The folder is never applied: the pin still reads 'Choose folder · Project' after a restart.
- From then on every key, click and resize goes to the dead, detached Inspector. Ctrl+Q cannot reach the App either, because the binding chain is built from a detached widget.
- The process idles until it is killed with SIGTERM.

This is the only in-Console control for giving file tools a bound folder.

**Severity / prior art.** P0, KNOWN_PARTIAL:
- TASK-32533 (Done) introduced the keep-alive.
- TASK-32569 (To Do) makes a kept-alive dead pump visible, but does not cover a dead screen left on the stack.
- TASK-1230 (Done) fixed an earlier soft-lock from a navigation guard.
- TASK-32800.4 (Done) added `scripts/check_textual_worker_contract.py`, which does not catch `push_screen_wait` outside a worker.
- TASK-32828 (In Progress) is redesigning the Inspector.

**Suggested direction.**
1. Run the binding selection in a worker, or use the push-with-callback pattern already used nearby in `session.py`.
2. Make the keep-alive in `app_lifecycle.py` never leave a dead screen on the stack. Either fall through to a loud exit, or remove the dead screen and any screens above it and refocus a live screen. Popping only the modal, or making Ctrl+Q a priority binding, is not enough.
3. Add a worker-contract rule for `push_screen_wait` reachable from a non-worker coroutine.

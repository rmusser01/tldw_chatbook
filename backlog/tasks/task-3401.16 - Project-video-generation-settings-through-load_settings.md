## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Ensure persisted [video_generation] configuration reaches the runtime loader so enabled backends and defaults selected in Settings are honored by Console generation.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 A persisted [video_generation] table is present in load_settings() output without dropping global or backend-specific values.
- [ ] #2 The video-generation config loader honors persisted default_backend, enabled_backends, and ComfyUI connection/workflow settings after cache reset.
- [ ] #3 The real Console generation path no longer reports a configured and enabled ComfyUI backend as disabled.
- [ ] #4 Focused regression tests fail when the projection is absent and pass when both initial load and reload paths preserve the table.
- [ ] #5 Malformed top-level or nested video-generation TOML values fall back safely instead of crashing runtime configuration.
<!-- AC:END -->

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Fix the inline generated-video preview so explicitly activating a ready MP4 preview cannot terminate the Textual app. Live UAT observed an unhandled AttributeError immediately after preview activation; the persistent scratch log recorded the app-level exception and shutdown.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Activating a ready generated-video preview never raises an unhandled exception.
- [ ] #2 The preview either plays or renders actionable degraded guidance when playback support is unavailable.
- [ ] #3 Pause, resume, and end-of-file transitions keep Console responsive.
- [ ] #4 A regression test reproduces the UAT activation path and fails if an app-level exception escapes.
- [ ] #5 Failure logging includes actionable component context without paths, prompts, or media content.
- [ ] #6 Opening the modal full player uses the same valid UI-thread bridge and cannot silently drop decoded frames.
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Move inline source open/probe/decode and modal probe/pipeline startup off the UI thread, then publish state only through the owning Textual app thread bridge.
2. Propagate real frame-source decode failures, contain source/timer cleanup, gate inline and modal callbacks by source/pipeline generation, and keep modal decode/timing/stat state in per-generation run objects so stale workers cannot read or mutate resumed, sought, or unmounted playback.
3. Make PlayerPipeline startup and run teardown transactional: close parent pipe descriptors exactly once on every branch, stop already-started children on failure, and wait after forced kill.
4. Add focused RED/GREEN coverage for real click/mount responsiveness, pause/resume/EOF races, stale queued callbacks, sanitized decode/render/cleanup logs, modal frame/EOF dispatch, real first/second spawn cleanup, and mid-pump failure containment.
5. Mutation-check each load-bearing bridge/ownership/cleanup guard, then run only affected playback test and static-analysis scopes.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Why: F6 / Shift+F6 is the app-wide way to move between Library panes. TASK-34000.28 (polish-1 task 2, fix round 1) made the two note-body editors give F6 back to the app (Widgets/text_area_pane_key.py, release_pane_key), but Textual's TextArea binds f6 to select-line, so in the Skills editor, the Prompts editor and the Media analysis text box F6 still selects the current line and focus never leaves the box. A keyboard user inside one of those boxes has no single-key way out to the next pane. Found by the polish-1 task 2 implementer and confirmed by its scoped re-review (2026-10-25); out of TASK-34000.28 AC#9, which covers only the note body.

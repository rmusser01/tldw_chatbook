## Implementation Notes

Both ratchets are at zero again. Phase 9, plan Task 10; base 10fead87cb.

**Dimension literals (AC#1).** `test_dimension_literal_ratchet` found 18 at the base, not the 14 filed: components/_agentic_terminal.tcss 1, components/_settings_splash_theme.tcss 2, features/_wizards.tcss 4 (new since filing) and features/_workflows.tcss 11. All 18 are tokens now.

- Recurring values use the shared tokens that already existed: `1fr` is `$ds-width-fill` or `$ds-height-fill`, `6` and `8` are `$ds-size-6` and `$ds-size-8`, `45%` and `90%` are `$ds-percent-45` and `$ds-percent-90`.
- `$ds-size-100` is new on the size scale, a round rung of the cap ladder beside 96, 104, 110 and 120. The workflow run dialog's `max-width` uses it.
- `$ds-wizards-voice-long-share` (21fr), `$ds-wizards-voice-mid-share` (14fr) and `$ds-wizards-voice-short-share` (11fr) are new feature tokens for the first-run voice radio. ADR-161 gives feature geometry a `$ds-<feature>-*` name, as the Watchlists region shares have.
- The `grid-columns: 21fr 14fr 11fr` line of the stacked radio is not a ratchet offender (the ratchet reads padding, margin, width and height) and is unchanged.

**Geometry unchanged (AC#1).** Checked by text, not by eye: with every `$ds-*` token replaced by its value from `_variables.tcss`, each of the four sheets is byte-identical to its version at the base. Four tokens were added, none removed and none changed in value.

**Python writes (AC#2).** `test_python_style_ratchet` flagged two files, not one.

- Widgets/Library/library_skill_work_pane.py: the Enabled label takes the `w-auto` utility class in place of `label.styles.width = "auto"`. `Tests/UI/test_library_skills_builtin_rows.py::test_preview_enabled_label_hugs_its_text_under_the_app_stylesheet` mounts the pane under the application stylesheet at 211x44. Without the class the label is 209 cells wide instead of 9, and the test fails on it.
- Widgets/Console/console_composer_bar.py (`_swap_size_class`, from 9a48cf3b06, TASK-33628.5.2): `widget.set_styles(**{name: None})` is now `setattr(widget.styles, name, None)`. Both clear one inline style; Textual 8.2.8's `set_styles` calls `setattr` once per keyword. The inventory could not read the `**` form and counted it as an unmarked write. It reads the new form as a reset, which the ratchet allows.

**Bundle and preflight (AC#3).** The bundle and the split sheets were rebuilt with `tldw_chatbook/css/build_css.py`; `check_bundle_sync.py` reports every generated sheet reproducing. `PYTHON=<venv> ./scripts/preflight.sh` returns 0 at the head of plan Task 10.

This rider alone adds 278 B (607,798 to 608,076), which is 14 B under the limit. The first draft of plan Task 10 went 222 B over it. TASK-33641.3 then moved a rule out of the boot bundle (113 B less), and TASK-33641.2 adds 31 B. Plan Task 10 as a whole adds 196 B and leaves 96 B.

## Implementation Notes (partial -- AC#2 deferred)

Landed on PR #2739 (`fix/core-review-loop`):

- **AC#1 (keypress not blocking)** — `all_tool_gates()` and
  `_off_tool_gate_status()` (which back `tool_gate_breadcrumb()`, the ~56 ms
  Space-press cost, and the Servers-detail `all_tool_gates` ~55 ms repaint)
  read ~11 gate keys, each a full storage-admission pass. Added
  `_gate_config_snapshot()` (one `load_cli_config_and_ensure_existence()`),
  and both enumerators now read `[tools]`/`[console]` from that one dict with
  the same `coerce_bool_setting` guard -- one admission pass instead of eleven.
  Gate states are unchanged (flat section reads == `get_cli_setting`; env is
  folded in at load). Tests migrated from patching per-key `get_cli_setting`
  to patching the single loader;
  `test_tool_gate_breadcrumb_loads_config_once_not_per_gate` pins the one-load
  contract, and the drift pin now runs gate-free.
- **AC#3 (write offloaded)** — the Permissions matrix wrote the store
  synchronously (~13 ms/keypress). Added `_call_profile_scoped_off_loop`
  (awaits the sync `_call_profile_scoped` via `asyncio.to_thread`) and routed
  the five state-cycle setters, the inspector re-allow, and `set_kill_switch`
  through it, mirroring the file's own `_save_builtin_flag` offload. Resync-
  after ordering and write end-state are unchanged.

**AC#2 (snapshot reads config once per pass) -- DEFERRED.**
`_collect_snapshots()`'s four `[mcp]` flag reads can be hoisted to one config
load exactly like AC#1, and the change was written and locally sound. But many
`Tests/UI/test_mcp_workbench.py` tests set up an in-memory `[mcp]` `flags` dict
by patching `mcp_workbench.get_cli_setting` and depend on `_collect_snapshots`
reading through that seam (the reload-reflects-write assertions). The hoist
bypasses that seam, so those tests must be migrated to patch
`load_cli_config_and_ensure_existence` instead. `Tests/UI` trips the ADR-126
storage gate in this worktree, so that migration cannot be verified locally;
it was reverted rather than shipped blind. AC#4's `_collect_snapshots` probe
is deferred with it. AC#1's per-keypress cost is pinned gate-free.

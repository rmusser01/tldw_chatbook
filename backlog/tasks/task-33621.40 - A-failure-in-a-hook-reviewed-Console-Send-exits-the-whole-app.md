## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
From the PR #2945 (TASK-33621.28) checkpoint review. The hook-review continuation runs through screen.run_worker(..., group='console-hook-send-review') with Textual's default exit_on_error=True. TldwCli._handle_exception sets 'underlying' for any WorkerFailed, so it never keeps one alive. Any exception in a hook-reviewed Send therefore exits the app. That includes RuntimeError from _permissions() after runtime disposal, which refresh() explicitly guards and _continue does not. A scratch probe recorded WorkerFailed and return_code=1. This is not a regression against dev, where a Console Send handler error also takes the exit, but a typo-level failure should never cost the user the app.

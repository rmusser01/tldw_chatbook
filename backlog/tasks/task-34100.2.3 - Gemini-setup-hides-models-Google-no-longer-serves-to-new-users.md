## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
TASK-34100.2 lists Gemini's chat models in setup from Google's own models.list (generateContent models, no TTS, image, embedding or preview ids). That list still includes `gemini-2.5-flash` and `gemini-2.5-pro`, and the setup Model step shows them in its top five rows. For a new key, `generateContent` answers 404 'This model models/gemini-2.5-flash is no longer available to new users. Please update your code to use models/gemini-3.8-flash' (TASK-34100.2 review round 1, live F7; evidence `.worktrees/setup-wizard-ux-qa/evidence/g2b-v-gemkey/04`). A user who picks one gets a failed first message. A listing cannot tell, so the fix is an ordering or filtering rule.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Several write paths discard their failure with no log line at all: the Console store's terminal-settlement write, a home-server profile link, the Prompt save path's only optimistic-concurrency check (a swallowed read error turns a conflicting save into a last-writer-wins overwrite), the lasting-sync abandon path, and a terminal file in the Console modules with nine swallowing handlers and no logger import anywhere. A swallowed write failure is indistinguishable from success to both the user and the log.

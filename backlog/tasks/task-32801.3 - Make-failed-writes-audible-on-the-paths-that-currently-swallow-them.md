## Description

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Six swallowed failures now log, across three files.

console_chat_store._settle_dispatch_recovery (:3812): the terminal-settlement write. Rollback and the caller's retry queue were already correct; the failure simply left no trace, so a turn that never settles looked identical to one that settled. Logs session_id, assistant_message_id, terminal_state.

library_prompts_controller (:3230): the staleness pre-read is the ONLY conflict check the Prompt save path has (the write seam cannot detect staleness itself). Swallowing it turned 'could not tell' into 'no conflict' -- a transient read failure silently downgraded a conflicting save to last-writer-wins. Logs prompt_id.

UI/Console_Modules/terminal.py: the file had ZERO logger references. Four runtime operations (detach_view, focus_session, retry_cleanup, send_key) reported failure only as a False return. Added a logger and a per-operation warning.

LOG-CONTENT REVIEW (what the diagnostic inventory exists to force): the settlement and prompt lines interpolate identifiers only, never content. The terminal lines interpolate exception type + message but NOT a traceback -- the repo's file sink runs with diagnose=True, so a traceback would dump frame locals. I checked whether those messages can carry a path: the Terminal package raises deliberately path-free errors ('invalid cwd', 'terminal PATH has no existing absolute directory', 'unknown terminal event kind'), so nothing sensitive reaches the sink.

MISTAKE CAUGHT IN PROGRESS: my first version wrote logger.warning(..., exc_info=True) -- a stdlib-logging idiom. Loguru formats via .format(**kwargs) and would have silently ignored it, logging no exception detail at all and recreating the exact silence I was fixing. Verified the corrected shape renders: 'Terminal detach_view failed (ValueError): runtime is gone'.

NOT covered by this task (named in the finding, still open): the lasting-sync abandon path's except: pass. It sits in library_file_notes_workspace and wants its own look rather than a blind log line.

Tests: Tests/Chat/test_console_chat_store.py 1 failed / 419 passed before and after (same pre-existing test); test_library_prompts_canvas.py at its known 202 baseline. Preflight green after regenerating the inventory pin with every added statement read. ruff clean.

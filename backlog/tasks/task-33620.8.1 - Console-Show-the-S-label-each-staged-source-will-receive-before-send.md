## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Split from TASK-33620.8 (its original AC#4) when the owner chose persisted citations on 2026-10-27. The persisted Cited sources window now maps a reply's [Sn] labels to documents after the reply. Before a send, staged chips and the Inspector's source rows still show titles without S-ordinals, so a user can't predict which label a source will get.

The ordinal is assigned at the prompt boundary, after fresh source authorization. That step can drop a source the user staged (deleted, out of scope, remote). A label shown before send therefore has to say it is provisional, or be computed by the same authorization.
<!-- SECTION:DESCRIPTION:END -->

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
TASK-33621.21 made the default path (warm the model before capture) bounded and plain: one message, a next step, raw errors in the log only. The opt-out, dictation.warm_model_before_capture = false, skips the warm-up, so the model download and load happen inside the service's start_dictation() with no stall bound, and their failures reach the toast through the controller's _fail(str(exc)) and the service on_error path. Errno values and cache paths can still appear there, and a wedged load can still sit on 'Preparing'.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 With dictation.warm_model_before_capture = false and no model cached, a failed or stalled model load ends within a bounded time with one plain message and a next step
- [ ] #2 No toast on that path shows errno values or file paths; the raw error is in the log
- [ ] #3 A start failure that is not a model load (for example a microphone device error) still shows an actionable message

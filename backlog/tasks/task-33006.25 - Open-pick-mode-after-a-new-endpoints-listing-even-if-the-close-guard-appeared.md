## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Found in the TASK-33006 final re-review (2026-10-03). After **New endpoint…** saves an entry, Chat settings lists the new entry's served models for up to 2.5 s, and then opens Switch model in pick mode. If the unsaved-changes close guard opens during that listing, pick mode does not open, and nothing says so. The entry is saved, but the chat stays on its old provider·model pair.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 When the close guard is showing as a new endpoint's listing finishes, the user gets a clear outcome: pick mode opens once the guard is dismissed, or a notice says the new entry was saved and how to pick it (Change, Alt+M). A test pins whichever is chosen.
<!-- AC:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Chose the notice. `_open_model_picker` (`Widgets/Console/console_settings_field_row.py`) now returns whether pick mode opened. When a created entry's listing ends and pick mode cannot open (the close guard is showing, or a default recovery holds the modal), `_list_then_pick` posts `CREATED_ENTRY_PICK_LATER_COPY`: "<name> is saved. Pick its model with Change (Alt+M)." It passes `markup=False`, because the name is user text (TASK-1513; `scripts/check_markup_interpolation.py` OK). The listing is still kept (TASK-33006.19), so after Keep editing, Change offers what the entry serves. After Discard, the Console's own Alt+M lists the saved entry too.

Deferring pick mode until the guard is dismissed was not chosen. Discard closes the modal, so that path would still need the notice, and it would add guard-dismiss wiring to `console_settings_modal.py`, which has no headroom.

Test (red at the base behaviour, green after): `Tests/UI/test_console_endpoint_discovery.py::test_a_created_entry_listed_under_the_close_guard_says_how_to_pick_it`. It edits Temperature, starts a created entry's listing held on an event, and presses Esc (the unsaved-changes guard shows). When it releases the listing, the modal stays current with the guard up and exactly the one notice. Esc (Keep editing) then Change offers `("custom-ep:gpu-box", "served-x")`. Before the fix (copy constant present, no notice), it failed with `assert [] == ['GPU box is saved. Pick its model with Change (Alt+M).']`.

The node joins the UI PR census (MINIMUM_FILES 334), 3 of 3 serial runs alone (about 5 s each). Docs: console.md's New endpoint… paragraph describes the notice.

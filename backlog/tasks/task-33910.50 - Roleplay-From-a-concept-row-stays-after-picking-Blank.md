## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
- **Present on dev 29592ecc9b; this PR fixes it.** `load_character` never closed the concept row or emptied its input, and `new_character` calls it. So a row opened by New › From a concept, or by the editor's "Generate whole character…", stayed open with its text on a Blank draft, a From a portrait draft and an Edit. Only mount, the row's own Cancel and a finished generation closed it.
- **Fix.** Right after the form is populated, `load_character` hides the row and empties its input (three lines). From a concept still re-opens the row, because `_begin_create_character_from_concept` shows it with `call_after_refresh`, which runs after `new_character`. The concept input is outside dirty tracking, so emptying it marks nothing unsaved.
- **Pre-import re-pin (owner decision 2026-11-05, "Re-pin per PR (Rec.)").** The editor is pre-imported, and dev pins `MAX_PASS_ADDED_LOC` at its measurement with zero headroom (426,539/426,539 on e8eeae7db9, after TASK-36516). These three lines make the pass 426,542, +3 with the module set unchanged. The fix cannot move off the pre-import path: `personas_screen.py` is pre-imported too, and a lazily imported helper would still add lines to the editor. A follow-up commit pins `MAX_PASS_ADDED_LOC` at 426,542 (LOC only) with a dated owner-decision comment and refreshes the snapshot with `scripts/update_boot_budget_snapshots.py --only preimport`. It also adds the ADR-097 ledger row.
- **Tests:**
  - `Tests/UI/test_roleplay_item_list_app.py::test_blank_after_from_a_concept_closes_the_concept_row`: the New chooser path (From a concept with text typed, then Blank, then From a concept again).
  - `Tests/UI/test_personas_generation_wiring.py::test_blank_after_generate_whole_character_closes_the_concept_row`: dev's own path.
  - `Tests/UI/test_personas_character_generation_ui.py::test_a_new_editor_session_closes_and_empties_the_concept_row[new|portrait|load]`: the editor contract.
- **Observation, not fixed here.** At 120x36 the concept row's input is about 19 cells wide, and Draft and Cancel sit on a line of their own. This exists on dev and is visible in the owner's captures.
- **Files:** `tldw_chatbook/Widgets/Persona_Widgets/personas_character_editor_widget.py` (no ratchet row), the three test files above, and `Docs/User_Guide/roleplay-chat-dictionaries/characters-and-personas.md` (the concept row's lifetime).

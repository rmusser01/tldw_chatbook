## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
- **Port of PR #3431** (another contributor's branch, about 2000 commits behind): 958bfcd17f cherry-picked with `-x` onto dev 8a55555798. Its re-pin commit f10248d8fc was not taken (see the boot budget below). The bug was still on dev: `load_character`, which `new_character` calls, never closed the concept row or emptied its input, so a row opened by New › From a concept or by "Generate whole character…" stayed open, with its text, on a Blank draft, a From a portrait draft and an Edit.
- **Fix (unchanged from the PR).** Right after the form is populated, `load_character` hides the row and empties its input. From a concept still re-opens it, because `_begin_create_character_from_concept` shows it with `call_after_refresh` after `new_character`. The concept input is outside dirty tracking, so emptying it marks nothing unsaved.
- **Red/green.** With the three lines reverted, all 5 new cases go red on `row.display` (True); with the port they are green. When only the line that empties the input is removed (the row is still hidden), all 5 go red on `concept.value == ""`, so each half is pinned on its own.
- **Boot budget: no re-pin.** Paired arms of `test_preimport_pass_payload_stays_within_budget`: dev 8a55555798 is 423,440 LOC and 558 modules (`ccp` 59,987); the branch is 423,443 (`ccp` 59,990). That is +3 LOC with no new module. Dev's ceiling is 427,830, so the branch keeps 4,387 headroom and the test passes. Every ADR-097 ledger raise answers a breach, so the PR's 426,575 -> 426,578 re-pin, its snapshot refresh and its ledger row are dropped. Nothing was raised.
- **Regression check.** The editor suites that call `new_character`/`load_character` (actor pack, save in place, avatar, deferred centre views) had 36 local failures on the branch, with the same first error at dev's source for each: 10 `RecoveryRequired: raw_source_selection_changed`, 15 timeouts waiting for the choice modal, and 11 at other steps. Under the bootstrap-profile probe plugin (lessons-testing-evidence), 31 of the 36 pass on both trees, and the same 5 fail on both with the same messages. None of those 5 is about the concept row.

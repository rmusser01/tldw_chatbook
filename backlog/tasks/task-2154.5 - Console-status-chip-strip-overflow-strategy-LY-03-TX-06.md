2. TX-06: `CONSOLE_SYSTEM_PROMPT_LABEL_UNSET = "System Prompt"` -> `"System Prompt: off"` in console_display_state.py (name:value grammar; ": set" unchanged). Sweep tests for the bare-label expectation.
3. Tests: new Tests/UI/test_console_chip_strip_overflow.py — (a) at 160/140/110 with rail open, content overflows viewport (max_scroll_x > 0) and no chip renders outside the virtual content width; (b) focusing each chip (incl. cost chip at 160 — AC "never clips") scrolls it fully inside the strip's content region; (c) System Prompt chip reads "System Prompt: off" when unset, ": set" when set.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Implemented the scroll strategy (LY-03) plus the System Prompt chip grammar fix (TX-06).

- Approach: `ConsoleStatusChips` now extends `HorizontalScroll` (was `Horizontal`), giving the strip `overflow-x: auto` for free; CSS hides the horizontal scrollbar (`scrollbar-size-horizontal: 0`) since the strip is one row — same pattern as `#console-native-tab-strip` (TASK-2154.4 precedent). Keyboard reachability comes from `Screen.set_focus(scroll_visible=True)` auto-scrolling each focused chip into view; mouse/trackpad via Shift+wheel / horizontal swipe (Textual 8.2.8). Priority hiding was rejected: with the rail open the strip is only ~130 cells at 160 cols, so hiding would permanently drop nearly half the chips.
- TX-06: `CONSOLE_SYSTEM_PROMPT_LABEL_UNSET` changed `"System Prompt"` -> `"System Prompt: off"` in `console_display_state.py` (set state keeps `"System Prompt: set"`).
- Features modified: chip strip container + `_agentic_terminal.tcss` (bundle regenerated via `./build_css.sh`), display-state label constant.
- Tests: new `Tests/UI/test_console_chip_strip_overflow.py` (7 tests, all pass) — scroll range at 110/140, focus auto-scroll reachability of every chip incl. the cost chip at 160, no phantom scroll when content fits, label grammar. Neighbor suites: 84 passed, 0 failed (status_chips, status_chips_cost, system_prompt×2, shell_chip_actions, tab_scope, resize_reflow, narrow_layout, workbench_visual_snapshots).
- UAT: `uat_console.py p1_ready p4_narrow` re-run ok; captures show the new `System Prompt: off` label and chips clipped-but-scrollable at the right edge instead of jammed mid-glyph.
- Trade-offs: chips beyond the fold are not visible until scrolled (accepted contract for narrow widths); no overflow marker added since the clipped chip edge itself signals more content.

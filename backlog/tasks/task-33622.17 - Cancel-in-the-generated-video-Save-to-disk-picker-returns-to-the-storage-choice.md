## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Owner decision 2026-10-03. TASK-33622.15 documented that Escape or Cancel in the generated video's Save-to-disk picker discards the video without asking. The owner ruled that Cancel should return to the storage choice instead, so a generated (often paid) video is never lost to a dismissed file picker.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Cancel or Escape in the Save-to-disk picker returns to the storage choice with the generated video still available
- [ ] #2 The video is discarded only by an explicit discard choice
- [ ] #3 Ctrl+Q while the picker or its Replace / Destination-changed confirmations are open still asks before discarding the video
- [ ] #4 The User Guide's video page describes the new Cancel behaviour
- [ ] #5 Tests pin the return-to-choice path and fail on the previous behaviour

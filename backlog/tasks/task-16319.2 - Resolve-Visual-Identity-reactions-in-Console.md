## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Use bound Visual Identity packs in the Console avatar path and let users choose or clear a session-local reaction without introducing automatic emotion classification or durable message replay.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 The structured resolver applies manual, operational, pack-default, neutral, legacy-expression, card-portrait, and placeholder fallbacks in the documented order.
- [x] #2 Console exposes a keyboard-operable filterable reaction selector with one lazy preview and clear manual-override state scoped to the active session and character.
- [x] #3 Avatar refresh and decode caches include resolved pack-version and asset identity, so manual changes, pack changes, actor changes, and post-await races cannot display stale reactions.
- [x] #4 Idle, thinking, speaking, and error automation plus legacy characters retain their existing behavior, and missing or corrupt pack assets fall through safely.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
After the media bodies have moved, the controller still holds LibraryScreen itself: it reaches six screen attributes directly and types its DOM handle as the screen, so it cannot be built or reasoned about without one. Narrowing that handle to the framework and shell services it actually uses finishes the parent's no-screen-reference outcome, and the parent's timing criterion needs one measurement spanning the whole move.

Source: architecture review 2026-10-25, `Docs/QA/architecture-review-2026-10-25/report.md` §F2; slice 8 of 8 in the TASK-36952.3 split plan, measured at `08b3c9d337`.

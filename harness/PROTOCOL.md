# Profile one current-dev Console first send

Freeze the recorded dev commit. Run a single body-free diagnostic on GitHub
hosted macOS 15 with the real served browser, original loopback HTTP transport,
private profile, and original readiness, trace, exit, port, source and overlap
checks. Capture complete current checked/settled config references before
launch, with only the profile root normalized. Compare ordered schema
fingerprints independently between the HTTP receiver and the verified trace.
The qualified baseline's settings, header and schema fingerprints become the
sealed references for a separate unprofiled B/C/C/B/B/C/C/B comparison.

ADR required: no for observing existing boundaries.
ADR path: existing ADR 230 (Console Send) and 126 (storage and retirement).
Reason: instrumentation and the loopback fixture preserve product behavior.
Assess the eventual product change separately before editing.

1. Qualify one original app first send, including every existing lifecycle
   and cleanup guard and the bounded original scalar observer.
2. Attribute work only between the existing durable commit and trace
   reservation boundaries. Active-segment rankings are inclusive and overlap.

   behavior, make a targeted change and run connected tests and review.

   every sample before statistics. Require the original latency or concrete
   maintenance gate and normal protections before any product merge.

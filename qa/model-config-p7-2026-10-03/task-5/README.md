# TASK-33007.5: Model defaults as one-row field-truth rows (2026-10-04)

Keyboard-and-click captures of Settings ▸ Providers & Models and Console Behavior with
the real stylesheet, on the branch rebased onto dev `5e0341d1ec` (Phase 6 merged).

## Procedure

- The real app ran in an isolated tmux server (`-L p7t5live`) under `env -i`. `HOME`,
  `XDG_CONFIG_HOME`, `XDG_DATA_HOME` and `TLDW_CONFIG_PATH` pointed into a scratch
  directory, and the keyring backend was the null one.
- Two scratch profiles were written from the shipped template (generated by a process
  whose own `HOME`/`XDG_*` pointed at a second scratch directory), each with
  `users_name = "verify_p7t5_live"`, `[first_run] setup_completed = true`, the splash
  off, `[model_catalog] auto_refresh_enabled = false`, `[console.onboarding]
  first_send_completed = true` and `[chat_defaults] temperature = 1.0`:
  - Anthropic: `chat_defaults` = `anthropic` / `claude-sonnet-4-5`, a fake
    `api_settings.anthropic.api_key`, and `model_defaults."claude-sonnet-4-5"` =
    `max_tokens = 8192`, `top_p = 0.9`.
  - llama.cpp: `chat_defaults` = `llama_cpp` / `qwen3-8b-q4`, `api_url =
    "http://127.0.0.1:18768"` (nothing listening; no probe runs at rest), and
    `model_defaults."qwen3-8b-q4"` = `temperature = 0.6`.
  The template's own `chat_defaults` (streaming Off, top_k 50, ...) and provider
  scalars were left as shipped; they are the lower layers the blank rows name.
- Steps: start at 211x44, wait for the nav bar, **F4**, **F6**, **Down**, **Enter**,
  **Esc** (Providers & Models).
  - `01`: at rest (Anthropic).
  - `02`: **F6**, **Tab** x12 lands on Streaming (Provider, Sign in with, API key,
    Clear, Env var, Endpoint, Model, the Model defaults title, Temperature, Max
    tokens, Streaming).
  - `03`: **Tab** x3 (Thinking, Thinking budget, the Sampling title), **Enter**.
  - `04`: a click on the rail's Console Behavior, then the mouse wheel down to the
    global fallback rows.
  - `05`: the llama.cpp profile, same keys as `01`.
  - `06`: the same session resized to 235x52 (`tmux resize-window`).
- The app was quit, the tmux server killed, and the scratch directory (including the
  `verify_p7t5_live` data dir) deleted. `~/.config/tldw_cli/config.toml` still reads
  2026-09-26.
